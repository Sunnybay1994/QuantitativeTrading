## 1. 使用规则

1. 主 Agent 发现必须由用户决定、授权、提供合规来源或参与真实运行的事项时，更新本文件，不再把关键请求散落在聊天或单个交付报告中。

5. 状态含义：
   - `待批示`：没有用户决定，相关实现或外部操作停止。
   - `待用户提供`：需要用户取得材料、许可或外部条件。
   - `待前置完成`：已知未来需要用户参与，但当前工程前置尚未完成。
   - `已批准待执行`：用户已批准，主 Agent 尚未完成执行闭环。
