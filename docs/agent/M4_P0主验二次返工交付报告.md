## 2. 根因与修复

- **现象**：`raise StoreError(...) from None` 后 `__cause__ is None` 且 formatted traceback 无路径，但 `exc.__context__` 仍挂载含绝对路径的 `OSError` / `sqlite3.Error`。
- **根因**：活跃 `except` 内抛出只设 `__suppress_context__`，不擦除自动附着的 `__context__`。
- **修复**：PARENT / OPEN / PRAGMA / MIGRATION / TX_BEGIN / TX_COMMIT / CLOSE / REFERENTIAL_INTEGRITY 均在离开捕获原异常的 `except` 后再抛；不赋值异常私有字段。
- **保留语义**：`_safe_rollback` / `_safe_close` 失败不覆盖主错；transaction body 业务异常原样外抛；既有 URI / identity / FK / ROW_CORRUPT / 幂等语义不变。
