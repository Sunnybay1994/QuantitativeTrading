### 签名符合性

```python
@dataclass(frozen=True)
class LabelBuildResult:
    labels: pl.DataFrame
    diagnostics: pl.DataFrame

def compute_forward_relative_labels(
    *, bars, benchmark_bars, eligible_keys, calendars,
    horizons, benchmark, label_version,
) -> LabelBuildResult
```

- 证券：`(close(t+h)*adj_factor(t+h))/(open(t+1)*adj_factor(t+1))-1`
- 基准：`close(t+h)/open(t+1)-1`（不套用 factor）
- `eligible_keys` 为样本候选 SSOT；reason 优先级与 diagnostics 守恒按 §4.3
- `SYMBOL_PATTERN` 未放宽；`H00300.CSI` 与价格指数兼容码仅进 benchmark pattern

### 针对性反例

- 除权手算：entry open=100/factor=1，exit close=50/factor=2 → `raw_return=0`
- entry/exit factor 缺失或非法 → 对应 `ASSET_*_FACTOR_INVALID`
- 基准不使用 factor；无公司行动 fixture 数值与 v1 一致
- diagnostics：每个 `(eligible key, horizon)` 只进成功 labels 或一个 reason
