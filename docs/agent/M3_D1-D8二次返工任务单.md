## 2. F1：readiness 显式选源

- 从 `config[data].source` 读取必需 source；缺失/空值返回 `CONFIG_INVALID`。
- bars 和 benchmark bars 均先按 source 过滤，再做重复、因子、finite、日历、覆盖和截面检查。
- 任一表无请求 source 时返回 `DATA_SOURCE_MISSING`，不得回退到其他源。
- 两 source 同 symbol/date、选中源内唯一时不报重复；选中源内重复必须报错。

## 3. F2：staging 必须选择 universe（2026-07-13 P0 修订）

函数签名变更为：

```python
def prepare_qlib_staging(
    *, bars: pl.DataFrame, membership: pl.DataFrame,
    calendars: pl.DataFrame, source: str, universe: str,
) -> pl.DataFrame: ...
```

- membership 先过滤 `universe == requested`，取得历史 symbol 并集，再仅按 symbol 过滤 bars。
- 不得按 `effective_from/effective_to` 删除并集证券的行情；provider 要保留完整 history window，样本
  资格由后续 `eligible_keys` 单独过滤。原“按有效区间 join”要求被本修订明确废止。
- universe 缺失或过滤后为空时 `ValueError`。
- 混入 `OTHER/600999.SH` 及行情的反例中，输出不得包含该证券。
- 反例：某证券 2026-02-01 首次生效，但 bars 从 2025-11 起存在；staging 必须保留生效前 60 sessions，
  后续训练 eligible keys 不得包含 2026-02-01 之前的该证券样本。
- 所有调用点与测试显式传入 universe，不设隐式默认。

## 4. F3：共享 finite 语义

- OHLC/volume/adj_factor 任一 null、NaN、`+inf`、`-inf` 均不是有效行情。
- staging 对上述行 `ValueError`；readiness 将它们排除在截面/可训练 session 外，并返回可识别的数据质量 `ERROR`。
- 使用 Polars `is_finite`，不得只依赖 `is_not_null` 或大小比较。

## 5. F4：manifest 不变式

`build_snapshot_manifest` 新增必需 `universe: str`，并将其写入 hash 输入和 manifest 顶层。在读文件后、计算
snapshot ID 前拒绝：

## 6. F5：evaluate 显式日期域

函数签名变更为：

```python
def rank_ic_by_date(
    predictions: pl.DataFrame,
    labels: pl.DataFrame,
    *,
    evaluation_dates: Sequence[dt.date],
) -> pl.DataFrame: ...
```

- `evaluation_dates` 非空、唯一、严格升序；否则 `ValueError`。
- predictions 的所有日期必须在该集合内；区间外预测拒绝。
- labels 先按 horizon 和 evaluation dates 过滤，再构造 expected denominator。
- 区间外 labels 不影响输出日数和 coverage；区间内有 labels 无 predictions 的日期仍输出 matched=0。
- 只有 predictions 但无 label 的日期输出 expected=0，但不得将其计为“零方差日”；不可计算原因需区分覆盖不足与零方差。
