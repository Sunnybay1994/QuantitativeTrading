## 5. Windows / WSL1-DrvFS / 未来 WSL2-ext4 边界

| 边界 | 现状与含义 |
|---|---|
| Windows 原生 Miniforge | 允许作开发与定向反馈；**不等于** Linux Gate |
| WSL Miniforge `base` | Linux/平台特有终验权威；U0C runner 经 `wsl.exe` 调该环境 |
| 当前 WSL1 + DrvFS（`/mnt/f`…） | WT 报告明确：跨平台绿测是 DrvFS 开发合同证据，**不是** ext4 发布 Gate；`RENAME_NOREPLACE` 等语义与 ext4 不等价 |
| 未来 WSL2-ext4 | 正式不可变发布/部分 Gate 的环境前置；属用户主机变更，Agent 不得用 Windows/DrvFS 冒充 |
| U0C 锁语义 | R3 增加跨任务外层 `flock` 串行；在 DrvFS/WSL1 上需以真实窗口日志验证，不能只靠 fixture |
