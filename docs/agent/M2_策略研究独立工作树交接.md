## 4. 不可降低的研究边界

- 策略只消费传入的 `as_of` 可知数据，只输出符合 `TargetWeightSchema` 的 `target_weight`；
- 明确信号日和最早成交日，禁止同收盘价前视成交；
- 使用统一的整手、停牌、涨跌停、T+1、费用和现金约束；
- 每次只改一个可解释假设，预先写通过/失败条件，保留 walk-forward 和 0.5x/1x/2x 成本压力；
- 轻量 `run.json` 必须绑定代码、配置、数据截止日、时间切分和结论；
- 普通研究结论只能是 `REJECTED` 或 `RESEARCH_ONLY`。未经主线准入不得自报 `PAPER_CANDIDATE`，更不得直接发单。
