## R1：D1 readiness

- **根因：** 截面用每日最大值；训练长度用全日历高度；PIT 只看任意交集；缺字段后仍执行依赖检查并可能抛异常。
- **修复：** 解析 `start_date/end_date`；配置区间内 SH 开市日稠密逐日截面；可训练 session = 截面达标 ∧ 基准有效 ∧ 开市；PIT 按成员整段覆盖；缺字段记 ERROR 并跳过依赖检查。
- **修改文件：** `src/quant/research/m3/readiness.py`，`tests/unit/test_m3_readiness.py`
- **新增逆向测试：**
  - `test_r1_daily_cross_section_uses_minimum_not_maximum`
  - `test_r1_trainable_sessions_not_raw_calendar_height`
  - `test_r1_history_outside_config_range_does_not_count`
  - `test_r1_pit_member_without_bars_rejected`
  - `test_r1_missing_fields_return_issues_without_raising`
- **针对性测试：** `pytest tests/unit/test_m3_readiness.py` — 通过
- **未实现：** 无

## R2：D4 staging/manifest/provider

- **根因：** 跨源重复在选源前拒绝；OHLC 未按累计因子归一化；manifest 缺元数据；`validate_provider` 空目录即成功。
- **修复：** 先 `source` 过滤再查重；按冻结公式计算 `qlib_factor/ohlc/volume`；manifest 增加 `source/row_count/symbol_count/min_date/max_date/adjustment` 与文件级字段；`validate_provider` 在无 Qlib 或未 materialize 时 `RuntimeError` fail-closed。
- **修改文件：** `src/quant/research/m3/snapshot.py`，`tests/unit/test_m3_snapshot.py`
- **新增逆向测试：**
  - `test_r2_explicit_source_selection_allows_cross_source_same_key`
  - `test_r2_adjustment_formula_hand_calculation`
  - `test_r2_validate_provider_fail_closed`
  - manifest 必需字段断言并入原 hash 不变/改价必变用例
- **针对性测试：** `pytest tests/unit/test_m3_snapshot.py` — 通过
- **未实现：** `materialize_qlib_provider`；真实 3×20 逐字段回读（G0/G2 阻塞）。**D4 状态：staging/manifest 已实现，provider 验证 fail-closed，G2 未验证。**
