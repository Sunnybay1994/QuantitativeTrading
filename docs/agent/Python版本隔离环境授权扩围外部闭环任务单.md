## 1. 最新权威规则

用户授权不再只限 G0。冻结规则如下：

1. 项目主体、日常开发、核心测试和交易运行时仍使用 WSL Miniforge `base`；不得为了某个依赖改变 `base`；
2. 某个第三方工具存在明确 Python 版本兼容问题时，可在 WSL Miniforge 创建命名清晰的版本隔离环境，并只在该
   环境运行受约束工具及其直接测试/探针；当前允许的实例是 Python 3.12 环境 `py312`；
3. 非交互调用使用 `/home/mabw/miniforge3/bin/conda run -n <env> <command>`；环境的创建、Python 版本、用途、
   安装依赖和验证证据必须由具体任务书/报告记录；
4. 隔离环境不能替代主体 `base`，不能据此跳过 base 核心回归，不能从 Windows Python/conda 调用项目；
5. 当前 Qlib G0 首先使用 `py312`，但一般规则不写成“只有 G0 可以存在第二环境”。其他版本问题需由主 Agent
   确认真实兼容证据和任务边界后再创建/使用相应环境。

本包只同步 SSOT，不创建环境、不安装依赖、不联网，也不改变 G0/Gate 状态。
