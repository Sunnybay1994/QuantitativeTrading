## 3. `evaluate_pretrade` 优先级映射（只读）

```text
1. MASTER_SWITCH
   mode ∈ {PAPER,SHADOW} → AUTO_TRADE_FORBIDDEN → CONFIG_IDENTITY /
   MARKET_SNAPSHOT / ACCOUNT_SNAPSHOT / COUNTER_SESSION 硬拒 → _reject_all
2. DATA_GATE
   全局龄 stale：禁 BUY、SELL 可续；缺符号/停牌/买额度为 intent 级拒
3. FROZEN_SYMBOL（先于 sell-only）
4. SELL_ONLY（仅拒 BUY；不误拒 SELL）
5. LIMIT
   单笔 max_order_notional / BUY 的 max_symbol_weight
   → 批次合计：max_daily_notional（超限仅剔 BUY，保留 SELL）
              max_orders_per_day（超限剔全部含 SELL）
              max_gross_exposure（超限剔 BUY）
COMMAND_POLICY：SHADOW 永不发 command；manual_approval 阻断发射；否则 PAPER command
```
