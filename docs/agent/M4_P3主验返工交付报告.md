## 2. F1–F4 实现摘要

### F1 双快照时点 Gate

- 闭区间：`0 <= now - as_of <= snapshot_max_age_seconds`（UTC-aware）。
- `market.as_of` 未来 → `DATA_GATE_FUTURE`，**全拒**，不走「过期可卖」降级。
- `account.as_of` 未来 / 过期 → `ACCOUNT_GATE_FUTURE` / `ACCOUNT_GATE_STALE`，**全拒**（现金/持仓/sellable 不可信）。
- 仅 **普通 stale market**（非未来）：保留禁 BUY、允许合法 SELL（`DATA_GATE_STALE` + `DATA_GATE_BUY_BLOCKED`）。

### F2 projected gross exposure

- 分子：在现有持仓上投影本批 candidate intent（BUY 加、SELL 减）后的**证券绝对市值之和**；**现金不计分子**。
- 分母：账户权益（CNY 现金 available + 持仓 × verified reference price）。
- 缺失行情 state **不**用成本价补齐；`EQUITY_PRICE_MISSING` / `GROSS_PRICE_MISSING` fail closed。
- 非正 equity：**不**再静默替换为 `1`；BUY → `NON_POSITIVE_EQUITY`；合法 SELL 可继续。
- 超限仅剔 BUY，保留同批合法 SELL（与日名义超限语义一致）。

### F3 sellable quantity

- SELL 须存在同 `(market, symbol)` 持仓且 `quantity <= sellable_quantity`。
- 无持仓 → `SELLABLE_POSITION_MISSING`；超限 → `SELLABLE_EXCEEDED`；恰好等于 → `SELLABLE_OK`。
- 合法卖出继续参与 projected gross，不被 buy-only 限额误拒。

### F4 命令策略审计

- 仅当存在 approved intent 时记录 `SHADOW_READ_ONLY` / `MANUAL_APPROVAL_REQUIRED` / `COMMANDS_EMITTED`。
- 无 approved：`commands=()`、`requires_manual_approval=False`，保留真实拒绝码，不追加虚假待审批成功项。
