## 2. 冻结入口（任务书 §4）

### 2.1 Protocol（`execution/ports.py`）

```python
MarketDataRepository.load_verified_market_snapshot(
    *, symbols: tuple[str, ...], session_date: date, as_of: datetime
) -> VerifiedMarketSnapshot

AccountSnapshotRepository.load_account_snapshot(
    *, as_of: datetime
) -> AccountSnapshot
```

方法签名不含 `root` / `path` / `glob`；无任意目录参数。

### 2.2 生产实现（`data/repositories.py`）

| 类型 | 职责 |
|---|---|
| `ValidatedCleanMarketDataRepository` | 调用注入 `read_market_facts` → `CleanMarketFactsBundle`；校验质量 Gate、PIT、精确 symbol 集合、唯一 key；`build_verified_market_snapshot` |
| `ValidatedCleanAccountSnapshotRepository` | 同上模式，账户侧 `CleanAccountFactsBundle` → `build_account_snapshot` |
| `reject_data_legacy_path` / `configured_paths` | 接线期拒绝 `data/legacy`；load 方法本身不接收路径 |

### 2.3 In-memory fake

`InMemoryMarketDataRepository` / `InMemoryAccountSnapshotRepository`：按明确 key / PIT 返回已验证 snapshot；用于合同测试，不打开项目 `data/`。
