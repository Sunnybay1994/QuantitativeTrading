## F1 readiness 显式选源

- **根因：** 未读取 `data.source`，跨源同键被误报重复；请求源缺失时无 `DATA_SOURCE_MISSING`。
- **修改：** `src/quant/research/m3/readiness.py`；`tests/unit/test_m3_readiness.py`（`_base_config` 增加 `source="fixture"`）。
- **行为：** 缺失/空 `data.source` → `CONFIG_INVALID`；按 source 过滤后再做重复/因子/finite/覆盖；无行 → `DATA_SOURCE_MISSING`。
- **反例：** 跨源同键不报重复；选中源内重复报 `BARS_DUPLICATE_KEYS`；请求 `tushare` 而 fixture 无该源 → `DATA_SOURCE_MISSING`。

## F2 staging 按 universe 并集选证券

- **根因：** 无 `universe` 参数；按 `effective_from/to` join 会删掉调入前 history window；OTHER 池可泄漏。
- **修改：** `prepare_qlib_staging(..., universe=)`；membership 先按 universe 取 symbol 并集，再按 symbol + **仅 SH 开市日**过滤；**不**按生效区间删行情。
- **反例：** `OTHER/600999.SH` 不进入输出；`000003.SZ` 在生效前 2026-01-05 的 bars 仍保留在 staging。

## F3 共享 finite 语义

- **根因：** staging/readiness 只查 null/大小，NaN/±inf 可漏过。
- **修改：** staging `_reject_invalid_rows` 用 `math.isfinite`；readiness `_valid_bars` 用 Polars `is_finite()`，并新增 `BARS_NON_FINITE` / `BENCHMARK_NON_FINITE` ERROR。
- **反例：** `close=NaN` staging 抛 `ValueError`；readiness 报 `BARS_NON_FINITE` 且该行不计入截面。

## F4 manifest 不变式

- **根因：** `files=[]` 可生成 0 行 snapshot；缺 universe/G1 provenance；列/文件名/日期/finite 未强制。
- **修改：** `build_snapshot_manifest` 必需 `universe`、`g1_release_id`、`g1_release_manifest_sha256`；拒绝空 files/空 parquet/重复路径或 symbol/文件名不匹配/`STAGING_COLUMNS` 不完全相等/日期非唯一升序/非 finite。
- **反例：** 空 files、空 parquet、错误文件名、重复路径均拒绝；G1 字段进入 hash。

## F5 evaluate 显式日期域

- **根因：** labels 日期污染 `all_dates`，区间外标签降低 coverage。
- **修改：** `rank_ic_by_date(..., evaluation_dates=)`；校验非空/唯一/严格升序；预测日必须 ⊆ 评价域；labels 先按 horizon + evaluation_dates 过滤；每日一行；`incomputable_reason` ∈ `{None, zero_variance, insufficient_coverage}`；`n_zero_variance_dates` 只计 `zero_variance`。
- **反例：** 区间外 labels 不改变日数/coverage；缺预测日仍输出 matched=0；无标签日不计零方差。

## F6 tracking key 扫描

- **根因：** mapping key 未走 `_assert_safe_string`，绝对路径/凭据可藏在键名。
- **修改：** `tracking.py` Mapping 分支对每个 `key_text` 先 `_assert_safe_string`，再敏感片段检查。
- **反例：** Unix/Windows 绝对路径 key、`Bearer `/`token=` key 均拒绝。
