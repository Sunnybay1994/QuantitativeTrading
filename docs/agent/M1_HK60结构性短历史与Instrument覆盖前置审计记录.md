## 1. 审计口径

- `as_of = 2026-07-10`；SH_CONNECT / SZ_CONNECT 均用已发布 `universe_membership` 取得 644 个有效成员。
- 从 clean HK `trade_calendar` 取截至 as_of 最近 60 个开市日；第 60 日为 **2026-04-14**。
- 用 clean HK `instrument.list_date` 判断：`list_date > 2026-04-14` 的当前成员即使每个上市交易日都有行情，也
  天然不可能拥有 60 个观测。

## 3. 对 M1 完成合同的约束

1. “全市场近 60 日行情”不能机械定义为 644 个证券全部恰有 60 条；至少 5 个已证明属于结构性短历史，停牌
   也会形成合法短窗。正式 Gate 应要求：在可知上市区间和交易状态范围内无数据洞，并把结构性短窗与采集缺失
   分开报告。
2. 在正式判定结构性短窗前，必须先为 36 个成员取得可信的 instrument 类型、上市日和 board lot；数据源与
   有效期需留存，不能用当前名单 effective_from 冒充 list_date。
3. 当前 `update` CLI 单日 Tushare 路径会用一次 `hk_daily(trade_date=...)` 批量筛选所有请求证券，这适合账号
   1 次/小时限频；但它默认请求 `hk_adjfactor`（当前无权限），且把当日未返回证券全部作为质量失败。真实 HK60
   恢复需显式不复权采集并保留“停牌/未上市/真实缺失”的可审计分类，不能直接循环现有 CLI 放宽门禁。
4. HK 复权权限仍是独立未决项；不复权 bar coverage 通过也不能表述为港股复权链路通过。
