## 脱敏 / SSOT / 边界摘要

- **cause/context**：`_prove_*` 在 `except` 外抛出稳定错误；CE2/CE3/NaN 探针均确认 `__cause__ is None` 且 `__context__ is None`，`str(exc)=="CONNECT_RULE_INPUT_INVALID"`。
- **enum SSOT**：经济拒绝 code 全部来自 `ExecutionRejectReason`；模块内无第二套拒绝字符串集合（`_ACCEPTED` / `_INPUT_INVALID` / route frozenset 非拒绝枚举散落）。
- **无 IO/网络/rounding**：见上；ELO 边界消费上游 `limit_up`/`limit_down`，未用 previous close 伪造。
