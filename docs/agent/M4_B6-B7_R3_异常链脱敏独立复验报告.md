## 2. 代码核对

`build_trading_metrics` 保留原有输入验证、decimal context、B6 公共 verifier、场景指标构造和 identity
公式。R3 的唯一语义变化是：非 `TradingMetricsError` 异常在 `except Exception` 中仅被捕获，随后离开
活动异常处理器再调用 `_fail()`。因此 Python 不再把下游 hostile 异常自动挂入新异常的
`__context__`。既有 `TradingMetricsError` 仍原样传播，成功路径未改。

B6 replay closure、root `replay_input_id` 绑定、同一 `simulate_order_plans` 重放和完整结果比较均未在 R3
修改；R2 的生产实现与对抗性测试继续通过。
