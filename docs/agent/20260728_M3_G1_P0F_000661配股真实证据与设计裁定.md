
`https://investor.szse.cn/knowledge/stock/other/t20181017_555756.html`。

## 6. 设计裁定

采用 **CNINFO 配股事件 + Tushare daily 市场参考价** 双证据路径：

1. CNINFO 使用独立 raw-first request/intent/candidate/receipt/journal，不写进 Tushare
   journal，不复用旧 request id。
2. 通过 `connectors` 内的 CNINFO 薄适配器访问官方 API；AKShare 只负责当前
   `Accept-Enckey` 适配和可选依赖装载，生产域代码不得 import SDK。
3. raw 保存官方字段码及响应计数元数据；中文展示列不是 SSOT。
4. 历史证券按排序后 50 只一批；代码去后缀、逗号连接；同一代码必须只出现一次。
5. 只接收已实施成功的 A 股配股：实际配股数量大于 0，配股后总股本大于配股前总股本，
   差额与实际配股数量一致；日期和经济参数完整。
6. `配股比例` 按 CNINFO/公告“每 10 股”转换为每 1 股比例，禁止猜测其他单位。
7. dividend 与 rights 进入统一 corporate-action ledger/evidence；event identity 必须包含
   action type、供应商记录标识、日期和经济参数。
8. 通式扩为：

   ```text
   declared_ratio =
     previous_close × (1 + stock_ratio + rights_ratio)
     / (previous_close - cash_per_share_gross
        + rights_price × rights_ratio)
   ```

9. actual、market 支持域与相互匹配继续沿用 P0E；declared 超差时可由 market reference
   接受，但没有 CNINFO rights 或 Tushare dividend 事件时仍为 no-event，继续 fail closed。
10. 本轮不覆盖增发、重整、拆并股或差异化除权；后续首败必须另行冻结。
