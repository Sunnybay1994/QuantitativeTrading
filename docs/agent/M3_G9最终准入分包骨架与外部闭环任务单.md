## 2. 全局不变量

1. `snapshot_id` 仅用于定位；provider/experiment/work/comparison/acceptance identity 全部从已验真输入重算。
2. 不使用 `glob/rglob/listdir` 猜候选；预期 node、receipt 和相对路径只来自 G8 registry/plan builder。
3. 不复制生产公式；每 Gate 调用对应模块的 `verify_*_artifact`，G9 只做身份、覆盖和证据合取。
4. 上游损坏时下游必须产生稳定 `UPSTREAM_EVIDENCE_INVALID`，不能崩溃、跳过或伪报 PASS。
5. FAIL 决策只输出规范 JSON，不写 final 目录、receipt 或看起来像成功证据的报告。
6. 所有持久 JSON 严格字段、duplicate-key 拒绝、规范编码、`allow_nan=false`，不含 PID、时间戳、绝对路径、
   tracking URI、token、客户端 repr 或未筛选配置。
7. 工程准入只检查口径、覆盖、闭包和可复现性；RankIC、收益或超额为负本身不是工程失败。
