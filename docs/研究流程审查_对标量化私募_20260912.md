> [`当前工作进展与后续计划_20260912_1125.md`](research/当前工作进展与后续计划_20260912_1125.md)。
> 结论：**流水线按设计落地了，执行质量高；但 P4"三模型全部 REJECTED"是评估设计的人为产物，不是模型无效。**
> 对标私募流程，缺的是风险模型、组合构建约束和因子健康诊断三块。下面按"发现 → 为什么重要 → 怎么改"写。

## 0. 先肯定做对的

- 因子库 353 个因子 / 658 个版本（raw + 规模行业中性两版），表达式 DSL 落地，全市场 2010 起全历史面板。
- 评估电池：MAD 3σ 去极值、OLS 规模+行业中性化、ST/新股/停牌/涨跌停/成交额后 20% 过滤、Newey–West t、ICIR、年度符号一致率、10 分组、多空 Sharpe、衰减、换手、冗余、三档成本、BH-FDR。**这是私募因子评估的标准配置**，一次写死不再改动，正确。
- 三模型逐年扩展 walk-forward、因果准入（只用截止再拟合日已知的历史选因子）、固定参数、极端窗口、水下期——纪律性超过多数个人研究者。
- 日更链：刷新 → 固定模型预测 → 8 个观察账户 → 月报，一条命令、重跑不重复推进。
- DeepSeek 循环：诊断 → 受限表达式 → 搜索 → 同一电池评估；文本信号先小批校准再决定预算。方向正确。

## 1. 必须立刻修的：评估设计缺陷（不是降低标准，是修正测量）

| E2 | 股票等权基准用 100 万现金过 `daily_account` 整手回放：全市场等权平均仓位 **4.19%**，中证 800 等权 43.5% | 两个基准数值无意义，三基准里只剩 510300 | 基准必须是**收益指数**：Tushare `index_daily` 取 000300 / 000905 / 000852 / 000906 / 000985 全收益或价格指数；自建等权基准用月末等权、按日收益复合、不经过整手与现金约束 |

修完 E1–E4 重跑 P4，预期结论从 REJECTED 变为 RESEARCH_ONLY 或候选；E5 决定它能不能进模拟盘。

## 2. 对标私募流程的差距与改法

私募的标准链路：数据 → 因子预处理与健康诊断 → 因子评估（含纯因子收益）→ 收益模型 → **风险模型** → **组合优化（约束）** → 交易成本模型 → 执行算法 → 事前/事后风控 → 归因与监控。本项目缺中间三块。

### R1 因子健康诊断（用户问的"丰度、偏度"）—— 缺

当前 scorecard 有覆盖股票数中位数和 20 日配对覆盖率，没有分布诊断。每个因子（raw 版）补一张"健康表"，进 scorecard 新增列：

| 指标 | 用途 |
|---|---|
| 逐日覆盖率（有效值 / 可交易池）、缺失率的时间序列与逐行业分布 | 丰度；发现某段时间因子失效或数据源换代 |
| 偏度、峰度、MAD 截尾比例（被 clip 的比例） | 分布形态；偏度 > 3 或截尾 > 5% 的因子要改用 rank 变换 |
| 年度 KS 统计量（相邻年份分布漂移） | 因子口径漂移、数据源接缝 |
| 与风格因子的截面相关（规模、beta、动量、波动、流动性、价值、成长、杠杆）| **"我的 alpha 是不是一个风格赌注"**——当前只中性化了规模+行业 |
| Top 分组的流动性画像：成交额分位分布、ADV20 中位数、持仓市值/ADV | 容量与可执行性 |
| 因子值时序自相关（有）、Top 分组月换手（有） | 保留 |

### R2 风险模型 —— 缺，是最大的差距

没有风险模型，就无法回答"2024-01 亏的 27% 里多少是规模、多少是行业、多少是选股"，也无法在组合层约束暴露。建一个 **CNE5 风格的轻量风险模型**（约 500 行 polars + numpy）：

- 风格因子 10 个：规模（log 市值）、非线性规模、beta、动量（12-1）、残差波动、流动性（换手）、账面市值比、盈利收益率（EP）、成长（营收/净利同比）、杠杆；行业用 `industry_l1` 哑变量；全部按日 MAD + z-score。
- 每日截面回归（市值平方根加权）→ 因子收益序列、特质收益；因子协方差 EWMA（半衰期 90 日），特质方差 EWMA（半衰期 60 日）。
- 输出：任意组合的风格/行业暴露、事前跟踪误差、风险预算、事后归因（因子收益贡献 vs 特质贡献）。
- 三处使用：① scorecard 补"Top 分组风格暴露"和"**纯因子收益**"（Fama–MacBeth 控制风格后的因子收益 t 值，比单纯规模行业中性更严格）；② 模型组合的月度暴露报告与 2024-01 归因；③ R3 的约束输入。

### R3 组合构建 —— 从 Top-K 等权升级为带约束的构建

私募几乎不用 Top-K 等权做产品，用的是**指数增强框架**：对某个基准（这里最合适的是中证 1000 或中证 500，因为 A 股因子在中小盘更强）控制主动暴露，把 alpha 分数转成主动权重。个人版本不需要完整 QP，两档可选：

- 简版（先做）：**分层选股 + 暴露上限**。行业主动权重 ±5pp 内；规模暴露 |z| ≤ 0.3（对基准）；单票 ≤ 3%；持仓 60–100 只；缓冲区（跌出 Top 1.5K 才卖）；单笔委托 ≤ ADV20 的 5%。
- 优化版（简版有效后）：`scipy`/`cvxpy` 求解 max(score·w − λ·wᵀΣw − c·|Δw|)，约束同上。

三种构建（Top50 等权 / 分层约束 / 优化）并排跑 2015–2026，2024-01 窗口的差异会直接告诉你约束值多少钱。

### R4 因子评估补两项

- **增量 IC**：把候选因子对已准入集合做截面正交化后再算 IC/t，代替现在的"与更高分因子 |ρ| < 0.7"。后者放过了一批相关 0.6 的近似重复（scorecard 里 alpha158 与 price_volume 系列 |ρ| 0.69–0.91 就是例子）。
- **状态条件 IC**：按 510300 相对 200 日线（牛/熊/过渡）、市场波动率分位、大小盘风格相对强弱三种状态分组报 IC，找出只在某种状态有效的因子（动量类通常如此），为 R5 的状态控制提供依据。

### R5 极端行情与风控 —— 部分到位

到位：涨跌停拒单、停牌、退市核销、历史税费、B93 四个极端窗口、水下期、成本 0.5×/1×/2×。

缺：

| 项 | 改法 |
|---|---|
| 极端窗口集只有 4 个，且 2020/2022 因空仓"通过" | 扩到 8 个：2015-06-15→09-30 千股跌停与停牌潮、2016-01 熔断、2018 全年、2021-02→03 抱团瓦解、2022-04、2023-08→2024-02 小微盘、2024-01、2024-09→10；空仓窗口标"不适用"而非"通过" |
| 流动性压力：无参与率约束 | 委托 ≤ ADV20 × 5%；压力情形下 ADV 取窗口内最低 20 日；跌停日卖不出已建模，再加"连续跌停 3 日按 −10%/日核销"的极端假设做敏感性 |
| 组合层风控只有 `concentration_caps.py` 30 行 | 事前：单票/行业/规模暴露/参与率四项硬约束进 `order_planner`；事后：日频写暴露、跟踪误差、回撤、换手到 `artifacts/paper/<acct>/risk_daily.csv`，超阈值在 `orders.md` 顶部标红 |
| 回撤控制作为**被检验的假设**而非默认 | 三个候选 overlay 各一页预注册：① 组合回撤 > 15% 仓位降至 50%、创新高恢复；② 12% 目标波动缩放；③ 510300 < 200 日线时仓位 70%。全部按 2015–2026 全历史比较，不通过就不用 |
| 因子失效监控 | 日更链里每月算一次持仓因子的近 12 个月滚动 ICIR 与全历史比较；跌到全历史 25 分位以下写进月报"预警"节，不自动动仓 |

### R6 数据预处理 —— 基本到位，补三项

到位：PIT 财务按公告日、复权、分红、ST 历史名称、退市保留、行业历史、分钟对账。

补：① 缺失填充策略写进 `battery.toml`（当前是 complete-case，见 E3）；② 财务数据的**极端值与会计口径断点**（如 2007 新准则、金融股报表结构）在因子层单独处理，金融/非金融分开算杠杆与成长；③ 每日数据质量报告：行数、缺失率、价格跳变（|涨跌| > 30% 非新股）、复权因子跳变、财务重述计数，接入日更链并落 `artifacts/data_quality/daily/`。
