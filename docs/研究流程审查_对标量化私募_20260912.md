## 2. 对标私募流程的差距与改法

私募的标准链路：数据 → 因子预处理与健康诊断 → 因子评估（含纯因子收益）→ 收益模型 → **风险模型** → **组合优化（约束）** → 交易成本模型 → 执行算法 → 事前/事后风控 → 归因与监控。本项目应优先补齐风险归因和组合约束，并完善已有健康与风控诊断。

### R1 因子健康诊断（用户问的"丰度、偏度"）—— 缺

当前 scorecard 有覆盖股票数中位数和 20 日配对覆盖率，没有分布诊断。每个因子（raw 版）补一张"健康表"，进 scorecard 新增列：

| 指标 | 用途 |
|---|---|
| 逐日覆盖率（有效值 / 可交易池）、缺失率的时间序列与逐行业分布 | 丰度；发现某段时间因子失效或数据源换代 |
| 偏度、峰度、MAD 截尾比例（被 clip 的比例） | 分布形态；偏度 > 3 或截尾 > 5% 先触发诊断；rank 变换另作版本验证，不自动改历史定义 |
| 年度 KS 统计量（相邻年份分布漂移） | 因子口径漂移、数据源接缝 |
| 与风格因子的截面相关（规模、beta、动量、波动、流动性、价值、成长、杠杆）| **"我的 alpha 是不是一个风格赌注"**——当前只中性化了规模+行业 |
| Top 分组的流动性画像：成交额分位分布、ADV20 中位数、持仓市值/ADV | 容量与可执行性 |
| 因子值时序自相关（有）、Top 分组月换手（有） | 保留 |

### R2 风险模型 —— 缺，是最大的差距

先复用 `model_stratification` 的暴露数据，补市场、行业、风格与特质收益归因；行业/规模约束可先使用现有暴露，不必等待完整协方差模型。参考 CNE5 思路逐步实现轻量风险模型，不以代码行数承诺精度：

- 风格因子 10 个：规模（log 市值）、非线性规模、beta、动量（12-1）、残差波动、流动性（换手）、账面市值比、盈利收益率（EP）、成长（营收/净利同比）、杠杆；行业用 `industry_l1` 哑变量；全部按日 MAD + z-score。
- 用前一时点可知暴露解释随后日收益，固定回归权重及行业共线性处理，输出因子收益、特质收益并核对贡献合计。需要事前跟踪误差时再补 EWMA 因子协方差（候选半衰期 90 日）、特质方差（60 日），先写配置并核验预测风险；这是简化模型，不等同于商业 Barra。
- 输出：任意组合的风格/行业暴露、事前跟踪误差、风险预算、事后归因（因子收益贡献 vs 特质贡献）。
- 三处使用：① scorecard 补"Top 分组风格暴露"和"**纯因子收益**"（Fama–MacBeth 控制风格后的因子收益 t 值，比单纯规模行业中性更严格）；② 模型组合的月度暴露报告与 2024-01 归因；③ R3 的约束输入。

### R3 组合构建 —— 从 Top-K 等权升级为带约束的构建

保留 Top50 等权作为研究对照，新增带约束的构建；采用指数增强框架时，先在配置中固定主基准、主动暴露定义及样本范围，不根据结果挑基准。个人版本先做简单构建：

- 简版（先做）：**分层选股 + 暴露上限**。行业主动权重 ±5pp 内；规模暴露 |z| ≤ 0.3（对基准）；单票 ≤ 3%；持仓 60–100 只；缓冲区（跌出 Top 1.5K 才卖）；单笔委托 ≤ ADV20 的 5%。
- 优化版（简版有效后）：`scipy`/`cvxpy` 求解 max(score·w − λ·wᵀΣw − c·|Δw|)，约束同上。

先比较 Top50 与一种分层约束构建，在共同有效区间报收益、风险、换手及三档成本，并分列极端窗口。优化器待简单构建有测得的瓶颈后再研究，不要求首轮交付三种构建。已有换手预算实验将日历模型持仓后换手 10.81→6.42 倍、年化 17.04%→13.48%，应复用该失败证据，避免重复同一路径。

### R4 因子评估补两项

- **增量 IC**：把候选因子对已准入集合做截面正交化后再算 IC/t，先与现有"与更高分因子 |ρ| < 0.7"并报；若改变准入则另建配置、冻结阈值并重算年度名单。后者放过了一批相关 0.6 的近似重复（scorecard 里 alpha158 与 price_volume 系列 |ρ| 0.69–0.91 就是例子）。
- **状态条件 IC**：按 510300 相对 200 日线（牛/熊/过渡）、市场波动率分位、大小盘风格相对强弱三种状态分组报 IC，找出只在某种状态有效的因子（动量类通常如此），为 R5 的状态控制提供依据。

### R5 极端行情与风控 —— 部分到位

到位：涨跌停拒单、停牌、退市核销、历史税费、B93 四个极端窗口、水下期、成本 0.5×/1×/2×。

缺：

| 项 | 改法 |
|---|---|
| 极端窗口集只有 4 个，且 2020/2022 因空仓"通过" | 扩到 8 个：2015-06-15→09-30 千股跌停与停牌潮、2016-01 熔断、2018 全年、2021-02→03 抱团瓦解、2022-04、2023-08→2024-02 小微盘、2024-01、2024-09→10；空仓窗口标"不适用"而非"通过" |
| 流动性压力：无参与率约束 | 委托 ≤ ADV20 × 5%；执行约束用信号前可知 ADV20；窗口最低流动性只能用于事后压力诊断。连续跌停按板块/历史规则设置情景并保留无法成交持仓，不将价格冲击再核销一次 |
| 现有 `order_risk`、`manual_orders` 已有风险诊断与拦截，但与研究组合约束尚未完整统一 | 复用已有现金/单票/行业/流动性检查，补主动规模和订单参与率并接入回放；事后记录实际可得的暴露、回撤、换手，跟踪误差待风险模型可用后增加，超限在订单参考顶部提示 |
| 回撤控制作为**被检验的假设**而非默认 | 三个候选 overlay 各一页预注册：① 组合回撤 > 15% 仓位降至 50%、创新高恢复；② 12% 目标波动缩放；③ 510300 < 200 日线时仓位 70%。全部按 2015–2026 全历史比较，不通过就不用 |
| 因子失效监控 | 日更链里每月算一次持仓因子的近 12 个月滚动 ICIR 与全历史比较；跌到全历史 25 分位以下写进月报"预警"节，不自动动仓 |

### R6 数据预处理 —— 基本到位，补三项

到位：PIT 财务按公告日、复权、分红、ST 历史名称、退市保留、行业历史、分钟对账。

补：① 缺失处理写入独立模型输入配置，保留原评估配置和结果（见 E3）；② 财务数据的**极端值与会计口径断点**（如 2007 新准则、金融股报表结构）在因子层单独处理，金融/非金融分开算杠杆与成长；③ 复用 `quant.data.daily_input_quality` 及现有日更质量检查，补充每日数据质量报告：行数、缺失率、价格跳变（|涨跌| > 30% 非新股）、复权因子跳变、财务重述计数，接入日更链并落 `artifacts/data_quality/daily/`。

## 5. 当前结论

已有研究链路支持继续投入；原 IC 模型同窗约 9.27pp/年的大盘超额是真实的历史描述，换手与回撤仍未达原条件。接下来修基准与准入、检验覆盖和组合约束，让正确比较决定是否进入第二模拟账户，而不是为得到候选修改标准。
