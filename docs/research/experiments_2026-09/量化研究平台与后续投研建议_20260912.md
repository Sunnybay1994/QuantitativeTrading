**建议继续把 Q1 测量修复、Q3/Q4 风险暴露与组合构建、Q5 成本执行放在扩充模型之前；新增研究集中于已有信号的可交易增量、PIT 基本面/公告与分钟低频化。** 外部文献用于产生假设，本地按统一口径的新 run 才能改变策略结论。

## 2. 已能直接指导工作的发现

### 2.1 数据与口径会改变结论，版本修正应优先于调模型

Open Source Asset Pricing 在 2024-10-14 专门修复 AnnouncementReturn 的前视问题，2025 年又更新为 Python 信号实现；这说明公开复现库也需要跟随修订核对公告时序。[来源](https://www.openassetpricing.com/code/)

Ken French 数据库自 2025 年 1 月由 CRSP FIZ 改用 CIZ：旧月收益按月末再投资分红，新月收益按日复合并在除息日再投资。相同“月收益”标签可以对应不同构造。[来源](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/data_library.html)

**项目动作：**Q1 保留官方指数的价格/全收益属性与分红处理，确保策略和基准区间一致。首次实际持股日至评估结束应保留中间再次空仓的日期，另报现金占比；不得只挑非零收益日。基准修复还要传导到历史年度因子成本准入与名单选择，随后重跑模型。这些动作沿用 Q1 当前实现安排。

### 2.2 规模分层与组合暴露需要一起看

JKP 的复现输出包含按规模分组的特征管理组合，分组断点也明确区分微盘股。[来源](https://jkpfactors.com/release-notes) 对本项目的启示是：因子层去掉线性规模暴露后，Top-K 截断、缺失样本和股票池仍可能改变最终组合的规模分布。

**项目动作：**在 Q3/Q4 用滞后暴露解释全期及各压力窗口，并对照同信号、同费用、同股票池的 Top50 与受约束组合。2024 年 1 月已有亏损只提供诊断线索；约束阈值按经济规则和训练/验证期固定，不根据这个已见窗口反复调到好看。

### 2.3 因果检查已有基础，优先补组合输入的衔接

JKP 的 [Common Task Framework 规则](https://jkpfactors.com/ctf/rules)（页面更新 2026-09-05）包含去掉未来数据后重新计算，比较历史权重是否变化的方法。该比赛还限制数据与特征选择，其全部规则不直接移植为项目制度。

本地已存在因子截断、未来标签扰动、年度成本与选择不变性测试，见 `tests/unit/test_factor_intraday.py`、`test_model_training_prefix.py`、`test_model_training_costs.py`、`test_model_training_selection.py`。新的缺失填充、风险暴露或候选搜索只需将同类检查覆盖到变化的接口，继续使用已有测试与研究 run。

### 2.4 缺失值应先分类，再比较简单方法

Chen–McCoy 的 [Missing Values Handling for Machine Learning Portfolios](https://arxiv.org/html/2207.13071v6) 比较多种插补与预测方法，发现简单截面均值在其资产定价数据上表现很好；复杂方法可能引入估计噪声。文章还指出，部分缺失来自数据源尚未存在，部分来自历史窗口不足，另一些来自因子经济定义限定适用股票。

**项目动作：**Q1 的简单填充作为可解释基线；Q2 同时记录缺失原因和每只股票实际使用的因子比例。价格、交易状态、收益标签、必需风险控制字段保持其业务约束，不能为扩大模型截面而统一补零。对均值、行业中位数等方法的比较，分别报告同一可用样本上的变化和新增股票带来的变化；不能把扩容收益全部归到插补方法。

### 2.5 LLM 的优势要从信息增量中证明

Bradford Levy 的 [Caution Ahead: Numerical Reasoning and Look-Ahead Bias in AI Models](https://onlinelibrary.wiley.com/doi/10.1111/1475-679x.70058)（Journal of Accounting Research，2026）通过按年知识截止模型、财报数字扰动和滚动 GBDT 对照研究盈余预测。结果提示历史预测可能混入记忆，并支持将数值计算交给程序。研究对象和受测模型有限，不能据此判定所有文本信号无效。

**项目动作：**P7 先用公告结构化字段做数值基线，再比较“变动原因”文本的增量。Codex 优先承担论文分析、提示词/解析器开发、失败案例设计；真实 API 评分仍沿既有 DeepSeek 小批校准。使用遮蔽公司名、保留含义的数值单位变换等敏感性诊断，并保留模型冻结后的新公告前向样本；这些诊断本身不能证明完全没有历史泄漏。

一项应立即更新的文献判断：Kim、Muhn、Nikolaev 的 **Financial Statement Analysis with Large Language Models 已于 2025-02-20 撤回**。[arXiv 状态](https://arxiv.org/abs/2407.17866)与[作者说明](https://faculty.chicagobooth.edu/valeri-nikolaev/ongoing-research-projects)均可核实，原因是复现时发现数据与分析不一致。旧摘要仍留在网页上，不能继续拿其中“胜过分析师”的结论支持 P7 预算或模型选择。

### 2.6 从业者的失败和争论能缩小搜索范围

Man 的 [2015 年圆桌](https://www.man.com/insights/overfitting-and-its-impact-on-the-investor)同时呈现对数据挖掘的警惕与对有纪律探索的支持，也指出短期试运行可以暴露实现问题，却不足以证明收益显著。[2019 年圆桌](https://www.man.com/insights/factor-investing)则讨论因子附带的行业、规模等暴露。

Rob Carver 的[快信号成本实验](https://qoppac.blogspot.com/2023/02/)分别考察预测、头寸、缓冲及成本，最终没有支持其最初“组合可以容纳更多快速信号”的设想。QSE 上 [Lehalle 的问答](https://quant.stackexchange.com/questions/83939/how-can-we-determine-the-minimum-viable-holding-period-given-granular-data-and-t)提醒成本应与策略、换手和规模一起衡量。

**项目动作：**先解释已有缓冲/换手实验为什么失败，再决定新机制。Q8 前向日志用来分离实现误差、成本偏差与信号变化；连续几个月模拟结果不承担本项目长期统计证据的全部职责。

### 2.7 独立因子成本与组合增量是不同问题

DeMiguel、Martin-Utrera、Nogales、Uppal 的 [A Transaction-Cost Perspective on the Multitude of Firm Characteristics](https://lbsresearch.london.edu/id/eprint/1124/)（RFS 2020）讨论多特征组合中的交易抵消：不同信号对同一股票的反向交易合并后，只需执行净额。作者接受稿引言与联合组合动机已读，详见经典专题 §7。

**项目动作：**当前 Q1 的冻结准入照常完成。Q7 可另预注册少量经济来源不同的家族组合，比较“分别建组合后计成本”与“合并目标后计成本”，并检查风险暴露与真实整手订单。家族名单只能由训练期确定；这是新的模型级实验，不会自动翻转旧的单因子 `REJECTED`，也不需要重启逐因子参数搜索。

## 3. 接到当前计划上的三项优先工作

以下为本次文献推导的建议，优先复用当前责任人和已开发模块；数值通过条件须在对应 config 里事先固定。

| 顺序 / 工作 | 目标与最小对照 | 关键产出与判断 | 时间盒 / 依赖 |
|---|---|---|---|
| **1. 完成 Q1，并把 Q2 缺失诊断接入报告** | 统一收益指数、首次持股后连续区间、48 月因果训练名单；固定预测器比较既有共同完整截面与简单填充 | 年度可用股票/信号月份、缺失原因、同样本预测差异、新增覆盖贡献、净成本指标。填充恢复信号不能直接等同于发现 alpha | 复用已开展 Q1/Q2；实现与解释半天，重跑后台完成 |
| **2. 完成 Q3/Q4/Q5 的组合与成本闭环** | 固定预测，先比较 Top50 与预注册的简单约束；再单独考察确有新机制的成本控制 | 滞后风格/行业贡献、主动暴露、预测到实际成交的换手分解、未成交原因、0.5×/1×/2× 成本。整体表现与多个窗口共同判断 | 模块继续并行；一个组合规则最多一天，依赖 Q1 修正基线 |
| **3. 用 P7 与现有因子库做信息增量研究** | 结构化公告基线→文本字段增量；另从文献挑经济来源不同的候选家族，和已有家族做消融比较 | 同样本的控制后增量 IC、年度一致性、覆盖/漂移、成本后贡献；候选按批进入流水线，保留总尝试数和失败结果 | 文献映射、表达式/解析开发半天；文本先小批，分钟线等待足够覆盖 |

第二项特别值得配读 [Machine Learning and the Implementable Efficient Frontier](https://academic.oup.com/rfs/advance-article/doi/10.1093/rfs/hhag022/8524346)（Jensen、Kelly、Malamud、Pedersen，RFS 2026-03-15 在线发表）：该研究将交易成本放进风险与组合评价。正文 §5 的基线是大型 NYSE 股票与 100 亿美元投资者，成本采用成交量相关的二次冲击模型；A 股个人账户应保留自己的费用、整手和成交限制。近期迁移评价目标与成本诊断，直接训练组合权重的方法留待简单约束结果出来后判断。

三项工作的并行方式是：数据任务完成质量与可知性，开发任务完成互斥模块和定向验证，主进程接入并解释真实 run。本文的文献工作提供定义、反例和实验选择；共享路线图由主进程统一更新。

**扩充因子库的取舍：**经典动量、价值、盈利能力以及分钟统计已有多项实现，先读专题里的本地映射；复现论文原定义或增加新数据来源才算有价值的新增。分钟低频化目前首先受覆盖与历史长度制约，可继续开发候选和诊断，已有短历史结果只作研究证据。LLM 多代理框架、复杂插补、全量高维优化都排在这三项之后。

本土增量来源可先看[从业者专题 §5](../references/量化平台_从业者讨论_20260912.md)：方正 2023 年“多空博弈”把分钟成交量路径压成日/月信号，中邮 2025 年微盘周报展示历史成分与固定当期成分的差异。前者需核对原文 1 分钟输入与本地 5 分钟替代的规格差异，后者更适合完善 Q3/Q8 的样本变更诊断。

### 3.1 最先读的六组材料

| 研究问题 | 阅读组合 | 读完应能做出的选择 |
|---|---|---|
| 为什么因子复制结论会相反 | Hou–Xue–Zhang (2020) 与 Chen–Zimmermann (2022)，见[经典 §2–3](../references/量化文献_经典研究_20260912.md) | 将原定义复制与本地可投资检验分开；不把改样本后的失效全部当实现错误 |

| 更多信号是否一定增加成本 | DeMiguel 等 (2020) 与 RFS 2026 实施有效前沿，见[经典 §7](../references/量化文献_经典研究_20260912.md)及[近期索引](../references/量化文献_近期研究_20260912.md) | 先测合并目标和净成本，再决定保留多少家族；固定信号分解约束制造的换手 |
| 缺失怎么处理 | Chen–McCoy (2024) 配 Freyberger 等的 *Missing Data in Asset Pricing Panels*，见[近期索引](../references/量化文献_近期研究_20260912.md) | 先简单插补并查缺失结构，复杂方法必须证明本地增量 |
| LLM 历史预测是否可信 | Levy (2026) 配 Kim 等撤回记录，见[近期索引](../references/量化文献_近期研究_20260912.md) | 结构化基线、文本增量、扰动与前向样本分开；不给旧摘要的收益承诺追加预算 |
| 分钟数据如何服务月度选股 | Amaya 等 (2015) 配方正“多空博弈”原文，见[经典 §9](../references/量化文献_经典研究_20260912.md)与[从业者 §5](../references/量化平台_从业者讨论_20260912.md) | 先核对聚合周期、原始频率与覆盖，再决定新表达式是否真的增加信息 |

批量研究还有一个需在下一版配置中明确的问题：本地 `configs/factors/battery.toml` 的 `admission_requires_fdr=false`。这意味着计算 BH-FDR 与用它约束准入是两个事实。主进程应明确探索排名和最终准入各采用什么统计规则；引用 Harvey–Liu–Zhu (2016) 时，不把其一般多重检验论述机械换成月度 RankIC 的一个新阈值。详见[经典 §4](../references/量化文献_经典研究_20260912.md)。

## 4. 如何把文献持续变成可评估信号

一次研究批次按以下顺序完成：

1. 从原论文/作者代码取得定义，记录版本、数据时序和经济解释；同时查勘误、复现与反例。
2. 对照当前因子库，区分已实现、需要修正定义、确有新增信息的候选。已有失败结果保留。
3. 候选成批登记，模型/组合规则先写版本化 config；冻结样本划分、搜索规模、评价口径与预算。
4. 流水线计算特征、评估、成本和增量；Agent 读结果，决定下一批信息来源。保存失败候选和总尝试数。
5. 阅读论文与调试可并行；共享数据发布和同文件修改沿现有责任人串行完成。15 点前优先用 Codex 做调研、实现与解释，DeepSeek 继续按原有小批校准与费用边界执行。

最值得固定下来的阅读组合是：**一篇方法/原始研究 + 一份复现代码或数据说明 + 一篇实施争论**。每批最终产出是候选配置、可复查 run 和一页选择结论，而不是继续扩充平台名单。
