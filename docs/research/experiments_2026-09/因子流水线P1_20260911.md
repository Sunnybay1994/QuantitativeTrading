# P1：首批20因子的全历史批量面板

2026-09-11完成计算入口：20个因子覆盖2010-01-04至2026-09-10的5,487只历史沪深股票、14,020,211个股票交易日；340个因子年分区共280,404,220条记录（包含缺窗空值），另有17个收益面板年分区。股票池过滤留在评估层。

## 使用

```powershell
$env:PYTHONPATH = 'F:\AI_Coding\QuantitativeTrading\src'
D:\Miniforge3\python.exe -m quant.factors.compute --factors all --from 2010-01-01 --to today
```

定义放在`configs/factors/library/*.toml`；每个定义含`id / expr / family / direction / source_ref`。首批为8个Alpha101、7个Alpha158、MAX、CV20、两种市值和账面市值比。方向仅作为后续统一评估的输入。

面板位于`data/factors/<id>/year=YYYY/data.parquet`，列为`trade_date / ts_code / value`。相同数据再次执行为no-op；新交易日只计算新增区间及必要的历史窗口。收益标签补算尚未成熟的尾部。修正输入或算子后，使用`--rebuild`重算请求范围；表达式变更使用新因子ID，避免混入旧列。

算子采用受限AST解释，不执行Python表达式；支持时序均值、标准差、极值、排名、相关/协方差、滞后/差分、线性衰减、截面排名、缩放和按已提供行业列去均值。时间窗口按交易日补齐，缺值窗口留空，行业列必须由调用方提供当时有效的数据。未来行情仅用于收益标签，因子计算只向后取数。

收益面板复用既有下一开盘标签：`open(t+1+h)×adj_factor / (open(t+1)×adj_factor)−1`，h为1/5/10/20/60个交易日；入场/离场日期随列保存。它是复权毛收益标签，组合成交约束与成本由后续因子评估流水线和统一回测器计算。
