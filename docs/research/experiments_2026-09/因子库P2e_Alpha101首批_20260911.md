# P2e：Alpha101首批扩展与数值修正

新增30个Alpha101编号，并增加第33式修正版，因子库由171增至202个定义。Alpha101已覆盖38个编号；达到数量目标后，仍继续补齐剩余编号、既有因子、PIT30和分钟9。

本批按[原始论文附录A](https://arxiv.org/pdf/1601.00991)登记第1–36式中缺少的30式。跨日价格使用累计复权价；VWAP为成交额/股数；论文的平均日成交金额`adv`在本地采用人民币成交额的滚动均值，`volume`为股数。因此第7式保留原文形式的金额/股数比较，和既有“当日成交额超过20日均额”的本地变体分列；阈值没有按收益调整。全部方向+1，在计算前固定。

原库`alpha101_033 = 1-open/close`与论文第33式相反。新增`alpha101_033_paper = rank(-(1-open/close))`；保留原列供历史结果解释，后续标准Alpha101集合使用修正版。

独立公式对照发现并修正三个数值边界：常量窗口的相关留空、协方差为0；横截面排名先保留10位有效数字，消除计算尾差造成的伪排序；线性衰减遇缺窗留空。极小量级仍按有效数字处理，避免绝对舍入把信号抹零。受影响的13个既有因子全历史重算，避免新旧口径混用。

37项相关测试通过：31式与独立Pandas实现在380日、8只股票上逐值对照，另含缺失传播、未来截断、常量和排名精度、线性权重及全库增量/全量一致性。旧第2式测试夹具的日内收益恒定，修正后相关应留空；原实现的非空结果来自浮点尾差，已改为数学期望检查。

全历史覆盖2010-01-04至2026-09-10：新增527个年分区、434,626,541条记录（403,072,081条非空），另重算221个分区。全部748个分区的键唯一性与非有限值检查通过；5只股票共30个实数样本与独立手算一致，重复运行无需新增写入。详细结果见[核对结果](../../artifacts/factors/p2e_20260911/audit.json)。后续运行仍使用`python -m quant.factors.compute --factors all --from 2010-01-01 --to today`。
