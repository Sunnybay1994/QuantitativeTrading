# P2h：Alpha101行业中性化表达式

新增18个行业表达式，因子库共265个定义，Alpha101的101个编号均已登记。2020-12-31全市场4,118只股票与独立Pandas公式对照，74,124个位置的空值一致，最大数值误差7.11e-15。历史面板待前一批54列重算完成后顺序计算。

本批为第48、58、59、63、67、69、70、76、79、80、82、87、89、90、91、93、97、100式。按[原论文附录A](https://arxiv.org/pdf/1601.00991)固定方向+1，非整数窗口向下取整；sector/industry/subindustry分别映射申万一/二/三级。价格用复权价格，VWAP为成交额/成交量乘复权因子，adv为人民币成交额均值，沿用前批口径。

计算入口自动读取[历史行业分类](申万历史行业数据_20260911.md)，按股票和有效日期连接。缺失分类保留空值；常量窗口相关系数无定义时留空。第97式在该抽样日仅3只有效值，独立实现一致，后续由全历史覆盖率和评估电池判断是否可用。

验证：三组公式对照覆盖正常数据、价格缺失、行业缺失与变更，并检查截断未来数据不改变历史结果；包含行业输入的265个定义全量/增量一致、重复运行no-op；定向测试共5项通过，Ruff通过。真实对照在 `artifacts/factors/p2h_20260911/`，包括完整截面、逐因子差异统计和30个抽样值（27个有限值、3个预期空值）。

下一步：计算18列全历史面板，核验306个年分区与30个存储样本，然后接入PIT财务因子。

关键限制：行业分类从2014年开始可用，此前这些行业因子留空。
