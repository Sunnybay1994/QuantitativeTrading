# P8：可打分月度简报

数据、生成与评分入口已接通。真实历史事实与收益的离线整链通过，API调用0次；测试概率明确标为人工fixture，尚无真实DeepSeek月度预测或有效事前成绩。

每期固定三个收益序列、信号日、下一开市日和目标日期。DeepSeek只根据保存的20/60日收益、60日波动率及来源事实生成上涨概率和中文依据，引用必须精确匹配输入键值。无成功输出时保留缺失，不填默认概率。预测对象、日期与数据在请求前固定。

生成晚于下一开市日09:30，或者使用注入测试客户端，均标为演练。记录使用实际生成时间。到期前为pending；到期后按信号日收盘至目标日收盘的含分红收益判定上涨事件，计算Brier与0.5概率基线（单项Brier=0.25）。平收益算未上涨，预测0.5的方向判定为中性。原始预测不覆盖。

数据读取固定2015-01-01归一化起点；更新快照计算已实现收益时，必须复核保存的信号日起点价格，避免不同时段归一化级别直接相除。生成器和评分器只读artifact，data读取器负责实际序列。

## 运行流程

环境沿用Windows原生Python，设置`PYTHONPATH=src`。

```powershell
# 准备固定日期事实；当前三基准完整版本到8月31日。
D:\Miniforge3\python.exe -m quant.data.monthly_brief_inputs prepare --config configs/data/return_benchmarks_q1b_20260912.toml --as-of 2026-08-31 --target-date 2026-09-30 --output artifacts/research/<新输入目录>

# 默认仅保存请求草稿，无预测、无API调用。
D:\Miniforge3\python.exe -m quant.research.monthly_market_brief generate --facts artifacts/research/<输入目录>/facts.json --config configs/research/deepseek_p7_thinking_8192_20260912.toml --output artifacts/research/<新简报目录>

# 到期且数据齐全后；需要新数据版本时显式提供--config。
D:\Miniforge3\python.exe -m quant.data.monthly_brief_inputs realized --inputs artifacts/research/<输入目录> --known-through 2026-09-30 --output artifacts/research/<新收益目录>
D:\Miniforge3\python.exe -m quant.research.monthly_market_brief score --brief artifacts/research/<简报目录> --known-through 2026-09-30 --outcomes artifacts/research/<收益目录>/realized.json --output artifacts/research/<新评分目录>

# 多期累计；每期重复--score，同一信号月份只允许一份评分。
D:\Miniforge3\python.exe -m quant.research.monthly_market_brief summarize --score artifacts/research/<评分目录>/score.json --output artifacts/research/<新汇总目录>
```

真实生成需要额外显式`--execute --max-requests <累计请求上限> --max-usd <累计费用上限>`，复用现有DeepSeek预算缓存；执行前核对定价有效期与全项目月度预算。当前P7批次运行期间不向其缓存插入P8请求，以免挤占固定批次的请求额度。
