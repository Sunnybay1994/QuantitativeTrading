## 格式与口径

- `.lc1/.lc5` 每条 32 字节，小端 `<Hhfffffii>`：压缩日期、日内分钟、
  open/high/low/close、amount、volume、保留字段。日期解码为
  `year=2004+value//2048, month=(value%2048)//100, day=value%100`。
- 日内分钟是 **bar 结束时刻**：`.lc1` 首根 `571` 表示 09:30–09:31，
  `.lc5` 首根 `575` 表示 09:30–09:35；午后从 13:01/13:05 开始，15:00 结束。
- 分钟价格已经是元，volume 是股数，amount 是人民币元；clean 口径为未复权。
- `.day` 每条 32 字节，小端 `<IIIIIfII>`，日期为 YYYYMMDD。股票/指数价格整数
  除以 100，ETF 除以 1000，amount 为人民币元。volume 通常为股数，但成交量超过
  UInt32 容量的记录会以“手”保存；导入器逐行比较成交额隐含均价，对这些记录乘 100。
  本批有 472,485 条源记录采用该换算。

## 存储、读取与重跑

raw 是按源内容哈希保存的不可覆盖版本，clean 与其他供应商隔离：

```text
F:\AI_Coding\QuantitativeTrading\data\raw\tdx_intraday\freq=<1m|5m>\source=tdx\...
F:\AI_Coding\QuantitativeTrading\data\clean\bar_intraday\freq=<1m|5m>\source=tdx\symbol=<代码.市场>\data.parquet
F:\AI_Coding\QuantitativeTrading\data\raw\tdx_daily\source=tdx\...
F:\AI_Coding\QuantitativeTrading\data\clean\bar_1d_tdx\source=tdx\market=<市场>\symbol=<代码.市场>\data.parquet
```

当前分钟 raw 6.612 GiB、clean 5.883 GiB；日线 raw 0.559 GiB、clean 0.540 GiB。
TDX 必须显式选择，不改变 BaoStock 的默认入口：

```python
from quant.data.stock_intraday_repository import read_stock_intraday_bars
from quant.data.tdx_daily_repository import read_tdx_daily_bars

minute_bars = read_stock_intraday_bars(
    data_root,
    symbol="000001.SZ",
    start=start,
    end=end,
    frequency="5m",
    source="tdx",
)
daily_bars = read_tdx_daily_bars(
    data_root,
    symbol="000001.SZ",
    start=start,
    end=end,
)
```
