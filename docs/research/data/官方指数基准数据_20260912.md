全收益序列反映现金分红再投资，普通000xxx序列是价格指数。后缀以实际`index_basic`元数据为准，中证全指价格代码是`.CSI`。[Tushare官方说明](https://tushare.pro/document/1?doc_id=95)明确`close/pre_close`为指数点位、`pct_chg`为百分数。发布表只提供点位及无量纲日收益，不将成交量、成交额作为基准净值。

数据版本：`data/clean/index_benchmarks/csi_price_total_return_20260912/`，`data.parquet`含十条长表序列，`summary.json`含逐序列定义、日期、raw路径和元数据。抓取与校验产物：`artifacts/data/index_benchmarks_20260912/{captures,metadata_paths,validation}.json`；CSI全市场元数据返回8,000行可能受上限影响，本批十个精确代码均在CSI/SSE元数据中找到，未把元数据总表视为完整市场名单。

```python
from pathlib import Path
from quant.data.index_benchmarks import read_index_benchmark

benchmark = read_index_benchmark(

    index_code='H00300.CSI', start=date(2015, 1, 1), end=date(2026, 9, 11),
)
# trade_date, index_level, previous_level, daily_return, return_type等
```

默认只接受`total_return`；价格序列须显式传`required_return_type='price'`。`daily_return[t] = index_level[t] / index_level[上一交易日] - 1`，单位为小数，按日期子集读取时保留边界日的真实日收益；点位单位为指数点、币种CNY。收益代表前收盘至当日收盘，主任务应按实际持股区间选取同期基准。

验证：9项定向测试、Ruff、mypy通过。十条序列均与交易日历逐日一致；所有前收盘值与前一交易日收盘完全相等，供应商涨跌幅与点位计算差异在四位小数百分比舍入范围内；每条首/中/末三个样本raw/clean一致，日收益复合与端点点位比一致。无无法获取的全收益代码。
