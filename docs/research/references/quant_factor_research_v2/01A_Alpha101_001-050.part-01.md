# Alpha101逐因子分析：001–050

## 1. 使用说明

本文件逐条保留论文公式，并给出机制分类、适用股票、有效环境、失效条件和实现注意。**公式后的经济解释是基于表达式结构的研究推断，不是论文作者逐因子提供的解释**；真正方向必须在目标市场、目标股票池和目标执行时点重新验证。

Alpha101论文给出101个实际量化交易公式，主要使用日频开高低收、成交量、VWAP、收益、少量市值和行业分类。论文报告这些Alpha的平均持有期约0.6–6.4日、平均两两相关约15.9%，并指出收益与波动较强相关、与换手没有显著关系。论文明确#42、#48、#53、#54为delay-0，其余通常按delay-1理解。[A1]

### 运算符关键口径

- `rank(x)`：当日横截面排名；因此**股票池改变会改变因子值**。
- `ts_rank(x,d)`：单股票过去d日时序排名。
- `delay(x,d)`：d日前；`delta(x,d)=x_t-x_(t-d)`。
- `correlation/covariance(x,y,d)`：过去d日时序统计。
- `decay_linear(x,d)`：最近值权重最高的线性衰减均值。
- `indneutralize(x,g)`：组内去均值；行业分类必须点时正确。
- 非整数窗口按论文定义向下取整。
- `adv20`等是过去20日平均**美元成交额**，不是成交量。

| 009 | 状态切换 | 当过去5日每日涨跌完全同向时顺势，否则对一日变动取反；把持续趋势和普通噪声区分处理。 |
| 010 | 状态切换 | 与Alpha#9相似但窗口缩短至4日并做截面排序；更强调极短期方向一致性和反转切换。 |

| 012 | 价量联动 | 成交量增减方向与一日价格变动反向相乘；把“放量上涨/缩量下跌”等状态编码为极简价量信号。 |
| 013 | 价量背离 | 收盘价排名与成交量排名的5日协方差取负；对持续的量价共同排序进行拥挤反转。 |
| 014 | 短期反转 | 三日收益变化的截面反转，乘以开盘价—成交量相关；用交易参与结构调节收益反转强度。 |
| 015 | 价量背离 | 高价排名与成交量排名的短窗相关先截面排序、再累加取负；惩罚连续出现的高位放量同步。 |

| 018 | K线与波动 | 五日收盘振幅、当日收开差及开收相关综合后取负；偏向规避高波动且日内结构不稳定的股票。 |
| 019 | 长短动量交互 | 七日价格趋势方向取反，再乘以250日累计收益强度；把短期拐点放在长期趋势背景下判断。 |
| 020 | 跳空反转 | 当日开盘相对昨日高、收、低三点的距离排名相乘并取负；寻找异常跳空后的价格回归。 |
| 021 | 状态切换 | 比较2日、8日均价及8日波动带，并加入成交量相对20日均额条件；是离散化的趋势/均值回归状态机。 |
| 022 | 波动率与价量 | 高价—成交量相关性的5日变化乘以20日价格波动；当量价确认恶化且风险较高时给出更强信号。 |
| 023 | 突破反转 | 当20日平均高价被突破时，对两日高价变化取反；属于高位突破后的短期回吐信号。 |
| 024 | 长周期状态切换 | 当100日均价走势平缓时，使用价格距100日低点的反转；否则使用三日反转，区分盘整与趋势环境。 |
| 025 | 流动性加权反转 | 负收益、20日成交额、VWAP与上影线特征共同排序；把短期反转放在可交易性和日内形态背景下衡量。 |
| 026 | 价量拥挤 | 近5日内高价排名与成交量排名相关性的最大值取负；识别局部最强的高位放量拥挤。 |
| 027 | 二元价量状态 | 对6日成交量—VWAP相关的截面平均排名设阈值，输出二元方向；用于把市场切成高/低拥挤两组。 |
| 028 | 价量与区间位置 | 低价与20日均额的5日相关，加上收盘相对日内中点的位置，再做截面排序；融合流动性确认与K线位置。 |
| 029 | 复合非线性 | 多层排名、最小值、乘积和滞后收益组合；核心仍是短期价格极值与反转，但非线性和离散化程度很高。 |
| 030 | 方向一致性 | 统计近3日上涨/下跌符号一致性并取反，乘以5日/20日成交量比；识别放量下的短期趋势耗竭。 |
| 031 | 复合反转 | 10日价格变动的衰减反转、3日价格反转及低价—20日均额相关符号相加；是多尺度反转合成。 |
| 032 | 长短均值回归 | 7日均价与当前收盘偏差，加上长期VWAP与滞后收盘相关；短期回归由长期价格结构修正。 |
| 033 | 日内动量 | `rank(1-open/close)`，等价于对日内收开收益做单调排序；原式方向偏向收盘强于开盘者。 |
| 034 | 波动压缩反转 | 两日与五日收益波动之比的变化，加上一日收益反转；寻找短波动压缩/扩张后的均值回归。 |
| 035 | 复合价量 | 成交量时序位置、收盘在日内区间的位置和收益时序位置三者相乘；强调“活跃度×K线×短期收益状态”。 |
| 036 | 复合多尺度 | 五个价量子信号加权，包括收开差、滞后量、滞后收益、VWAP—成交额相关和长期均价交互；属于人工集成因子。 |
| 037 | 日内结构延续 | 过去200日滞后收开差与收盘的相关，加上当前收开差；检验日内方向结构是否具有长期稳定性。 |
| 038 | 区间位置反转 | 收盘价的10日时序排名取负，乘以收盘/开盘；寻找近期高位且日内走弱的股票。 |
| 039 | 动量与流动性 | 七日价格变化取反，乘以成交量相对20日均额的衰减排名，再乘以250日动量；是长短趋势与放量的三重交互。 |
| 040 | 波动率与价量 | 10日高价波动排名乘以高价—成交量相关并取负；高波动、高位放量同步时偏向反转。 |
| 041 | 价格几何 | 高低价几何均值与VWAP的差；用日内价格区间的几何中心作为“公允价”代理。 |
| 042 | 延迟0反转 | VWAP与收盘价差的截面排名，除以VWAP与收盘价和的排名；本质是临近收盘对VWAP偏离的逆向交易。 |
| 043 | 放量反转 | 成交量相对20日均额的时序排名，乘以7日价格变化的反向排名；放量越明显、短期涨幅越大，反转暴露越强。 |
| 044 | 价量背离 | 高价与成交量排名的5日相关取负；简洁的高位放量拥挤信号。 |
| 045 | 多尺度相关 | 滞后5日收盘均值、短窗收盘—成交量相关及5日/20日价格聚合相关三者相乘并取负；衡量趋势一致性与量价拥挤。 |
| 046 | 趋势曲率状态 | 比较20→10日与10→当前的平均斜率差；强正曲率输出空头，负曲率输出多头，否则做一日反转。 |
| 047 | 估值代理与形态 | 低价股排名、成交量/20日均额、高价上影结构及VWAP五日变化共同构成；偏向低价高换手股票的形态反转。 |
| 048 | 延迟0序列相关 | 一阶价格变化的250日自相关乘当前变化并按价格归一，再除以长期实现方差，最后做子行业中性；是日内可交易的残差序列… |
| 049 | 趋势曲率状态 | 与#46相同的趋势曲率，但阈值为-0.1；在明显下弯时给多头，否则做一日反转。 |
| 050 | 价量拥挤 | 近5日成交量排名与VWAP排名相关的最大值取负；惩罚最近出现过的最强量价同步。 |

## 3. 逐因子卡片

## Alpha #001

```text
(rank(Ts_ArgMax(SignedPower(((returns < 0) ? stddev(returns, 20) : close), 2.), 5)) - 0.5)
```

| 项目 | 分析 |
|---|---|
| 主类型 | 波动率与极值 |
| 核心逻辑 | 对负收益阶段的20日波动率进行平方放大，再观察其5日极值出现时点；本质是“下行波动冲击是否刚发生”的状态信号。 |
| 更适合的股票/股票池 | 流动性较好、历史长度充足且波动存在横截面差异的股票；中小盘或高波动股票信号更强，但容量更低。 |
| 较可能有效的环境 | 风险偏好切换、过度反应后回归、横截面波动分化明显时。 |
| 主要失效情形 | 单边趋势、波动制度突变、涨跌停连续发生或期权/事件冲击使历史波动失真时。 |
| 实现与回测注意 | 含条件或布尔输出，需检查触发率、并列值比例与阈值附近稳定性。 含幂运算；必须固定负底数、非整数指数、溢出和截断规则。 默认按delay-1使用：当日收盘数据形成信号，下一可交易时点执行。 |
| 方向解释 | 原式输出方向需在目标市场重新定向；本文解释的是公式机制，不把论文中某一历史样本的正负号视为永久规律。 |


## Alpha #002

```text
(-1 * correlation(rank(delta(log(volume), 2)), rank(((close - open) / open)), 6))
```

| 项目 | 分析 |
|---|---|
| 主类型 | 价量背离 |

| 更适合的股票/股票池 | 成交连续、成交量口径稳定、投资者结构多元的股票；中盘和活跃小盘通常更有行为信息。 |
| 较可能有效的环境 | 信息逐步扩散、价格与成交参与不同步、市场并非完全单边时。 |
| 主要失效情形 | 极低流动性、成交量被大宗/回购/指数调仓主导，或全市场一致性行情中。 |
| 实现与回测注意 | 需统一成交量/成交额口径，停牌日和零成交日应显式处理。 含比值结构；应记录分母近零比例并设置与原式兼容的epsilon策略。 默认按delay-1使用：当日收盘数据形成信号，下一可交易时点执行。 |
| 方向解释 | 原式输出方向需在目标市场重新定向；本文解释的是公式机制，不把论文中某一历史样本的正负号视为永久规律。 |
