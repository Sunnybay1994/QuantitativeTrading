# 跨因子库去重、筛选与组合框架

## 1. 覆盖口径

本批材料完整收录：

- Alpha101：101条；
- Qlib Alpha158：158维；
- Qlib Alpha360：360维；
- 核心公开公式合计：619维；
- QIML 2024日历：用户上传扫描版完整解析366条；
- QIML 2026日历：公开可核验具体项2个，另列同源/最新券商候选，**未冒充完整日历**。

“619维”不能理解为619个独立Alpha。Alpha360本身是6条序列的60日展开，Alpha158有多个确定性关系，Alpha101也含代数可化简和同机制复合项。

## 2. 四级去重

| 级别 | 判定 | 是否直接删除 |
|---|---|---|
| L0 完全同式 | 标准化AST和输入口径完全相同 | 是，保留一个canonical id |
| L1 仿射/单调等价 | 排序或z-score后信息相同/反向 | 排序模型通常删；非排序模型审慎 |
| L2 确定性可推导 | 一组输入可无损计算另一项 | 依模型能力、样本量和解释需求 |
| L3 机制相近 | 经济逻辑相同但窗口/门控/归一化不同 | 否；用增量IC和组合贡献判断 |

## 4. QIML 2024与经典三库的去重关系

2024日历新增366个原始条目后，全包原始条目数为985，但当前**不报告“去重后唯一因子数”**。原因是扫描页尚未全部转成可执行AST，且很多关系属于L2可推导或L3同机制，不能只按名称删重。

### 4.1 与Alpha101/158/360的主要关系

| 日历因子簇 | 与经典库关系 | 去重层级与处理 |
|---|---|---|
| ROC、乖离率、随机指标、技术平滑 | 可由Alpha360的60日价格路径计算；与Alpha158 ROC/MA/RSV等高度相关 | 多为L1-L2；线性模型择一，树/序列模型做消融 |
| 日频动量、反转、价格位置 | 与Alpha101短期反转/动量及Alpha158 ROC/CNT/SUM/RSV同机制 | L3；比较残差IC、持仓重合和交易路径 |
| 价量相关均值/波动/趋势/综合 | 与Alpha158 CORR/CORD和Alpha101多条价量相关式同簇，但日历多用分钟数据 | 通常L3，非L0；先对日频量价基准残差化 |
| 已实现波动、跳跃、偏度、峰度、SemiBeta | Alpha158 STD/WVMA和Alpha101波动因子只能提供日频代理，不能直接还原分钟跳跃和条件高阶矩 | 分钟因子通常是新增数据维度；同族内部先去重 |
| 成交量熵、峰值、模糊度、逐笔分布 | Alpha360 volume路径与Alpha158 VSTD等可解释总量/波动，但无法还原逐笔分布 | L2-L3；检验熵/分布相对总量代理的增量 |
| 大中小单、主动买卖、订单失衡、盘口深度 | 经典三库没有逐笔方向和Level-2盘口 | 新数据源；内部大小单/买卖/时段变体高度冗余 |
| 基本面、分析师、专利、新闻、股东、北向、供应链/基金网络 | 经典三库没有相应输入 | 原则上不是公式重复；仍需对规模、行业、流动性和动量残差化 |

### 4.2 日历内部优先合并的因子族

1. `PV_corr_avg / PV_corr_std / PV_corr_trend / PV_corr / CPV`等价量相关变体。
2. 总/上行/下行/大小跳跃/不对称/偏度/峰度/双幂次/三幂次等波动因子。
3. 大单、小单、超大单、主买/主卖、净流入、占比、强度、集中度、开盘后与尾盘变体。
4. Amihud、买/卖单非流动性、价差、深度、冲击、价格时滞和流动性溢价。
5. 新闻数量/共现/点击/情绪、自选股、惊恐、注意力衰减及具象命名的注意力因子。
6. 标准化、异常、残差化、去杠杆、同比/环比和“增长减增长”的基本面改造。

### 4.3 正确的判定顺序

```text
扫描页逐式转写
→ 统一输入字段/频率/复权/窗口/epsilon
→ AST化简与L0/L1判定
→ 冻结样本数值指纹
→ 同机制聚类
→ 对基准因子残差化
→ 比较样本外IC、成本后IR、持仓重合与容量
```

## 5. 自动去重工程

### 4.1 表达式标准化

将因子公式解析为抽象语法树（AST），执行：

1. 大小写、空格、函数别名标准化；
2. 交换律排序：`a+b`、`b+a`统一；
3. 常量折叠：`0.7*x+0.3*x → x`；
4. 公因式和恒等式：`x/x → 1`（同时保留零分母语义标签）；
5. rank语义标签：cross-sectional rank与time-series rank绝不混用；
6. 输入口径指纹：复权、成交量/成交额、时区、行业版本、股票池；
7. 输出canonical hash。

### 4.2 数值指纹

仅靠符号化无法识别所有等价关系。对一个冻结的“指纹样本集”计算：

- 原始值相关；
- 横截面Spearman；
- z-score后最大绝对差；
- 符号一致率；
- 在不同年份/市值域的相关稳定性。

建议阈值不是硬编码真理，可从以下起点开始：

```text
L0候选: max_abs_diff < 1e-10（同口径）
L1候选: |Spearman| > 0.9999 且长期稳定
高冗余簇: |Spearman| > 0.90，但仍需分年份检查
```

### 4.3 经济机制标签

每个因子至少打以下多标签：

```text
horizon, cross_section/time_series, momentum/reversal,
volatility, liquidity, price_volume, intraday_shape,
industry_neutral, nonlinear, binary_gate, long_history,
small_cap_sensitive, execution_delay
```

L3去重应在同机制簇内比较，而不是全库只看相关系数。

## 6. 因子筛选顺序

### 第一步：硬删除

- 常数/近常数；
- 点时不可用；
- 覆盖太低；
- 公式错误或数值爆炸；
- L0重复；
- 明确不可交易的delay-0伪收益。

### 第二步：统计与稳定性

- RankIC、HAC t、分组单调；
- 时间/股票域/市场状态稳定；
- 参数邻域平台；
- 成本与容量。

### 第三步：残差增量

对候选因子`f`相对已有基准`X`做截面回归或非线性残差：

```text
f_resid = f - E[f | X]
```

然后评价`f_resid`的IC和组合贡献。一个原始IC高但残差IC为0的因子，只是在重复已有风格。

### 第四步：组合层选择

单因子最优不等于组合最优。按以下目标选择：

- 预测：最大化样本外IC/RankIC；
- 组合：最大化成本后IR并控制MDD、换手、行业和风格；
- 稳健：最小化权重不稳定和因子暴露漂移；
- 容量：限制股票成交额参与率和拥挤。

## 7. 不同模型的去重策略

| 模型 | L0 | L1 | L2 | L3 |
|---|---|---|---|---|
| OLS/线性打分 | 必删 | 基本必删 | 强烈删/正交 | 聚类选代表 |
| Ridge/Elastic Net | 必删 | 建议删 | 可保留一部分 | 正则化+稳定选择 |
| LightGBM | 必删 | 建议删 | 可保留，但做重要性/消融 | 可保留条件结构 |
| 深度时序 | 删除常数/同列 | 视输入编码 | Alpha360可替代大量工程特征 | 机制差异可保留 |
| Alpha组合/策略流 | 必删 | 反向合并 | 看交易路径是否相同 | 重点看收益相关和持仓重合 |

## 8. 从因子到组合

### 7.1 预测层

推荐分别预测1、5、10、20日的行业/规模中性未来收益，避免用一个标签迫使所有因子服务同一持有期。可用多任务模型共享表示。

### 7.2 风险与中性化层

```text
raw_score
→ winsorize / robust zscore
→ industry + size + beta + liquidity neutralization（按策略目标）
→ score shrinkage by uncertainty/coverage
→ portfolio optimizer
```

不要把所有风格都中性掉后再宣称因子“纯Alpha”；中性化本身是一项投资选择。应报告中性化前后的收益来源。

### 7.3 交易层

对每只股票估计：

- 可成交概率；
- 买卖盘价差；
- 市场冲击；
- 涨跌停/停牌概率；
- ADV参与率；
- 预期信号衰减。

优化目标示例：

```text
maximize  alpha'w - λ_risk w'Σw - λ_turnover |w-w_prev| - impact(w)
subject to industry/style/position/ADV/limit constraints
```

## 9. 因子有效性状态模型

每个因子维护状态条件：

| 状态变量 | 示例 | 用途 |
|---|---|---|
| 市场趋势 | 指数20/60日动量 | 动量/反转切换 |
| 市场波动 | 实现波动、波动分位 | 波动和低风险权重 |
| 流动性 | 全市场成交额、价差 | 高频/小盘容量 |
| 风格拥挤 | 因子多空估值、持仓、相关 | 防止拥挤平仓 |
| 截面分散度 | 收益/因子分散度 | 判断选股机会集 |
| 交易约束 | 涨停家数、停牌、基差 | 可实现性 |

状态模型只能在严格样本外训练；不能看完因子回撤后再事后添加规则并继续沿用同一测试集。

## 10. 建议的首版研究基线

### Baseline-A：可解释树模型

- 股票域：全A剔除ST、上市<120日、近20日成交额过低；
- 特征：Alpha158去常数/确定性冗余 + Alpha101中较简单且非delay-0的因子；
- 模型：LightGBM，按月滚动训练；
- 标签：未来5/10/20日VWAP到VWAP行业规模中性收益；
- 验证：purged walk-forward；
- 组合：行业中性、单票/ADV约束、真实冲击成本。

### Baseline-B：序列模型

- 输入：Alpha360 reshape为`60×6`；
- 额外静态特征：行业、规模、流动性、可交易状态；
- 模型：TCN或小型Transformer；
- 对照：Alpha158 LightGBM；
- 消融：价格块、成交量块、滞后带、可交易掩码。

### Baseline-C：高频日历候选

- 先仅加入量涌波动率和成交量分桶熵；
- 对普通日内波动、20日反转、成交量波动做残差化；
- 评估全A/300/500/1000，月频与周频，成本和参与率；
- 只有残差IC、成本后IR和跨年稳定均通过后再扩展峰岭谷因子族。

## 11. 因子生命周期与退役

```text
idea → verified_formula → research → shadow → production → degraded → retired
```

退役触发可以包括：

- 滚动12个月IC显著低于历史置信区间；
- 成本后收益为负且无法由状态解释；
- 因子与核心库相关升高、增量贡献消失；
- 数据源/交易规则变化使机制失效；
- 容量下降或拥挤度超阈值。

退役不等于删除历史；保留版本、当时假设、失败原因和重新启用条件。
