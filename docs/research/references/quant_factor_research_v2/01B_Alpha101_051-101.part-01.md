# Alpha101逐因子分析：051–101

## 1. 使用说明

本文件逐条保留论文公式，并给出机制分类、适用股票、有效环境、失效条件和实现注意。**公式后的经济解释是基于表达式结构的研究推断，不是论文作者逐因子提供的解释**；真正方向必须在目标市场、目标股票池和目标执行时点重新验证。

Alpha101论文给出101个实际量化交易公式，主要使用日频开高低收、成交量、VWAP、收益、少量市值和行业分类。论文报告这些Alpha的平均持有期约0.6–6.4日、平均两两相关约15.9%，并指出收益与波动较强相关、与换手没有显著关系。论文明确#42、#48、#53、#54为delay-0，其余通常按delay-1理解。[A1]

### 运算符关键口径

- `rank(x)`：当日横截面排名；因此**股票池改变会改变因子值**。
- `ts_rank(x,d)`：单股票过去d日时序排名。
- `delay(x,d)`：d日前；`delta(x,d)=x_t-x_(t-d)`。
- `correlation/covariance(x,y,d)`：过去d日时序统计。
- `decay_linear(x,d)`：最近值权重最高的线性衰减均值。
- `indneutralize(x,g)`：组内去均值；行业分类必须点时正确。
- 非整数窗口按论文定义向下取整。
- `adv20`等是过去20日平均**美元成交额**，不是成交量。

## Alpha #051

```text
(((((delay(close, 20) - delay(close, 10)) / 10) - ((delay(close, 10) - close) / 10)) < (-1 * 0.05)) ? 1 : ((-1 * 1) * (close - delay(close, 1))))
```

| 项目 | 分析 |
|---|---|
| 主类型 | 趋势曲率状态 |
| 核心逻辑 | 与#49同结构但阈值为-0.05；阈值变化使其对趋势拐点更敏感。 |
| 更适合的股票/股票池 | 价格连续、20日窗口内趋势形态清晰的股票。 |
| 较可能有效的环境 | 趋势加速/减速可区分，且阈值附近样本不拥挤时。 |
| 主要失效情形 | 震荡噪声使曲率频繁翻转、跳空或阈值过拟合时。 |
| 实现与回测注意 | 含条件或布尔输出，需检查触发率、并列值比例与阈值附近稳定性。 含比值结构；应记录分母近零比例并设置与原式兼容的epsilon策略。 默认按delay-1使用：当日收盘数据形成信号，下一可交易时点执行。 |
| 方向解释 | 原式输出方向需在目标市场重新定向；本文解释的是公式机制，不把论文中某一历史样本的正负号视为永久规律。 |
