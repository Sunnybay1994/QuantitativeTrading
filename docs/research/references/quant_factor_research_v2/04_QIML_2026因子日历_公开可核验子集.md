# QIML 2026《因子日历》：公开可核验子集

## 1. 结论与边界

QIML（量化投资与机器学习）自2022年推出《因子日历》。公开材料确认2026版日历存在，但**公开网页没有发布完整的2026因子名称、日期页、精确公式和参数清单**；它主要以实体日历及配套资料形式提供。因此，本文件不能诚实地声称“已经收齐2026版全部因子”。[C1]

公开历史信息可用于校准规模：2025版宣传为新增期货因子70+、更新股票因子190+；2023年的QIML教程称其已复现全部日历因子并结合数据提供250+个可计算因子，其中剔除高缺失率后有232个参与机器学习测试。[C2][C3]

本文件按证据等级处理：

| 等级 | 含义 | 本文处理 |
|---|---|---|
| A | QIML官方公开页直接给出因子名/公式 | 可列为日历确定项；当前公开检索未发现完整公式页 |
| B | QIML官方转载确认日历版本或研究框架 | 用于确认产品和测试框架，不推断具体因子 |
| C | 第三方复现文章明确引用“2026因子日历”中的名称/逻辑 | 列为“公开可核验日历子集”，公式仍以原研报/复现为准 |
| D | 最新券商原始研究，逻辑高度相关但未证明收录日历 | 作为扩展候选，不能标成日历因子 |

## 2. QIML公开测试框架的启示

QIML 2023教程披露的示例框架为：中证全指成分股、MAD去极值、行业中位数填充、市值和行业中心化、标准化，月频预测下月收益；测试232个因子，并区分横截面与过去24个月滚动的跨横截面样本。[C3]

这意味着复现日历因子时，必须区分两件事：

- **因子原始公式是否有效**；
- **在特定预处理、月频标签和中证全指股票域下是否有效**。

同一高频因子放到沪深300、全A小盘、周频或不同成本模型，结论可能完全不同。

## 3. 公开可核验的2026日历因子

### 3.1 量涌波动率

**证据等级：C。** 2026年公开复现文章明确称该因子出现在2026《因子日历》，原始研究来自民生证券2025年《日内“动量脉冲”与股价过度反应的精细刻画》。[C4][C5]

#### 概念公式

```text
对每只股票、每个交易日：
1. 剔除开盘前10分钟等高噪声区间（按原研报口径）；
2. 在当前时间段内寻找分钟成交量峰值，以峰值递归二分区间，最多划分6轮；
3. 对每个区段计算区段收益；
4. 计算当日多个区段收益的离散程度/波动率；
5. 对日度指标做标准化，并在约20日窗口上形成稳定性指标。
```

公开描述将其定义为**负向因子**：区段收益越不稳定，说明不同情绪/参与者对价格冲击差异越大，过度反应和未来下行风险越高；稳定性更强的股票未来相对收益更高。

| 维度 | 分析 |
|---|---|
| 类型 | 分钟级价量、日内分段、波动/过度反应、短期反转 |
| 经济逻辑 | 成交量峰值将不同投资者集中交易阶段切开；区段收益离散度代理参与者意见分歧和过度反应 |
| 更适合 | 分钟成交连续、成交量峰值有意义的活跃中小盘；原研报显示小盘域更强的趋势，但容量需另算 |
| 有效环境 | A股日内过度反应显著、短期反转占优、流动性充裕且投资者结构多元 |
| 失效环境 | 单边基本面重估、涨跌停、一字板、成交稀疏、市场微观结构变化、固定费率低估冲击成本 |
| 数据要求 | 1分钟成交量和价格、严格交易时段定义、午休/集合竞价处理、至少20日历史 |
| 去重 | 与普通日内波动、主力波动率存在高相关；需做残差化和增量IC，而不能只看单因子回测 |

**公开复现的增量性警示。** 第三方复现报告称，量涌波动率与普通高频波动率的因子收益相关性超过0.95，因子值的截面Spearman相关约0.76；五组回测中主要是最高因子组显著落后，其余组区分有限。这不能替代独立复现，但足以说明：该因子首先应被视为“波动率的结构化变体”，上线前必须对普通波动率残差化并检查净增量。

### 3.2 成交量分桶熵（标准差）

**证据等级：C。** 公开复现文章称该因子在2024–2026《因子日历》中至少出现两次，源自兴业证券2022年“成交量分布中的Alpha”研究。[C6]

#### 概念公式

```text
对每只股票、每个交易日：
1. 取得全部分钟成交量 v_m；
2. 按成交量数值区间划分约10个等宽桶；
3. p_k = 落入第k桶的分钟数 / 有效分钟总数；
4. H_day = -Σ p_k log(p_k)；
5. factor = Std(H_day, 20日)  # 日历公开逻辑所称“标准差”版本
```

| 维度 | 分析 |
|---|---|
| 类型 | 高频成交量分布、信息熵、稳定性/尾部风险 |
| 经济逻辑 | 日度熵反映分钟量在不同水平上的分散；20日熵波动反映成交量结构是否频繁改变，可能对应知情交易和不稳定性 |
| 原始方向 | 公开日历逻辑为负向：因子越大，成交量不稳定程度变化越大，整体下行风险更高 |
| 更适合 | 分钟成交充分、交易时段完整、量分布非离散退化的股票；中小盘行为信息可能更丰富 |
| 有效环境 | 交易参与结构变化能够领先风险，且量结构不是被动资金单独主导 |
| 失效环境 | 低流动性导致大量0量分钟、不同数据源补零规则不同、指数调仓/大宗交易、桶边界参数过拟合 |
| 复现风险 | 等宽/等频、是否含0、分钟数、标准化方式、20日均值还是标准差都会显著改变结果 |
| 公开复现结论 | 第三方复现认为单调性和增量价值并不强；应将它视为待验证候选而非已确认Alpha |

**参数与结果敏感性。** 公开复现称5桶、10桶、20桶的结果差异不大，20日标准差版本优于均值版本；但其样本中仅2019年的年度绝对IC超过0.06，五组收益主要表现为最高因子组落后、其余组交织。该形态更像尾部风险过滤器，而不是稳定线性排序Alpha。

## 4. 同源原研报因子：高可信候选，但未公开证明收录2026日历

以下因子来自“量涌波动率”的同一民生证券原研报。它们是最新高频研究的重要候选，但当前公开证据不足以逐一标注为2026日历项。

### 4.1 偏锋涨跌幅

- **类型**：日内超额动量/市场广度条件反转。
- **逻辑**：当某时段全市场上涨股票更多时，个股在该时段的超额上涨更可能是拥挤的过度反应，后续约20日发生反转。
- **适合**：横截面宽、分钟价格完整、市场广度分化明显的股票域；中小盘反应可能更强。
- **失效**：结构性牛市、行业共同基本面重估、涨停扩散导致“超额动量”实际不可买卖。
- **去重**：与日内分时收益、市场残差收益、短期反转和Beta中性动量同簇。

### 4.2 动量脉冲

- **构造**：偏锋涨跌幅与量涌波动率等权合成。
- **逻辑**：前者捕捉瞬时超额动量，后者捕捉分段收益稳定性；组合识别日内过度反应。
- **适合**：希望降低单一高频指标噪声的月频选股模型。
- **失效**：两个子因子高度相关或共同暴露小盘/低波/低流动性风格时；合成后必须再做风格归因。

### 4.3 主力波动率、虹吸效应、主买成交特异性

原研报将这些既有高频价量因子与动量脉冲比较，并指出相关性并非都低。它们可作为QIML日历因子去重时的参照簇：

- 主力波动率：交易主导群体造成的价格波动；
- 虹吸效应：资金/成交向局部时段或股票集中；
- 主买成交特异性：主动买入行为相对常态的异常程度。

仅凭名称不足以复现精确公式，需取得原研报或日历页后再入正式因子库。

## 5. “峰、岭、谷”高频成交量因子族：最新扩展候选

**证据等级：D，不标记为QIML日历项。** 开源证券2025年报告按分钟成交量的局域形态，将时点划分为量峰、量岭和量谷，并构建11类20个有效因子。报告解释：量峰是缺乏跟随的孤立大额交易，较像知情交易；量岭是有资金跟随的大额交易，较像个人投资者和情绪交易；量谷是低活跃时点。[C7]

| 因子 | 方向/机制 | 更适合 | 失效风险 |
|---|---|---|---|
| 量峰分钟数 | 正向；知情交易参与频率 | 活跃中小盘，报告显示小盘域更强 | 峰识别阈值漂移、被动大单 |
| 量岭分钟数 | 负向；跟随交易/情绪参与 | 个人交易占比较高股票 | 趋势行情中跟随交易继续有效 |
| 量岭分钟收益 | 负向；情绪交易的价格过度反应 | 高换手股票 | 真信息驱动趋势 |
| 量岭相对加权价格 | 负向；跟随者成交价格过高 | 日内价格区间充分 | 涨跌停、VWAP口径 |
| 量谷加权价格分位点 | 正向；低情绪时点价格更少过度反应 | 中小盘和震荡市 | 量谷样本太少；需反转中性化 |
| 量峰加权价格分位点 | 正向；知情交易成交价格位置 | 信息交易较明显股票 | 峰被异常单笔污染 |
| 量峰间隔峰度 | 正向；知情交易时间聚集结构 | 小盘域可能更强 | 分钟数不足、极端间隔主导 |
| 量峰间隔标准差 | 原报告为负向 | 峰事件频繁股票 | 峰数量少时估计不稳 |
| 量峰间隔偏度 | 原报告为正向 | 峰事件有不对称聚集 | 对单日异常敏感 |
| 量岭间隔标准差 | 原报告为正向 | 跟随交易节奏有信息 | 投资者结构改变 |
| 量岭间隔偏度/峰度 | 跟随交易时间分布高阶矩 | 高频数据完整股票 | 样本量和极端值 |
| 谷岭加权价格比 | 低情绪价格相对跟随交易价格 | 震荡和反转环境 | 分母、状态样本不足 |
| 峰岭加权价格比 | 知情交易价格相对情绪交易价格 | 多元参与者股票 | 状态误分类 |
| 峰岭成交比 | 正向；知情交易相对跟随交易参与 | 中小盘、信息不对称高 | 机构被动交易、容量 |
| 喷发成交额跟随比例 | 衡量大额成交后是否被跟随 | 情绪和追单行为明显 | 交易规则/算法执行变化 |

这类因子最值得做的不是复制报告参数，而是建立统一的**局部状态识别器**，然后系统搜索：分钟数、收益、成交额、加权价格、时间间隔及状态比值。必须用嵌套样本外，避免20个因子和大量阈值共同造成数据窥探。

## 6. 2026年后续研究：价格跳跃峰岭谷

开源证券2026年5月报告把分钟价格跳跃划分为价峰、价岭、价谷，构建11类17个因子。[C8]该报告发布时间晚于2026日历的发布，因此本文**明确不把它算入2026日历**；它更适合作为下一轮候选库。

核心启示：成交量峰岭谷识别“谁在交易、是否有人跟随”，价格跳跃峰岭谷识别“价格是否跳、是否连续、是否留下缺口”。两者可以交叉形成状态矩阵，但维度迅速膨胀，必须预注册组合和严格控制多重检验。

## 7. QIML日历全量补齐所需材料

要达到“完整收集并逐因子去重”的标准，需要以下任一输入：

- 2026实体日历的逐页照片/扫描件；
- QIML随日历提供的Excel/CSV/公式资料；
- 可检索的完整因子目录。

获得材料后，建议抽取以下字段：

```text
calendar_date, factor_name, source_broker, source_report_date,
raw_formula, parameters, frequency, expected_direction,
universe, neutralization, test_period, IC, ICIR,
long_short_return, turnover, public_source, evidence_grade
```

再与Alpha101/158/360执行L0–L3去重。当前文档已为该补齐过程预留相同分类和评估字段。
