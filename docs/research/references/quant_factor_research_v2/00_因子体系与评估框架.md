# 股票量化因子体系与评估框架

## 0. 结论先行

因子不是“一个回测曲线”，而是一个完整对象：**数据定义、经济机制、预测对象、持有期、股票域、预处理、组合映射、成本与失效条件**缺一不可。因子挖掘最常见的失败，不是完全没有相关性，而是把数据泄露、市场风格暴露、微盘流动性溢价、参数筛选和不可成交收益误认为独立Alpha。

建议把因子体系分为三层：

1. **经济与行为层**：价值、质量、投资、成长、动量、反转、波动、流动性、资金流、情绪等，解释收益为什么可能存在。
2. **数据与表达层**：基本面、日频OHLCV、分钟/逐笔、文本、持仓、衍生品、宏观；横截面/时序、线性/非线性、原始序列/人工特征。
3. **投资职能层**：预期收益Alpha、风险暴露、容量/流动性、交易执行、状态过滤。并非所有“有预测力”的变量都应直接作为多空权重。

评估时至少同时看：**点时数据正确性、RankIC及其Newey–West显著性、分组单调性、样本外衰减、跨股票域稳定性、换手与成本后收益、容量、与现有因子的增量贡献、多重检验校正**。Harvey、Liu、Zhu指出，在大规模因子检验背景下，传统t>2门槛过低，新发现因子的统计门槛应显著提高；McLean与Pontiff发现已发表预测变量在样本外和发表后存在明显收益衰减。[R1][R2]

## 1. 因子的三种定义

### 1.1 学术资产定价因子

用于解释共同收益来源，如市场、规模、价值、盈利、投资、动量、低风险。它强调经济解释和长期风险溢价，不一定能直接成为高频交易信号。Fama–French、Jegadeesh–Titman、Novy-Marx、Hou–Xue–Zhang等研究构成了经典脉络。[R7][R8][R9][R10][R11]

### 1.2 业界Alpha信号

任何能够预测未来相对收益、风险调整收益或成交条件的变量。它可以是复杂公式、模型输出、事件概率或目标持仓。Alpha101采用的是这一宽口径定义。[R16]

### 1.3 风险模型因子

用于解释组合共同波动和控制暴露，例如行业、Beta、规模、残差波动、流动性、杠杆。风险因子可能有长期收益，也可能仅用于约束；把它与Alpha混为一谈会导致“收益来自未控制风格”的假象。

## 3. 按构造方式与使用方式划分

### 3.1 横截面因子与时序因子

- **横截面因子**：在同一时点比较股票，典型输出是截面rank或z-score。股票池定义会直接改变数值。
- **时序因子**：比较一只股票当前值与自身历史，典型输出是ts-rank、突破、趋势和波动状态。
- **混合因子**：先时序计算再截面排序，或先截面排名再做时序相关。Alpha101大量使用混合结构。

### 3.2 原始序列与人工特征

- Alpha360属于“固定60日原始归一化序列”，把特征学习交给模型。
- Alpha158属于“人工统计摘要”，对树模型、线性模型更友好。
- Alpha101属于“人工非线性公式”，大量嵌套rank、相关、条件和行业中性。

### 3.3 连续、离散与门控

连续因子便于排序和组合；二元/条件因子适合做状态过滤，但容易出现覆盖率低、并列值多、阈值抖动。任何条件因子都应报告**触发率、分组样本数、触发率随时间漂移**。

### 3.4 因子的五种投资职能

| 职能 | 输出 | 评价重点 |
|---|---|---|
| 预期收益Alpha | 未来相对收益预测 | IC、分组收益、成本后组合 |
| 风险控制 | 风格/行业/尾部暴露 | 风险解释度、暴露稳定性 |
| 容量与流动性 | 可交易规模、冲击成本 | ADV占比、价差、冲击函数 |
| 交易执行 | 成交概率、短期滑点 | 实现短缺、成交率、延迟 |
| 状态过滤 | 何时使用其他因子 | 条件收益、状态持续性、切换成本 |

## 4. 因子研究的正确数据链路

### 4.1 点时正确性

1. 股票池必须使用当时成分，避免幸存者偏差。
2. 财务数据按**实际公告时间**进入，不能按报告期末提前使用。
3. 行业分类、指数成分、自由流通股本、分析师预测均需保存历史版本。
4. 价格复权必须与预测任务一致；OHLC、VWAP、成交量和市值的复权口径要成套。
5. 停牌、涨跌停、ST、上市天数、退市和不可卖出状态必须进入可交易掩码。
6. 分钟/逐笔因子必须使用当时已经结束的bar；收盘因子要区分delay-0和delay-1。

### 4.2 推荐基础表

| 表 | 主键 | 最少字段 |
|---|---|---|
| security_master_pti | instrument, date | 上市/退市、ST、行业、交易状态、板块 |
| daily_bar_adj | instrument, date | O/H/L/C/VWAP、量额、复权因子、涨跌停 |
| intraday_bar | instrument, datetime | OHLC、量额、笔数、主动买卖（若有） |
| fundamentals_pti | instrument, announce_time | 财务项、报告期、公告版本 |
| universe_membership | universe, instrument, date | 当时是否属于股票池 |
| factor_value | factor_id, instrument, asof | 原始值、处理值、版本、可得时间 |
| forward_return | instrument, asof, horizon | 开到开、收到收、VWAP到VWAP等标签 |

## 5. 单因子评估指标

### 5.1 数据质量与可用性

- 覆盖率、缺失率、无穷值比例、分母近零比例。
- 横截面唯一值数、并列值率、零值率、二元触发率。
- 分布：均值、标准差、偏度、峰度、1%/99%分位。
- 时间稳定性：PSI、分位漂移、缺失率漂移、供应商修订率。
- 自相关与半衰期：决定合理调仓频率和换手。

### 5.2 IC体系

对每个交易日或月末，计算因子与未来收益的截面相关：

```text
IC_t     = Corr(factor_t, forward_return_t)
RankIC_t = SpearmanCorr(factor_t, forward_return_t)
ICIR     = mean(IC_t) / std(IC_t)
```

必须同时报告：

- IC均值、中位数、正IC比例、ICIR；
- Newey–West/HAC t值，滞后阶数与持有期匹配；
- 1/5/10/20/60日等多预测期衰减曲线；
- 行业中性、规模中性前后差异；
- 全A、沪深300、中证500、中证1000、创业板/科创板等分域结果；
- 牛/熊/震荡、高/低波动、高/低流动性状态结果。

### 5.3 分组与组合

- 5/10分组收益与单调性；
- 多头、空头、多空各自贡献；
- 分组换手、成交额占比、停牌/涨跌停占比；
- 等权、市值权重、风险平价、优化权重下的稳健性；
- 行业/风格约束前后；
- 毛收益、佣金后、滑点后、冲击成本后。

### 5.4 因子稳定性

| 检验 | 目的 | 合格信号 |
|---|---|---|
| Walk-forward | 模拟真实滚动训练 | 多个样本外窗口方向一致 |
| Purge/Embargo | 防止重叠标签泄露 | 去泄露后仍有效 |
| 参数扰动 | 防止精确窗口过拟合 | 相邻窗口形成平台而非单点尖峰 |
| 股票域迁移 | 检查规模/板块依赖 | 至少明确适用域，而非全域伪稳定 |
| 数据源迁移 | 检查供应商依赖 | 关键结果不因口径小差异消失 |
| 中性化顺序 | 检查预处理依赖 | 结论不由单一预处理步骤制造 |
| 延迟测试 | 检查可交易性 | 滞后1bar/1日后仍有剩余收益 |
| 成本压力 | 检查经济可实现性 | 成本翻倍后仍有正净收益或明确容量边界 |

## 6. 多重检验与“因子动物园”控制

因子挖掘通常同时试验大量公式、窗口、股票池、标签和预处理。只报告最佳结果会严重高估真实收益。

建议记录**研究试验总账**：每次表达式、参数、数据版本和结果都入库，并执行：

1. 提高显著性门槛；不把t≈2视为新因子充分证据。[R1]
2. Benjamini–Hochberg/FDR控制，或White Reality Check/Hansen SPA比较候选策略。[R4]
3. Deflated Sharpe Ratio修正非正态和多次尝试。[R5]
4. Probability of Backtest Overfitting/PBO评估配置选择过拟合。[R6]
5. 设置真正未触碰的最终样本；任何看过结果后的修改都使该区间失去“最终样本外”资格。

## 7. 冗余与增量价值评估

### 7.1 四级去重定义

- **L0 完全同式**：公式在同一输入口径下完全相同。
- **L1 仿射/单调等价**：例如`rank(1-x)`与反向`rank(x)`，排序信息相同。
- **L2 确定性可推导**：原始60日序列可以计算均值、波动、极值；仍可能因模型能力不同而保留。
- **L3 机制近似**：都叫动量/反转，但窗口、条件和股票域不同；不能机械删除。

### 7.2 推荐诊断

- Pearson/Spearman相关、分年份相关和极端状态相关；
- 层次聚类或图社区；
- VIF和条件数（线性模型）；
- 对现有因子做截面残差化后的Partial IC；
- 加入基准模型后的ΔIC、ΔRankIC、Δ净Sharpe、Δ最大回撤；
- SHAP/Permutation重要性稳定性（树模型）；
- 不同训练窗中被选中频率。

## 8. 股票适用性矩阵

| 股票特征 | 更可能适合 | 核心风险 |
|---|---|---|
| 大盘高流动性 | 质量、价值、分析师预期、行业残差、低风险、长周期序列 | 信号弱、拥挤、估值主导 |
| 中盘活跃 | 价量、动量、反转、资金流、事件 | 风格轮动和容量中等 |
| 小盘高换手 | 短期反转、注意力、微观结构、峰岭谷、高频流量 | 冲击成本、涨跌停、壳/退市、纸面Alpha |
| 微盘低流动性 | 某些非流动性和彩票偏好因子 | 几乎所有实盘可实现性问题；应单独建域 |
| 高波动 | 波动、跳跃、尾部、反转、日内结构 | 极端值、成本、风险预算 |
| 低波动 | 质量、低风险、长周期趋势、残差价值 | 低波拥挤、行业集中 |
| 新股/次新 | 事件、短窗价量 | 长窗缺失、IPO机制、涨跌停 |
| 周期股 | 商品/宏观敏感度、库存、盈利修正、价值 | 静态估值在周期顶部误导 |
| 金融股 | 资本充足率、资产质量、利差、分红 | 通用工业财务因子口径不适配 |
| 科技成长 | 预期修正、研发/无形资产、景气、动量 | 传统账面价值失真、久期风险 |

## 9. A股专项约束

1. **涨跌停与T+1**：短期反转和delay-0收益尤其容易不可实现。
2. **停牌与复牌**：长窗统计要区分“交易日窗口”和“自然日窗口”。
3. **ST/退市/壳价值**：微盘和低价因子必须单独剥离。
4. **除权除息**：OHLC、VWAP、成交量、市值要保持一致复权逻辑。
5. **行业中性**：申万/中信分类历史版本不同；金融、地产应考虑专属基本面模型。
6. **北向与融资数据**：制度和披露口径可能变更，需做结构断点检验。
7. **分钟数据午休与集合竞价**：230/240分钟口径、开盘10分钟、尾盘竞价必须明确。
8. **小盘容量**：建议用成交额参与率、冲击模型和涨停无法买入概率联合评估，而非只扣固定费率。

## 10. 因子准入门槛模板

以下不是市场真理，而是一套内部治理起点：

| 维度 | 最低要求示例 |
|---|---|
| 数据 | 点时正确；覆盖率>80%；异常/分母近零可解释 |
| 统计 | 多数样本外窗口方向一致；HAC t值达到内部多重检验门槛 |
| 单调性 | 至少在目标股票域分组可解释；不能只靠一个极端组 |
| 稳健性 | 相邻参数有平台；跨数据源或口径扰动不崩溃 |
| 增量性 | 对现有因子残差后仍有IC或能改善组合风险收益 |
| 成本 | 真实成本后为正；报告容量和可交易掩码 |
| 机制 | 有可证伪逻辑，明确适用股票与失效状态 |
| 生产 | 可版本化、可监控、可回滚，计算延迟满足执行时点 |

## 11. 标准因子卡片

```yaml
factor_id: unique_name_version
hypothesis: 可证伪的经济或行为逻辑
data_asof: 使用哪些点时数据、最晚可得时间
formula: 精确表达式及epsilon/复权/缺失规则
direction: 高值预期收益方向；是否需要动态定向
universe: 股票池、上市天数、ST/停牌/涨跌停规则
preprocess: 去极值、标准化、行业/规模/Beta中性
label: 未来收益起止价格、持有期、是否重叠
metrics: IC、HAC-t、分组、净收益、换手、容量
regimes: 有效/失效环境
redundancy: 与现有因子的L0-L3关系
status: idea / research / shadow / production / retired
```

## 12. 推荐研究流程

```text
经济假设

  → 样本内探索
  → purged walk-forward样本外
  → 多重检验修正
  → 成本/容量压力测试
  → 与现有因子残差化和增量测试
  → 影子盘监控
  → 小规模实盘
  → 漂移监控与退役规则
```

### 13.2 研究含义

- **经典三库主要是价量表达，日历主要扩展数据层。** 财务、分析师、股东、专利、新闻和关系网络通常不是Alpha101/158/360的公式重复。
- **高频条目多但工程门槛最高。** 逐笔方向、盘口重建、订单大小阈值、竞价/午休、微观噪声和冲击成本决定信号是否可实现。
- **同族变体很多。** 价量相关性、已实现波动/跳跃、大小单资金流、流动性、惊恐/注意力和基本面标准化均形成因子簇，必须做残差IC和组合增量测试。
- **扫描解析不替代精确公式复现。** 本包按页码提供构造摘要和机制研究，生产前仍需依据原页和引用研报补齐公式、参数和预处理。
