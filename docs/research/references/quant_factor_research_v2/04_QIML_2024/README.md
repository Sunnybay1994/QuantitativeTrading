## 3. 对因子研究体系的关键补充

### 3.1 2024日历显著扩展了经典三库的数据边界

Alpha101、Alpha158和Alpha360主要围绕日频OHLCV/VWAP及其路径统计。2024日历则大量加入逐笔订单、盘口、分钟高阶矩、分析师、专利、新闻、股东、北向、供应链和基金/券商网络。其最大价值并非再增加一批同类技术指标，而是提供**新的数据视角**。

### 3.2 高频因子占比高，但最容易出现纸面Alpha

订单流、成交分布、价量微观结构和分钟波动类占据主要部分。这些因子的毛IC可能集中在小盘、高换手、高波动股票；T+1、涨跌停、开收盘竞价、盘口分类、算法拆单、手续费和冲击成本会显著改变结论。必须在可交易掩码和真实执行价格上重算。

### 3.3 日历内部存在明显“因子族”冗余

- 价量相关性：均值、标准差、趋势、综合、去反转与合成版本。
- 波动/跳跃：总、上行、下行、大小跳跃、非对称、偏度、峰度、双幂次和三幂次变差。
- 订单流：大/中/小/超大单、买/卖、净流入、强度、占比、集中度、开盘后与尾盘变体。
- 流动性：Amihud、非流动性变异、买/卖单非流动性、价差、深度、冲击、时滞和流动性溢价。
- 注意力/情绪：新闻数量、共现、点击、自选、情绪、惊恐及多个具象命名的注意力因子。
- 基本面：标准化、异常值、同比/环比、残差化、去杠杆和增长减增长等改造。

同族因子不能靠名称去重；应统一公式AST、参数、输入频率与方向，再做数值指纹、残差IC和组合增量检验。

## 4. 建议的落地优先级

1. **第一层：低数据门槛可解释基线。** 先实现日频技术、规模、估值和Point-in-time财务因子，用于核验数据链路和组合框架。
2. **第二层：分钟K线因子。** 实现已实现波动、价量相关、成交分布、日内/隔夜结构；统一230/240分钟、集合竞价和午休口径。
3. **第三层：Level-2订单流。** 只有在逐笔方向、买卖单合并、订单大小阈值和冲击模型稳定后再引入。
4. **第四层：分析师与另类数据。** 先做时间戳和覆盖审计，再评估网络、新闻、专利和关注度的增量。
5. **任何层级都必须先去重。** 对Alpha101/158/360及日历内部同族做L0-L3判定，不能把同一机制的多个变体当成独立证据。
