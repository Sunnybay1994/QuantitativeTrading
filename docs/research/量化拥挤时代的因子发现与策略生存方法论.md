# 量化拥挤时代的因子发现与策略生存方法论

> 状态：持续更新
> 首次冻结：2026-08-15
> 最近更新：2026-08-16
> 适用范围：本项目的 A 股/港股通因子发现、策略研究、前向观察和生命周期治理
> 证据标记：`[事实]` 为论文、监管或数据源直接支持；`[项目规则]` 为结合本项目约束冻结的默认门槛，不冒充学术共识。

## 1. 结论

因子已经极度拥挤时，竞争优势不再是“能生成多少指标”，而是能否经营一个高淘汰率的研究工厂：

```text
少量有机制的假设
→ 完整登记所有尝试
→ PIT/时间语义审计
→ 多重检验与时间顺序验证
→ 成本、容量、拥挤和不可成交否证
→ 冻结 holdout / forward
→ 组合增量与生命周期治理
```

[推断] 个人 A 股量化更现实的结构优势，是容量小、决策链短、能精确处理本地公告时点、报表修订、交易制度和小容量执行；不应与大型机构拼另类数据采购、深度网络参数量或高频速度。

## 2. 一个策略必须同时回答六个问题

1. **经济机制**：收益来自风险补偿、行为偏差、信息迟滞、制度摩擦还是流动性供给？
2. **PIT 数据**：在 `as_of` 时点究竟知道哪个版本，最早何时允许交易？
3. **可执行映射**：信号如何转换为 `target_weight`，如何处理停牌、封板、T+1、整手、成本和容量？
4. **统计证据**：所有尝试是否计入多重检验，是否完成 chronological walk-forward？
5. **组合增量**：加入现有策略库后是否仍贡献净收益、风险分散或成本抵消？
6. **生命周期**：何时冻结、前向、扩容、暂停、降权和退役？

缺少任何一项，只能叫研究信号，不能叫可运行策略。

## 3. 九道研究 Gate

| Gate | 必须产物 | 通过逻辑 | 失败示例 |
|---|---|---|---|
| G0 研究注册 | 机制、方向、期限、宇宙、成本、参数族、试验预算、否证条件 | 在看收益前冻结 | 看结果后补故事或反转方向 |
| G1 数据 | PIT、修订、退市/新股/ST、复权、覆盖审计 | 任意历史时点可重放 | 报告期、最终修订或当前成分回填历史 |
| G2 机制 | 机制特有的截面/期限/状态预测和负对照 | 不只解释收益，还预测何时失效 | 正负对照同样强 |
| G3 简单基线 | 单变量分组、RankIC、长端和 long-short 诊断 | 低自由度、基本单调、不靠少数点 | 只有一个极端组或几只股票有效 |
| G4 统计 | 完整 trial ledger、FDR/DSR/PBO、walk-forward、参数平台 | 多重检验后仍成立 | 只保存冠军回测 |
| G5 实施 | 费用、滑点、冲击、换手、成交率、容量和拥挤压力 | 基准和 2 倍成本仍可行 | 只靠不可交易的微盘/封板收益 |
| G6 增量 | 对本土 size/EP/turnover/市场及现有库残差化 | OOS 净增量存在 | 单独 Sharpe 高但与现有策略同源 |
| G7 冻结前向 | 一次性 holdout 或在线预测日志 | 参数和输入在收益实现前固化 | 修改后继续把同一段称为 OOS |
| G8 生命周期 | 扩缩容、暂停、退役和人工审批 | 证据升级与资金升级分离 | 回测一绿直接进入 PAPER |

## 4. 项目默认统计与稳健性规则

以下是研究治理默认值，不是论文给出的普适常数：

- 发现阶段 `|t| > 3` 只作高门槛初筛；
- 多重检验优先报告 FDR q 值，默认候选要求 `q < 5%`；
- 有足够试验台账时报告 Deflated Sharpe Ratio，默认概率目标 `> 95%`；
- 候选集合足够时报告 PBO，默认目标 `< 10%`；
- 至少 3 个时间顺序 folds，费用后至少 2/3 同号且不能有灾难折；
- 参数邻域、起点扰动、流动性过滤和市值权重切换后不应翻转；
- 基准和 2 倍成本后净收益仍为正；
- 任何门槛不允许替代真正的冻结 forward。

DSR 与 PBO 不能互相替代。DSR 修正多次选择和非正态导致的 Sharpe 膨胀；PBO/CSCV 估计从候选中选出历史赢家后在其他分区退化的概率；二者都不能替代按时间前进的前向验证。

## 5. 自动化否证清单

任何候选都应主动尝试以下反例：

1. 剔除最小市值 30% 后收益是否消失；
2. 从等权改为流通市值权重后是否消失；
3. 使用真实公告时间和历史修订后是否消失；
4. 纳入停牌、封板和次日不可成交后是否消失；
5. 控制中国本土 size、EP、turnover/liquidity 和市场暴露后是否消失；
6. 费用从 1 倍升到 2 倍是否立即变负；
7. 参数热力图是否只有一个针尖最优；
8. 是否一半以上收益来自单一年份、行业或极少数股票；
9. forward RankIC/净收益是否与注册方向相反；
10. 与现有策略是否高相关、同步回撤且边际贡献为零。

通过反例不是“证明真理”，只是降低最常见的自欺概率。

## 6. 更有希望的因子发现路径

### 6.1 从机制原语出发

- **财务信息迟滞**：公告后盈利、现金流和资产负债信息被缓慢吸收；
- **报表内部一致性**：利润—经营现金流、收入—应收、存货—销售、资本开支—未来盈利背离；
- **基本面轨迹**：ROA/ROE、现金转化、杠杆、投资强度的变化和加速度，而非只有水平；
- **价格隐含预期差**：估值与基本面改善/恶化的交互；
- **流动性与需求状态**：换手、Amihud 冲击、量价异常、短期反转/延续与市场波动状态；
- **剩余信息**：对 size、EP、市场、流动性和可用 PIT 行业暴露残差化后再研究；
- **自然实验**：披露、指数纳入或制度变化，但必须事前登记；
- **另类数据**：只有授权、PIT、修订、幸存偏差和供应连续性闭合后才进入。

### 6.2 当前数据可立即研究的第一队列

| 候选 | 机制 | 当前数据 | 首轮角色 |
|---|---|---|---|
| Amihud 非流动性 | 单位成交额价格冲击与流动性补偿/过度交易 | 日线收益、amount | 新候选，月频聚合 |
| 自由流通换手 | 投资者需求、交易拥挤和流动性状态 | daily_basic turnover/free-share proxies | 新候选；水平和异常必须分开 |
| Downside beta | 下跌状态系统风险与防御性需求 | 个股和 510300 日收益 | 新候选；与低波/市场 beta 去冗余 |
| 流通市值 | 中国微盘/壳价值强控制变量 | circ_mv/total_mv | 优先作为控制，不先宣传为 alpha |
| Overnight gap | 隔夜信息吸收 | 昨收与今开 | 候选；严格 next-open 避免自引用 |
| ATR20/IMXD20/RESI20/VSUMD20 | 波动、日内结构和量价状态 | 已有日线 | 次级候选，先过冗余 Gate |

前三个候选被选中，不是因为已知有效，而是因为现有数据足够、机制相对独立、实现自由度低，适合快速证伪。

### 6.3 财务数据完成后的队列

具体执行顺序以 [M2 策略与因子库并行建设路线图](../roadmaps/M2_策略与因子库并行建设路线图.md) 为准：

1. 先完成已预注册的四个 PIT 质量因子单因子基线，不用组合替代首轮证伪；
2. 首轮结束后单独运行 annual asset growth，固定方向和单次 trial，不用组合挽救失败结果；
3. GPOA、盈利改善、SUE/PEAD 等后继候选只有在本地 raw 列、首次信息链和 clean/PIT 契约分别闭合后，
   才能各自预注册并独立检验；
4. 只有组成分量各自通过 validation 与控制实验，才允许另开冻结权重的低维组合 trial；不得在同一测试集上
   事后挑选 ROA/ROE、价值因子或调权形成“价值—质量—保守投资复合”。

`fina_indicator` 只能作为供应商交叉核验，不能替代三张原始报表的 canonical 公式。没有历史 PIT 行业时，不得用当前行业回填历史做“行业中性”。

## 7. 组合与拥挤治理

- 先按经济机制聚类，族内对高度相关信号做稳健平均/收缩，不挑历史 Sharpe 最高者；
- 相同宇宙和频率的信号优先在股票级合成，让相反交易互相抵消；
- 不同期限、不同成交路径的策略在策略级做风险预算；
- 对预期收益和协方差强收缩，目标函数显式包含换手、容量和尾部同步亏损；
- 评价新策略看加入后 OOS 净效用、回撤和成本变化，不只看 standalone Sharpe；
- 每日归因拆成预测收益、市场/因子暴露、约束损失、费用和无法成交损失；
- 拥挤指标进入极端时先管理资本和订单，不自动宣判经济机制死亡。

## 8. Forward 与生命周期

建议状态机：

```text
IDEA → EXPLORATORY → FROZEN_OOS → FORWARD
→ RESEARCH_ONLY → PAPER_CANDIDATE → PAPER
→ LIMITED_LIVE → LIVE / RETIRED
```

每个预测在收益实现前必须固化数据版本、代码版本、参数、候选池、`target_weight` 和成本假设。失败研究进入 graveyard，并继续计入未来多重检验的 trial 数。

### Kill criteria

- **证据立即失效**：PIT 泄漏、幸存偏差、无法重放、成交/账户对账错误、规则错误、授权或 MNPI 问题；
- **暂停新买或降权**：真实滑点越过压力区间、成交率/容量破线、输入覆盖漂移、拥挤极端、制度变化；
- **退役机制**：达到预注册最小 forward 样本后方向错误，关键截面/期限预测失败，或连续两个独立前向窗口没有组合增量。

阈值必须在运行前相对预测分布定义，不能看到亏损后临时挑窗口。

## 9. 当前明确不做

- 数千指标 × 窗口 × 阈值的暴力搜索；
- 依赖逐笔、盘口或延迟优势的 HFT；
- 用深度模型掩盖 PIT、股票池和成交语义缺口；
- 用报告期、最终修订、当前成分或当前行业回填历史；
- 把 long-short 诊断收益直接当个人长多账户收益；
- 押注最小微盘、ST、新股、长期停牌或频繁封板制造的回测；
- 用短样本训练复杂 regime 模型；
- 因历史回测漂亮而自动创建 PAPER 候选。

## 10. 维护约定

新增候选前，先更新机制、负对照、试验预算和与现有库的预期差异；完成研究后记录所有失败变体。新增论文只能改变假设优先级，不能直接把论文历史结果当成 2026 年可交易 alpha。
