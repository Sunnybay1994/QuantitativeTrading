## 1. 假设

> 将第一轮中三折方向一致、横截面 RankIC 较强的 `alpha158_std20`、
> `alpha158_roc20`、`alpha158_rsv20` 按每日横截面等权 rank 合成，并对最终
> Top-50 目标复用既有 60-observation、12% 年化、只降仓不加杠杆的组合波动率
> 控制，可能把排序能力转化为 2x 成本后为正的 long-only 绝对收益。

这是一条新的、可证伪的研究假设，不是对第一轮 run 的补算或覆盖。

## 2. 冻结设计

- 数据 snapshot、2019 流动性 Top-800 冻结股票池、日期范围和三组
  walk-forward 与第一轮完全相同；
- 信号在 `as_of` 收盘形成，最早下一开市日开盘执行；缺失精确开盘不跨日补值；
- 每一 fold 只在 validation 中分别确定三个分量的正负方向；test 只消费该方向；
- 每个交易日先对三个已定向分量分别做横截面 average rank，再固定等权平均；
- test 每 20 sessions 选择 composite Top-50，初始等权；
- 复用 `scale_target_weights_to_volatility`：60 个共同历史收益观测、12% 年化目标、
  252 年化 sessions；只按比例降低全部正权重，现金回报按零处理，禁止加杠杆；
- 成本继续引用 `configs/research/m3_qlib_example.toml` 的历史 A 股费率，执行
  0.5x/1x/2x 压力；法定费用不随 multiplier 缩放；
- 阈值与第一轮相同，不搜索 Top-K、窗口、权重、波动率目标或成本参数。

## 3. 预注册判定

三折串联后同时满足以下条件，才可标为 `RESEARCH_ONLY`：

1. 20-session 平均测试 RankIC 不低于 `0.01`；
2. 至少两折测试 RankIC 为正；
3. composite 方向固定为正且三折一致；
4. 2x 成本串联绝对收益为正。

否则结论为 `REJECTED`。本实验无论结果如何都不生成 `PAPER_CANDIDATE`，不启动
PAPER。

## 4. 选择偏差与失效条件

三个分量是观察第一轮测试结果后选出的，因此本实验不是独立的最终样本外确认。
即使达到上述阈值，也只能说明组合值得进入新的冻结前向窗口；不能把 2022、2024、
2026 测试期再次当成无偏证据。

出现以下任一情况即否证当前版本，不原地调参：

- 2x 成本串联收益不为正；
- 组合 RankIC 主要由单一 fold 驱动；
- 波动率控制因历史不足频繁降为全现金，导致假设实际变成缺失过滤；
- 结果依赖改变任一已冻结窗口、Top-K、组合权重或 12% 风险目标。

## 6. 运行结论

诊断 run `221c1e72fc862ac3d083dee0335471e485aad2eebc2b1ba4e23d7812f131c400`
已不可覆盖发布并重放为 `reused=true`。其机械阈值输出为 `RESEARCH_ONLY`，但
31 个调仓期中 51.6% 因风险历史不足被置为全现金，触发第 4 节预注册失效条件。

进一步只读对照使用未经过日度流动性过滤的同一 clean stock bars，仍有 38.7%
