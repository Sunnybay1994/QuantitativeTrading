# 研究自动化接续

本轮补齐已有因子评估到年度模型的接续、真实 DeepSeek 研究循环，以及已有策略规则的批量入口。沿用原统计、回测与费用口径，历史研究结果不自动提升为模拟盘准入。

## 真实研究循环

```powershell
$env:PYTHONPATH='F:\AI_Coding\QuantitativeTrading\src'
$env:POLARS_MAX_THREADS='4'
D:\Miniforge3\python.exe -m quant.research.run_research_cycle --config configs/research/research_cycle_live_v2_20260913.toml --output artifacts/research/research_cycle_live_20260913_03 --execute --resume --return-benchmark-config configs/data/return_benchmarks_q1b_20260912.toml
```

此处是已有实跑的恢复命令，只有旧进程已退出时使用；新运行使用新目录并去掉 `--resume`。配置限定最多四个候选，共享费用累计上限十九美元，月度总授权仍为三十美元。

首轮诊断和候选生成成功，但建议集中在补充工程工作，未生成合法候选；第二轮出现响应长度与结构不合格。保留两个运行目录，修正诊断提示并将本消费者输出上限提高到四千零九十六 token 后，第三轮四个提议中三个通过本地校验，自动进入因子计算与评估。报告省略的数组不再被解释为项目未做分析，统计淘汰后的成本跳过也不再一概建议补跑。

流水线新增 `report.md`；成功生成但无合法新候选时，按空批次完成，明确跳过评估。费用不足、调用失败、合成样本仍保留停止或失败状态。恢复不会重复成功的 LLM 阶段。

需要在因子评估后继续年度模型时，使用 `configs/research/research_cycle_with_models_20260913.toml`，其中 `[models]` 显式指定模型和收益指数配置；入口会冻结两份配置并直接传给后续流水线。此完整接线有定向测试，当前第三轮实跑使用原不带模型配置，避免中途改变已冻结任务。

## 因子评估接年度模型

`quant.research.follow_factor_models` 接受完整因子批次与显式模型模板，绑定本批统计和成本输入，再调用原年度模型流水线。完整批次逐年重算前缀，不先挑全期赢家。缺失成本或统计时保存具体缺项；测试末日不超过输入已知末日。

实跑 `artifacts/models/genetic_price_liquidity_follow_20260913_03/` 已完成三个 GP 因子在二〇一五至二〇二五共十一个年度的筛选、三模型及回放报告，年度成本输入无缺失，但每年准入后因子均为空，因此预测零行、模型按规则保持空仓，三个模型均为 `RESEARCH_ONLY`。历史候选的适应性搜索限制保留，顶层不自动晋级。

## 已注册策略批量执行

`quant.research.run_strategy_batch` 支持固定白名单中的仓位控制和换手预算两类入口，新任务调用原回测器，完整既有任务核对配置后复用。真实批次 `artifacts/research/strategy_batch_q6_q10_20260913_02/` 汇总 Q6 三规则与 Q10，共四项、二十四条成本记录，零重跑、零失败，原结论全部 `REJECTED`。详情见[使用说明](已注册策略批量运行说明_20260913.md)。

报告提取增加 `--evaluate` 后，可把通过本地校验的非空批次直接送入原评估流水线；两份实际报告保留十一项跳过原因，新增 API 费用合计 $0.0039615。当前共享费用账本快照累计 $18.9033768，仍低于月度 $30。详情见[报告显式DSL提取](报告显式DSL候选提取_20260913.md)。

## 仍需区分的边界

报告提取首版只接受原文已有明确 DSL 公式及方向，缺公式、字段、窗口或方向时跳过；自然语言/数学公式转 DSL 尚未完成。策略批量入口复用固定的仓位控制和换手规则，保留逐项原结论，不能据历史结果自动选优。日更仍由现有 Codex 定时唤醒执行，尚未改为独立系统调度。真实成交成本校准及前向收益继续等待实际数据。
