# 冻结年度预测的回放与报告恢复

年度模型完成预测后，回放或报告中断可以从已有年度账户断点继续，不必重新训练。适用于 `quant.research.run_calendar_annual_model` 产生的目录。

```powershell
$env:PYTHONPATH = 'F:\AI_Coding\QuantitativeTrading\src'
D:\Miniforge3\python.exe -m quant.research.run_calendar_annual_model --config configs/models/q1c_missing_valid_controls_96_20260912.toml --measurement-config configs/data/return_benchmarks_q1b_20260912.toml --output artifacts/models/<已有运行目录> --resume-replay
```

确认原进程已退出后使用原配置和原目录。入口检查保存的实验、测量配置及完整预测文件；回放沿用年度账户恢复，报告使用原模型、测量及压力窗口。已完成运行直接返回原结果。训练尚未完成时明确报错，应使用新目录运行训练。

只需恢复报告时：

```powershell
D:\Miniforge3\python.exe -m quant.reporting.multifactor_models --run artifacts/models/<运行目录>/replay --measurement-config configs/data/return_benchmarks_q1b_20260912.toml --output artifacts/models/<运行目录>/reports --resume
```

报告恢复会重新计算输出表，配置改变要求使用新目录。启用组合约束的报告保存约束配置并注明实际作用的策略名称，Top100等其他场景不能被误写成同样受约束；汇总文件最后写出。

实际演练将修正96月完整运行复制到隔离目录，移除其最终汇总和成本报告模拟中断，再执行恢复。304个已存文件参与核对，年度账户证据及预测保持不变，重建的成本指标和同窗基准比较逐行等于原结果。证据：[恢复验证](../../artifacts/models/q1c_replay_resume_rehearsal_20260912_01/resume_validation.json)。8项定向测试、Ruff和mypy通过，覆盖报告重建和输入变化拒绝。

关键边界：该能力恢复预测完成后的阶段，不接管仍在运行的计算进程。
