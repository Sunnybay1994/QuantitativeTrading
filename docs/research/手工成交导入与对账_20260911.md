# 手工成交导入与对账

`quant.execution.manual_fills`已支持按外部编号导入实际股数、价格和费用，并单列入金、出金、现金分红与费用事件。输出新目录，不覆盖原观察账本。同一编号和内容重复时不记账；同一编号内容冲突、超卖、现金不足或未知旧事件插入均报错。部分成交按实际股数记入，买入股数到下一开市日才可卖。

输入为JSON事件列表，时间未写时区时按上海时间解释。例如：

```json
[
  {"event_id":"REHEARSAL-001","timestamp":"2026-09-10T09:30:00+08:00","kind":"BUY","symbol":"600000.SH","quantity":100,"price":10.0,"fee":5.0},
  {"event_id":"REHEARSAL-CASH-001","timestamp":"2026-09-10T15:00:00+08:00","kind":"DEPOSIT","amount":1000.0}
]
```

成交类型为`BUY`/`SELL`；现金事件为`DEPOSIT`/`WITHDRAWAL`/`DIVIDEND`/`FEE`，现金事件使用正数`amount`；分红另填`symbol`。`fee`非负、默认0。编号使用账户内唯一的券商成交编号或现金流水编号；演练数据使用明确的演练前缀。参考订单只用于价格和股数偏差比较，不能替代实际成交。

```powershell
D:\Miniforge3\python.exe -m quant.execution.manual_fills --state <期初state.json或上次book.json> --events <事件列表.json> --observed <同日现金持仓.json> --reference-orders <原参考orders.csv> --output artifacts/manual_fills/<新目录> --rehearsal
```

`--observed`和`--reference-orders`可选；真实手工记录不加`--rehearsal`。输出`book.json`、`summary.json`和`report.md`。期初快照视为该日收盘，首次新增事件必须更晚；同一批可以部分成交，迟到的更早事件需从更早期初重新合并导入。每个导入结果保留去重记录。

实际验证使用B32已保存的09-10模拟成交，并明确标为演练：48条成交、48只持仓，导入后现金92,166.230407元，与原统一账户的现金及股数完全相同；费用249.09元。重复48条时新增0条，账本不变。相对09-09信号收盘价的净不利成交价差为−1,378.32元，即总体有利；这包含隔夜市场变化，不能直接当作滑点参数。12项定向测试、Ruff及类型检查通过，覆盖部分成交、重复/冲突编号、T+1、费用、分红、出入金与对账差异。

[导入及偏差报告](../../artifacts/manual_fills/rehearsal_20260910_01/report.md)、[重复导入](../../artifacts/manual_fills/rehearsal_20260910_repeat_01/report.md)。

收盘估值已接入`quant.execution.manual_nav`，从上一收盘状态与本期事件开始逐个开市日推进，复用统一账户的分红、送股及登记日权益处理；实际分红到账后才增加现金，未到账仍列应收。缺收盘价只有官方停牌时才允许沿用已知估值。同一已关闭日期、相同事件重复为no-op。

```powershell
D:\Miniforge3\python.exe -m quant.execution.manual_nav --opening <上一收盘state.json> --events <本期事件.json> --to YYYY-MM-DD --observed <同日现金持仓.json> --output artifacts/manual_fills/<新收盘目录> --rehearsal
```

估值时点为上海时间15:00；收盘后现金流水进入下一次估值。无出入金时按相邻收盘权益计算收益；有出入金时，用实际时间权重的日度Modified Dietz近似，分母为期初权益加加权净资金流，分子为期末权益减期初权益再减净资金流。净值连乘每日收益；现金分红和费用属于投资结果，不作为外部资金流剔除。起始纯现金账户可从单位净值1开始，已有持仓必须提供带日期的期初估值。输入`--paper-config`默认复用B32的分红税率口径。

真实演练收盘权益997,535.23元、单位净值0.99753523、日收益−0.2465%；现金、股票市值、应收、权益和单位净值五项均与原统一账户一致。加入一笔明确标记的09:00入金10万元后，名义权益增长9.7535%，调整后收益为−0.2405%，避免将入金误计盈利。48项相关测试通过，包含原PAPER回归、重复关闭、分红到账/未到账、送股限制、停牌估值及资金流；Ruff与三个模块类型检查通过。
