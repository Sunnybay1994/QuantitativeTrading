# 因子评估接续年度多因子模型

已有完整评估目录可以直接接续，不必重复挖掘、统计和成本回放：

```powershell
$env:PYTHONPATH='src'
D:\Miniforge3\python.exe -m quant.research.follow_factor_models --evaluation artifacts/factors/genetic_price_liquidity_20260913_01/evaluation --model-config configs/models/p4_annual_walk_forward_20260911.toml --measurement-config configs/data/return_benchmarks_q1b_20260912.toml --output artifacts/models/<新目录>
```

Python 入口是 `follow_factor_models(evaluation=Path(...), model_config=Path(...), measurement_config=Path(...), output=Path(...), data_root=Path('data'))`。模型模板与收益指数 measurement 必须显式指定。输出目录必须是新目录。

支持 `run_factor_pipeline` 的 `statistics/costs/benchmarks` 和 `run_factor_search` 的 `training/costs/attempt_*/benchmarks`。从统计表读取整批因子，汇集并核验所有完成成本路径，复用按年度保存的成本历史读取器；不会按全期 scorecard 准入名单筛掉“失败”因子。缺统计文件、成本分支或历史末日时，保存具体缺口并停止模型阶段。年度统计、成本筛选、相关性选型、三模型预测、账户回放与报告均复用现有多因子流水线。

每个输出目录保存独立 `model.toml`、原 `model_template.toml` 和 `measurement.toml`。专属模型配置绑定本批统计源、全部已完成 `cost_runs` 与配套基准；测试末日不超过模板末日和统计可知末日，96 个月等模板阈值保持原值。年度准入只使用各次 refit 时可知的前缀。

历史自适应挖掘不能靠年度重算变成未见测试集。因此接续层 `conclusion=RESEARCH_ONLY`、`promotion_allowed=false`，底层模型原判定另保存在 `raw_model_conclusions` 中，供诊断。它不会接入模拟盘或自动交易。

两个搜索入口现在都支持可选的 `--model-config` 与 `--measurement-config` 成对参数；Genetic 入口同时使用 `--evaluate` 或 `--evaluate-only`。不提供这两个参数时原行为不变。自动接续写入搜索目录的 `models` 或下一个 `models_002` 等新目录。已有评估若只想接模型，使用上面的独立入口。
