# 遗传编程因子挖掘

使用 DEAP 进化表达式，沿用现有因子 DSL、已发布因子面板及月度股票池。首版对无量纲价量终端做加减乘和取负，终端仍保留原始滚动窗口语义。安装研究依赖：`D:\Miniforge3\python.exe -m pip install -e ".[research]"`。

一次命令完成搜索、验证选择、冻结测试，追加 `--evaluate` 自动计算冻结候选全历史面板并运行已有因子评估及三档成本回放：

```powershell
$env:PYTHONPATH='F:\AI_Coding\QuantitativeTrading\src'
$env:POLARS_MAX_THREADS='4'
D:\Miniforge3\python.exe -m quant.research.run_genetic_factor_search --config configs/factors/search/genetic_price_liquidity_20260913.toml --output artifacts/factors/genetic_price_liquidity_20260913_01 --evaluate
```

输出目录必须是新目录。搜索完成后若需单独继续评估，使用相同配置与目录，改传 `--evaluate-only`；这不会重新搜索或重看测试以选参。长任务中断后，确认旧进程已停止再恢复。

配置的 `terminals` 来自因子库；对应面板需已由 `quant.factors.compute` 发布。`statistics` 指向已有评估的冻结股票池与月度收益标签，每个年份只提供一份。按当时 `eligible` 股票池取样，保留缺失终端，标签退出日须落在所属时间段内。首批使用 2010—2019 年训练、2020—2022 年验证、2023—2025 年测试。

训练目标是逐月横截面 RankIC 的平均值绝对值减复杂度惩罚，方向只由训练期确定。验证门槛与选择数量写入配置；先保存 `frozen_selection.json`，然后计算测试。`search.json` 保存搜索尝试及随机基线，`validation.json` 保存验证指标，`summary.json` 和 `report.md` 给出冻结候选结果，`library/` 可直接交给现有因子评估入口。

历史自适应搜索结果先标为 `RESEARCH_ONLY`（没有入选则 `REJECTED`）；全历史统计用于诊断，不能当成独立样本证据。达到统一成本要求后仍需前向观察再决定模拟盘使用。
