# P3与年度成本收益指数重评（Q1b，2026-09-12）

复用原NAV与成交，重评原始/中性两版本、0.5/1/2成本。每档从首次正股票市值至报告截止连续计算，保留首日费用和之后现金日；初始现金期另列。基准用510300含分红参考、中证800历史成员月末等权、全市场P3 eligible月末等权，均无整手/账户现金约束。指数首次收益由数据加载器保留，不替换为官方市值加权指数。

唯一基准配置：`configs/data/return_benchmarks_q1b_20260912.toml`。三个入口均接受 `return_benchmark_config=Path(...)` / `--return-benchmark-config`，调用 `quant.data.equal_weight_index.load_return_benchmarks`。旧 `--benchmarks` 目录仅校验成本配置与execution_snapshot，不再读取其账户NAV做收益比较。

```powershell
$env:PYTHONPATH='F:/AI_Coding/QuantitativeTrading/src'
D:/Miniforge3/python.exe -m quant.research.factor_battery_cost_report --run <已有因子cost-run> --return-benchmark-config configs/data/return_benchmarks_q1b_20260912.toml --output <新单因子报告目录>
D:/Miniforge3/python.exe -m quant.research.factor_battery_scorecard --screen <原统计screen> --cost-root <完成cost根目录> --benchmarks <原成本基准目录> --redundancy <相关性目录> --return-benchmark-config configs/data/return_benchmarks_q1b_20260912.toml --output <新scorecard目录>
D:/Miniforge3/python.exe -m quant.research.model_training_costs --prefix <96月年度统计目录> --cost-root <完成cost根目录> --benchmarks <原成本基准目录> --return-benchmark-config configs/data/return_benchmarks_q1b_20260912.toml --output <新年度成本目录>
```

评分表可用 `--previous-scorecard` 复用其中的原cost-run路径，但会重新读NAV/成交，不复用旧成本通过标记。无显式收益指数配置时只报告成本，基准证据缺失，不能准入；`--etf-reference`旧参数不再启用旧账户比较。新目录保存 `return_benchmarks.toml`，`summary.json.measurement` 为 `holding_window_return_indexes_v1`。

每个年度先把NAV和成交截至唯一 `refit_close`，基准加载同样只读到该日，再重新计算首持股日、成本和超额。本轮Q1b真实对照使用96月配置；通用入口复用training_prefix_settings，分别记录final_battery_minimum_months和training_minimum_months，按model配置支持独立48月变体。统计摘要与model的训练门槛不符时拒绝混用。准入数值阈值不改：仍由原统计门槛、全市场等权净超额和相关性条件决定；三成本持仓证据须齐全；P3准入仍只要求1×全市场等权净超额。ETF/中证800为补充对照，缺覆盖明确记comparison_status=unavailable及原因，不新增准入门槛；缺全市场等权不可准入，无持仓直接不能准入。各版本成本独立加载自己的持股窗，禁止取共同交集缩短窗口。

开发验证覆盖首日费用/收益、初始及后续现金、同窗口换手、完整基准网格、无持股、旧通过标记失效、年度未来数据隔离和96/48区分。真实alpha101_010六档校准已完成（artifacts/research/q1b_alpha101_010_calibration_20260912_01）：raw从2010-02-01、neutral从2014-02-07，截止2026-08-31；18项基准比较中15项完整，raw三档ETF因2012才开始覆盖而明确不可比较，中性化9项完整。1×成本后CAGR分别−2.61%/−0.72%。全库重算与年度模型集成由主进程执行。

关键边界：自建指数无报价采用前值并单独标记，尚不能据此判断当日可成交；数据口径与missing_quote_weight见指数产物及数据说明。

年度成本入口支持 `--previous-costs <已完成年度成本目录>`：模型、battery和收益基准配置一致时，复用同一成本产物路径的年度度量，再按当前统计表重新计算准入；新因子或替换路径重新读取NAV/成交。主模型流水线在补齐缺项时自动传入匹配的上次成本目录。旧基准口径不复用。

真实alpha101_010全年前缀测量约7.63秒（含cProfile），复用约1.41秒；三张成本、比较和准入表按列名逐项精确一致，证据在 `artifacts/models/q1b_single_factor_prefix_cached_20260912_02/timing.json`。29项定向测试覆盖复用时不读取原NAV、替换路径必须重算和改变基准拒绝复用。当前已启动的旧进程继续原计算，增量能力适用于后续启动的恢复运行。
