# P2g：Alpha101剩余价量表达式与相关窗口修正

新增15个价量表达式，库共247个定义；83个非行业Alpha101编号已登记，其余18个需要历史行业分类。全历史初次计算完成后，真实样本核对发现第77式有排名差异，修正后正在重算本批15列及受影响的39个旧列。

本批为第75、77、78、81、83–86、88、92、94–96、98、99式，按[原论文附录A](https://arxiv.org/pdf/1601.00991)固定方向+1和向下取整窗口。新增滚动乘积；整数布尔信号在线性衰减前转为浮点数。15式的独立Pandas对照、缺失数据与未来截断检查均通过。

真实数据揭示了短窗边界：兴蓉环境连续三天的复权中间价分别为120.1805425、120.18054250000002、120.1805425，原计算会把浮点尾差当成波动。滚动相关的非空池因此随读入历史长度变化，造成第77式排名差异。常量窗口判断现沿用排名的10位有效数字口径，相关留空、协方差为0；真正有相对变化的极小信号仍保留。

46项相关测试通过。修正后第77式2020-12-31全市场两组排名与独立计算零差异：中间价/VWAP衰减项4,043个有效值，相关衰减项3,961个。完整重算及918个分区审计完成后再记录最终有效行数。

下一步：完成54列重算，复核30个真实样本与全库重复运行；再计算18个行业表达式。[行业数据](申万历史行业数据_20260911.md)已经发布。

关键限制：本批仍在重算，旧缓存不能据此用于最终scorecard。
