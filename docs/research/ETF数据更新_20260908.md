# ETF 总回报价格更新（2026-09-08）

11 只 ETF 全部更新至 2026-09-08；新增 42 个交易日、462 行，总计 9,823 行。
原有序列截至 2026-07-10，新增区间来自 Tushare，沿用现金分红再投资口径。

## 运行

```powershell
$env:PYTHONPATH = "F:\AI_Coding\QuantitativeTrading\src"
D:\Miniforge3\python.exe -m quant.data.refresh_etf_prices --end 2026-09-08
```

证券池读取 `configs/research/m2_s2_volatility_target.toml`。依照本地沪深日历检查完整性，
抓取旧末日之前 45 个自然日起的行情与分红，全部验证通过后仅追加新日期。
再次执行同一命令返回 `new_rows=0`、`no-op`。

总回报公式：`TR[t] = TR[t-1] × (close[t] + cash_dividend[t]) / close[t-1]`。
`fund_div.div_cash` 单位为每份人民币元，按实施事件的除息日计入；相同日期与金额的重复记录
只计一次，冲突金额报错。[字段来源：Tushare](https://tushare.pro/document/2?doc_id=120)。

## 核对

- 用重叠区间首日的一次比例缩放延续旧序列尺度；2026-05-26 至 07-10 每只 33 个交易日、
  共 363 个观测逐日核对，最大相对误差 **8.881784197001252e-16 < 1e-6**。
- 新区间与沪深开市日逐日匹配：11 只各 42 行，缺失与重复均为 0。
- 新区间包含 510500.SH 于 2026-07-15 的每份 0.149 元分红，按上述公式计入。
- 抽样：510300.SH 的 09-07 / 09-08 收盘为 4.634 / 4.624；总回报价格为
  5.040795225730375 / 5.029917376732251，两者日收益比值误差 < 1e-12。
- 5 项定向测试通过（含去重分红手算、接缝偏离拒绝和原重建器测试）；Ruff 与 mypy 通过。
