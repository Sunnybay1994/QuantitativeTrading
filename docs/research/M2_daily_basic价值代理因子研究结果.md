## 2. 冻结协议

- `as_of` 为信号日收盘后；最早在下一交易日开盘执行；
- 标签和成交价格只来自 verified bar snapshot，绝不使用 `daily_basic.close`；
- 三折 walk-forward，测试期分别为 2022、2024、2026-01-01 至 2026-08-13；
- 1/5/20 日标签，20-session 非重叠 Top-50 诊断组合；
- 使用配置 SSOT 的 A 股费用并报告 0.5x/1x/2x 压力；
- 方向在 validation 冻结，test 只读；相关性阈值为 0.80；
- 四个假设一次性共同运行，不按测试结果修改窗口、方向、Top-K 或阈值。

## 4. 为什么两个通过项仍不是策略候选

BP 的三个 1x 测试折收益依次为 `-5.14% / +24.88% / -7.73%`；股息率依次为
`-7.08% / +30.68% / -1.04%`。两者均由第二折主导总收益，2/3 折的绝对组合收益为负。

20-session 五分组中，最高组减最低组的测试折平均收益为：

- BP：`+1.20% / -0.26% / +1.82%`；
- 股息率：`+1.32% / -0.99% / +0.67%`。

因此，横截面 RankIC 的方向比 Top-50 组合收益稳定，但极端分组和绝对收益具有明显时期依赖。当前还没有
行业中性、历史 ST、完整历史证券池、基准超额归因或统一市场事件回放；`daily_basic` 比率也是供应商日频
代理，不是按公告修订链重建的财务 PIT。`RESEARCH_ONLY` 只表示值得进入独立的价值—质量验证，不表示
已经形成可部署策略。

## 5. 后续动作

1. 不在同一 test 上组合 BP 与股息率，也不修改阈值追求更高收益；
2. 按既定顺序采集利润表、资产负债表、现金流量表和财务指标，构建真实 PIT 修订链；
3. 首批只验证 TTM ROE、TTM ROA、现金利润质量和总应计，并报告与 BP、股息率的增量信息；
4. 若基本面质量无法改善跨折稳定性，诚实保留本轮因子级结论，不晋级 PAPER；
5. 即使后续基本面结果为正，仍需历史证券池/市场事件闭包和冻结后前向证据，才可另行申请 PAPER 准入。
