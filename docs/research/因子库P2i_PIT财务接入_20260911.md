# P2i：PIT财务因子接入

财务质量四项已接通日频计算接口，2020-04-27至05-08的7个交易日、3,821只股票，共26,747行真实样本与逐日财报重选结果一致。完整PIT批次登记和2010起面板仍待完成。

接口沿用已有ROE TTM、ROA TTM、现金利润质量和总应计项公式。`quant.factors.compute` 遇到 `family="pit_quality"` 时读取 `configs/data/refresh.toml` 的 `financial_snapshot`，目前指向 `b7_halfyear_20260909`；由 `quant.data` 读取三表，原PIT选择器处理公告日期、修订冲突和季度链，公式由既有实现计算。进入选择器前按该族原有字段投影，避免其他指标的字段差异造成误隔离；对应重复修订测试通过。

每段日期先计算全部候选股票，后续仅在新公告可知时重新计算受影响股票，再连接回日频面板。公告当日仍按原口径不可用；新的无效或冲突分数覆盖旧分数，缺失行情日留空。真实基准中，股票计算次数从26,747降至6,974，耗时从3.92秒降至1.65秒；接入正式读取器后的样本耗时2.00秒。

样本有效值：ROE 23,440、ROA 23,560、现金利润质量19,683、总应计项23,280。产物为 `artifacts/pit_quality_actual_sample_20260911.parquet`。两项财务定向测试覆盖公告时点、冲突修订、行情缺失、未来截断及全量/增量一致与no-op；既有15项表达式测试、2项面板测试通过，Ruff和mypy通过。

下一步：按现有实现各自的最少历史长度接入其余财务指标，年报指标保留18个月有效期，季度ROE稳定性保留6个月有效期；随后统一登记并计算全历史。

关键限制：该样本验证计算口径和接入，因子有效性由后续全历史评估电池判断。
