# P2i：PIT财务30项接入

已登记30项财务因子，本批使库达到295个定义。2020-04-27至05-08的7个交易日、3,821只股票、26,747行样本完成核验：27项迁入指标与原有逐日计算一致，新增3项通过105个独立手算对照。整库57项定向测试通过，Ruff与mypy通过；财务全历史面板计算中。

批次包括TTM盈利/现金流质量、毛利率、资产增长、流动比率、杠杆、盈利与营收增长/加速、SUE、年度现金盈利、盈利组件及组合、季度ROE稳定性、年度Z-score、债务/EBITDA和F-score。新增净利率、资产周转率、现金流/负债三项的公式、方向与无效值规则，事先固定在 `configs/factors/pit_financial_expansion_20260911.toml`；全部定义位于 `configs/factors/library/pit_*.toml`。

流水线从表达式识别财务输入，按公告更新受影响股票，再连接到日频面板。原选择器保留严格滞后公告、季度链和修订冲突规则；每个因子族只使用其原有字段识别冲突。年度现金盈利保持独立字段范围，不能直接用综合盈利评分中的现金组件替代。无效新分数覆盖旧分数，缺失行情日留空。

年度指标逐日检查18个月有效期，季度ROE稳定性检查6个月；现金流收益率和Z-score使用当日市值；年度盈利组合用当日完整可观察股票截面重新排名。F-score也在澄清公告可知时更新。上述边界及全量/增量一致、重复运行no-op均有定向测试。

数据由 `configs/data/refresh.toml` 指定：财务四表 `b7_halfyear_20260909`，股本事件 `20260910_cycle2013`，配合已捕获的澄清公告。真实样本计算耗时22.31秒；产物为 `artifacts/pit_all_thirty_sample_20260911.parquet` 和同名JSON。

30项2010起全历史计算已启动；完成后核验510个年分区及真实样本，然后继续分钟低频化和既有因子迁入。

关键限制：F-score样本仅1,178个有效股票日，受股本历史与九项同时完整的要求限制；其可用性由全历史评估电池判断。
