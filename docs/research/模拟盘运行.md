
交易日历中的前向首日为 **2026-10-08**。9 月 30 日收盘后运行会生成首次订单参考；10 月 8 日收盘后运行会记录模拟成交与净值。此前正式账户只有初始化文件，`nav.csv` 为空，不把历史演练当作前向记录。

## 文件与成交口径

`artifacts/paper/<date>/`：`positions.csv` 当前数量与盯市价、`nav.csv` 累计净值、`fills.csv` 当日模拟成交、`rejections.csv` 拒单、`targets.csv` 下一开市日目标、`orders.csv` / `orders.md` 人工订单参考、`state.json` 续跑账户。重复运行同一天为 no-op，漏跑多个交易日会顺序补记。

执行复用 `simulate_daily_targets`：下一开市日不复权开盘价加滑点、100 股整手、先卖后买、现金约束，股票费用仍由统一核心管理。一天一个目标批次，先卖完旧持仓再买入，故新买入的份额不能在当天卖出。除息日前一开市日须为登记日；除息日按旧持仓确认应收分红，到达支付日后才转为可用现金。

模拟盘使用 Tushare 专用 [`etf_limit`](https://tushare.pro/document/2?doc_id=491) 的实际涨跌停价格；开盘触及限制或滑点将越过限制时拒绝对应方向。零成交量不成交、缺行情或缺价格限制时报错。日线开盘价解释为当天第一个可成交报价。一键刷新同步维护 `data/clean/etf_limit/data.parquet`，从 2026-07-10 起增量更新，raw 请求保存在 `data/raw/tushare/etf_limit/`。此前 `stk_limit` 空响应属于股票接口探测，ETF 使用专用接口。

## 人工开关

```powershell
# 停止模拟成交，继续盯市；设置会持续保存
D:\Miniforge3\python.exe -m quant.execution.paper_ledger --halt
# 恢复
D:\Miniforge3\python.exe -m quant.execution.paper_ledger --no-halt
# 仅允许卖出；恢复买卖用 --no-sell-only
D:\Miniforge3\python.exe -m quant.execution.paper_ledger --sell-only
```

开关保存在账户目录的 `controls.json`。同一天切换会更新待执行订单，不重做已经记账的成交。订单参考使用信号日收盘价，开市后须按实际价格、可用现金和交易状态复核。
