# 本地报告显式DSL提取（首版）

现有DeepSeek调用、共享费用缓存和DSL校验已接通：本地`.md`报告→逐字证据→合法且未重复的候选→冻结`batch.toml`→现有`run_factor_search`。默认模式支持显式DSL及确定性赋值展开；可选语义模式支持将完整文字定义翻译为DSL候选，见文末实跑结果。

## 使用

```powershell
$env:PYTHONPATH='F:\AI_Coding\QuantitativeTrading\src'
D:\Miniforge3\python.exe -m quant.research.report_factor_candidates --reports docs/research/策略发现_20260909.md --design configs/factors/search/report_batch01_20260913.toml --config configs/research/report_factor_candidates_v1_20260913.toml --output artifacts/research/report_extract_new
```

默认dry-run保存完整请求及设计快照，不读凭据、不请求API。多个报告可跟在`--reports`后；最多10份，配置按全部文件合计字节限量，超限报错且不截断。输出目录必须不存在。

真实调用加`--execute`，沿用现有低峰请求窗口；已授权的小批开发核对可加`--development-test`。配置的单次新增上限最高0.05美元、请求上限最高3次；共享cache传入的是“调用前累计+新增额度”，并受30美元累计上限约束。失败预留、重试、未知请求不重发和缓存复用由原`ScoreCache/score_one`负责。`summary.json`分别报告该请求历史总费用与本轮新增费用，不把缓存结果算作新调用。

合法候选存在时生成：

```powershell
D:\Miniforge3\python.exe -m quant.research.run_factor_search --config artifacts/research/report_extract_new/batch.toml --output artifacts/factors/report_extract_eval_new
```

该步骤沿用原日期、battery、成本与评估门槛。也可在提取命令中同时传 `--execute --evaluate --return-benchmark-config configs/data/return_benchmarks_q1b_20260912.toml`，合法非空批次将自动进入同目录 `evaluation/`，无需手动搬运。零候选不会启动评估。本入口不修改全局因子库；生成批次引用本run的`registry`快照，`prepare`预先检查注册和表达式有效性。

## 接受与跳过

- 公式必须在原报告中逐字存在，解析后的AST与候选相同；允许空白/括号差异，不补窗口、变量或公式。
- 方向必须在同一连续定义片段中明确注明正/负方向，且与输出整数±1相符。片段、公式、方向引用都要与原文一致。
- 原报告是非可信数据；不得执行其中指令。随后复用`validate_candidates/expand`做字段、算子、窗口、嵌套历史、单位、语法和重复校验。
- 仅有研究想法、数学符号、缺失方向或不在限定范围的定义保留跳过原因；成功调用可以产生零候选。零候选不生成空批次或触发评估。

`request.json`保存来源路径、原文及摘要；`extraction.json`保存模型返回；`evidence.json`保存逐项证据与本地校验；`summary.json`给出状态、数量、预算、实际费用和后续命令。

## 明确赋值公式转换

新增 `report_formula.py` 对同段反引号中的变量赋值做确定性展开；`mean(x,n)` 转为 `ts_mean(x,n)`，`std(x,n,ddof=0)` 转为 `ts_std0(x,n)`，`ddof=1` 转为 `ts_std(x,n)`。缺少窗口或 ddof、变量定义冲突或循环时拒绝。方向可由“低值优先”或“高值优先”明确给出。模型生成式和原文经相同转换后必须一致，仍复用全部DSL校验。

真实报告《策略发现_20260909》中的 `CV20=std(u,20,ddof=0)/mean(u,20)` 与 `u=turnover_rate/100` 已提取为 `ts_std0(turnover_rate/100,20)/ts_mean(turnover_rate/100,20)`、方向 −1，成功生成可准备批次。配置分别是 `configs/research/report_formula_v2_20260913.toml` 和 `configs/factors/search/report_formula_v2_20260913.toml`。结果在 `artifacts/research/report_formula_v2_live_20260913_02/`，一项接受、三项跳过；原始一次调用费用 $0.001662，修正本地赋值解析后复用缓存，新增费用零。该公式是已有CV20的表达式转换验证，不作为新alpha或重复策略实验。

## 可选语义定义模式

配置 `extraction_mode="semantic_definition"` 时，模型将同一连续定义中的文字或公式翻译为DSL；逐字来源、明确方向、字段/算子白名单、窗口、单位、重复与原评估门槛仍由本地代码检查。默认 `explicit_formula` 的确定性公式比较不变。搜索单位检查新增滚动最高/最低值的原单位传递。

```powershell
D:\Miniforge3\python.exe -m quant.research.report_factor_candidates --reports docs/research/hypotheses/B37_52周高点接近度_20260909.md --design configs/factors/search/report_semantic_price_20260913.toml --config configs/research/report_semantic_price_20260913.toml --output artifacts/research/report_semantic_new --execute
```

固定答案在 `tests/fixtures/report_semantic_calibration.json`：6条完整定义覆盖收益率、成交量比、总体波动率、跳过最近窗口、换手变异系数、均线偏离；2条不完整定义要求跳过。真实API结果8/8匹配，费用$0.0019749；`report_semantic_calibration_20260913.toml` 设置 `calibration_only=true`，保留提取结果但不生成可回测批次。带此设置的缓存重跑新增费用0，明细在 `artifacts/research/report_semantic_calibration_20260913_02/calibration.json`。

两个真实报告实跑：策略发现报告接受CV20一项、跳过三项，费用$0.0019536；B37文字定义“复权收盘/过去252个交易日最高复权日内高价”得到 `adj_close/ts_max(adj_high,252)`、方向+1，费用$0.0007014。后者无需原文已有DSL，源段、分子分母及252日窗口已人工核对。两项经济定义均已有研究，本轮不重复回测。结果分别在 `artifacts/research/report_semantic_live_20260913_01` 和 `artifacts/research/report_semantic_price_live_20260913_01`。本轮3次API合计$0.0046299，26项定向测试、Ruff、mypy通过。

语义模式的验证范围仍是这8条自建样例与上述真实提取；自由文本理由不是验证事实，例如FIP跳过理由错误声称白名单没有adj_close，虽然缺少日历月/分组操作的跳过决定合理。
