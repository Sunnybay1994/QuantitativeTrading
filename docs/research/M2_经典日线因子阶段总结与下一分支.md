# M2 经典日线因子阶段总结与下一研究分支

日期：2026-08-15

## 1. 已完成证据

当前阶段已将上传调研中的代表性日线价量机制转成不可覆盖、可重放实验：

- 第一批六因子全部 `REJECTED`；
- 三因子 + 510300 风险控制为探索性 `RESEARCH_ONLY`，但需独立前向观察；
- MA20/CORR20/WVMA20 第二批全部 `REJECTED`；
- 五因子 LightGBM 平均 test RankIC 约 0.0229，但 2x 串联 -17.99%，`REJECTED`；
- BETA20/RSQR20/CORD20/SUMD20 第三批全部 `REJECTED`。

这些否证表明框架已经能区分统计排序、成本后收益、市场暴露与跨期稳定性，而不是为了得到
正结果无限调参。当前唯一保留候选仍是已冻结的 510300 三因子前向观察合同，尚非
`PAPER_CANDIDATE`。

## 2. 停止规则

同一 2022/2024/2026 test 已用于多轮探索，从现在起停止：

- 增加相同机制的 5/10/30/60 日窗口；
- 依据已见 test 选择 CORD/RSQR 或重新训练 LightGBM；
- 调 Top-K、持有期、波动目标、成本门槛以改善历史结果。

后续价量研究只可使用冻结前向样本或新的、明确隔离的数据窗口。

## 3. 下一独立分支：PIT 基本面价值—质量

下一分支不从既有 test 挑公式，先只读审计共享 raw/clean 数据是否能支持：

1. `daily_basic` 的估值、流通市值和换手率历史；
2. `fina_indicator` 及财务表的 `ann_date/f_ann_date/end_date/update_flag` 修订链；
3. 严格 `as_of` 公告可知、下一开市日执行的 PIT 快照；
4. 价值、盈利质量和稳健杠杆三个预注册机制；
5. 与价量候选分开的 walk-forward 与成本压力。

若公告时点、修订或历史覆盖无法闭合，该分支应在数据审计阶段停止，不得用最新财务值回填历史。
