# 2026-09-09 策略发现：四个可执行的新假设

目标与时间盒：1 小时内从论文和量化专业论坛找到增量假设，冻结一个可用现有数据验证的配置。已对照研究议程、排行榜和因子源码；下列四项均无同公式的本地 run。优先 B25 换手稳定性，其次分钟下行风险分解。

| 假设、方向与本地执行公式 | 原始来源与样本核验 | 字段、成本与区别 |
|---|---|---|
| **B25 换手稳定性**：`CV20=std(u,20,ddof=0)/mean(u,20)`，`u=turnover_rate/100`；低值优先，月末 Top50 等权，次日开盘。 | [Chordia–Subrahmanyam–Anshuman 2001，机构摘要](https://research.iimb.ac.in/fac_pubs/1268/)、[原文出版页](https://www.sciencedirect.com/science/article/pii/S0304405X00000805)：NYSE/AMEX，1966–1995，换手/成交额变异与预期收益负相关。[Barinov 作者稿 §2](https://faculty.ucr.edu/~abarinov/Turnover%20Variability%20(JBF%20R3).pdf)核实 CV 定义，其扩展样本为 1966–2010、过去 36 个月月度值。 | [Tushare 官方 daily_basic](https://tushare.pro/document/2?doc_id=32) 的 `turnover_rate` 分母为无限售流通股数，clean 同名。**20 日是本地短窗适配**，原论文也非本地净收益证据。它测离散程度，与已有换手均值、异常换手比、`std(abs(ret)*volume)/mean(...)` 不同；必须测这些近邻的冗余。 |
| **连续信息动量 FIP**：先按 12 个月形成期收益 `PRET` 取前 20%，跳过最近 1 月；再按 `ID=sign(PRET)*(N_negative-N_positive)/N_valid` 取最低 50 只，月调仓。零收益计入分母，停牌缺失不补零。对照同样动量池、同持股数的纯动量组合。 | [Da–Gurun–Warachka 2014 作者正式稿，式1与表2](https://academicweb.nd.edu/~zda/Frog.pdf)：CRSP 美国股票，主检验 1927–2007；原文双重排序、跳过一月、持有六个月。低 ID 是在给定形成期收益后更连续的信息，不能独立解读成低 ID 股票必涨。 | `bar_1d.close * adj_factor` 计算日收益；需至少 13 个月历史，现有日线可满足。与 B23 的港股 20 日动量、B4 ETF 12−1 不同，唯一新增变量为动量赢家内部的 ID 排序；A 股月频是本地适配，原文多空价差不直接移植。 |
| **PIT 存货扩张**：`(inventories_q-inventories_q-4)/((total_assets_q+total_assets_q-4)/2)`，低值优先，非金融股月度 Top50；相同季末同比避免季节性。 | [Thomas–Zhang 作者稿，附录与表1](https://www3.ntu.edu.sg/home/HuaiZhang/inventory%20paper-RAST.pdf)：NYSE/AMEX 1970–1997、39,315 公司年；原定义年度存货变动/平均资产，研究后续股票收益，低增量方向较好。 | `balancesheet.inventories,total_assets,end_date,ann_date,f_ann_date`；对两个报告期分别使用 `available_date < signal_date` 当时已知版本，排冲突修订与非正资产。需先查存货字段覆盖；不同于 B7 总应计和 B18 总资产增长，季度同比/月度持仓为本地适配。 |
| **分钟下行半方差占比**：同日相邻 5m 收盘对数收益 `r`，`RS-=sum(r²*1[r<0])`、`RV=sum(r²)`，`D20=mean(RS-/RV,20日)`。在既有月度选股分数不变时，将权重乘 `1-D20` 后归一，检验回撤是否改善。 | [Patton–Sheppard 2015 作者正式稿，§II–III](https://public.econ.duke.edu/~ap172/Patton_Sheppard_REStat_2015.pdf)：105 只美股及 SPDR，1997-06-23 至 2008-07-31；原文平均约 5 分钟的事件时间采样，预测未来波动率。 | BaoStock clean 的 `symbol,trade_date,bar_start,close`（bar 收盘在 `bar_start+5m`），沿用 B8 每日量额/收盘核对；缺 bar、跨午休收益及 `RV=0` 日排除，20 个完整日才有效。固定钟表 5m 是适配；论文支持风险预测，不提供低 D20 的收益方向，故先做权重风险实验而非宣称 alpha。 |

发现线索来自 [QuantConnect 专业论坛 Reversal Fakeout Alpha](https://www.quantconnect.com/forum/discussion/7527/reversal-fakeout-alpha/p0)：它介绍连续信息筛选与短期反转混合做法，促使本次回溯 FIP 原文；这里只保留 ID 一个变化，不采用帖内 ADX/周频/多空组合或回测数字。其余假设直接从作者论文及其参考文献发现。

中文论坛补查：[聚宽“行业因子研究—动量与换手率”](https://www.joinquant.com/community/post/detailMobile?page=2&postId=41011)讨论先行业动量再低换手标准差；[果仁“换手率相对波动率”](https://guorn.com/forum/post/p.1837854.288529839017061)展示一个常见命名陷阱：名称叫“相对波动率”，给出的公式却只有标准差。B25 以论文的 `std/mean` 为准，两个帖子仅提供研究线索，收益数字不纳入证据。

四项均先走 A 股日频 T+1 路线：收盘信号、下一开市日开盘、整手/停牌/涨跌停限制，统一 `daily_account`；沿用现有佣金 0.025%、最低 5 元、卖出印花税 0.05%、过户费 0.001%、单边滑点 0.1%，逐项报 0.5×/1×/2× 成本。论文未给出适用于本项目的上述净成本结果。分钟项先低频化，不依赖盘中手工追单。
