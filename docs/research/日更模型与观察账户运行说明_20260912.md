# 日更模型与观察账户

一条命令按同一已完成交易日运行：日更数据及固定模型预测、B20、B32、B32月度报告。预测保持 RESEARCH_ONLY，不传给账户；账户沿用冻结规则和既有 halt/sell_only，auto_trade=false。无券商、微信发送或付费LLM调用。

在项目根目录 PowerShell 运行（每次 output 使用新目录）：

```powershell
$env:PYTHONPATH='F:/AI_Coding/QuantitativeTrading/src'
D:/Miniforge3/python.exe -m quant.research.run_daily_observation --output artifacts/research/daily_observation_<日期与序号>
```

默认配置 `configs/research/daily_observation_v1.toml` 指向现有修正版固定模型 selection、B20/B32配置及正式账户目录。默认 to=today，按上海时间已完成交易日解析；盘中不会使用当日未完成行情。模型正式观察自 selection 冻结的 forward_start 开始，之前必须显式 --rehearsal。

使用主进程已准备的截至9月10日账户副本，推进9月11日（仅命令示例，本次开发没有运行这些副本）：

```powershell
D:/Miniforge3/python.exe -m quant.research.run_daily_observation --to 2026-09-11 --saved-data --rehearsal --account-root artifacts/research/daily_observation_rehearsal_20260912_01/accounts --b20-output artifacts/research/daily_observation_rehearsal_20260912_01/accounts/b20 --b32-output artifacts/research/daily_observation_rehearsal_20260912_01/accounts/b32 --output artifacts/research/daily_observation_rehearsal_20260912_01/record_01
```

--account-root 默认映射其下 b20、b32 子目录；也可用上面的两个显式覆盖参数。演练强制目录在 account-root 内、互不嵌套且与正式账户不重合。程序不复制或重建账户；B32空目录必须先由既有入口在冻结 initial_signal_date 初始化。saved-data 不刷新日历/行情/B20专用ETF快照，输入须事先准备好；账户输入仍由各原有入口检查。

失败处理：B20独立运行，正常模式自行刷新专用ETF快照。B32仅在日更刷新成功或 saved-data 模式运行；模型特征缺失不阻塞它。B20失败不阻塞B32；B32未完成则跳过月报。月报检查两个账户最新快照恰为目标日期，旧日期/未来日期不算成功。任何异常、缺失输入、日期不一致或跳过组件均使 summary.status=incomplete、CLI退出码非零；日历失败也写summary.json。失败时已完成的账户快照保留，修复后用新output重跑，原入口处理已存在日快照。

产物：output/summary.json 汇总请求日、实际交易日、演练标识、各阶段状态/错误与账户目录；output/model 存刷新及预测；output/monthly 存当日月度报告。saved-data 的refresh状态表示使用已有输入，不声称重新执行全量质量检查。报告中的部分月份保留原有覆盖说明。

验证：15项mock定向测试覆盖失败独立性、日期新鲜度、路径隔离与不覆盖控制参数；真实saved-data账户对照验收由主进程运行。
