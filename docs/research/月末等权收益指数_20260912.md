# 月末等权收益指数（2026-09-12）

已发布两条按日复合的浮点权重收益指数，各覆盖 **2010-02-01—2026-08-31，4,026 个交易日、199 次月度调仓**。用于 P3 成本/年度评价与模型报告的同期股票基准。

## 数据与选股

构建配置：`configs/data/equal_weight_indexes_20260912.toml`；读取配置：`configs/data/return_benchmarks_q1b_20260912.toml`。产物位于 `data/clean/equal_weight_indexes/battery_monthly_gross_20260912/`，包含日序列、两份月度名单、估值事件和摘要；已有版本拒绝覆盖。

复用 `battery_statistics_20260831_20260911` 已保存的 P3 eligible 股票池、配置指定的日线快照、`factor_battery_20260911_v2` 公司行动/退市/停牌数据及 `csi800_20260911` 历史成分。全市场指数取信号日 eligible；中证800指数再与截至信号日最新历史成分取交集（缺失或超过40天的成分版本报错）。没有用当前成分回填历史。

冻结 eligible 已含上市天数、历史 ST/名称状态、当日成交及涨跌停、成交额流动性过滤；本次直接复用，不重新筛选。月末收盘确定名单，下一交易日开盘设为 1/N，月内权重随收益漂移。首个有效信号为2010-01-29，故不构造2010年1月指数收益。

## 收益与估值口径

- 初始开盘点位1000；调仓日旧组合先赚隔夜收益，再按开盘价重置新组合，赚取日内收益。普通交易日按前收盘到本收盘复合；首日为开盘到收盘收益。
- 分红和送转在除权日计入税前总收益，公告日期必须不晚于当天。普通日现金按本股收盘价再投资，调仓日计入开盘重配资金；这是理论收益指数，不采用到账日或股份上市日的账户权益回放。
- 明确停牌与缺失/零成交报价均沿用最近估值，除权日按现金与送转理论调整；事件分别记为 `suspended_last_mark`、`missing_quote_last_mark`。退市生效日按零回收处理并扣减组合价值。
- 使用浮点权重，不施加整手、现金账户、费用或滑点约束；调仓时的停牌估值同样是理论指数估值。

## 接口

```python
from datetime import date
from pathlib import Path
from quant.data.equal_weight_index import load_return_benchmarks

series = load_return_benchmarks(
    config=Path("configs/data/return_benchmarks_q1b_20260912.toml"),
    data_root=Path("data"), start=date(2010, 2, 1), end=date(2026, 8, 31),
    names=["csi800_equal_weight", "all_market_equal_weight"],
)
```

`names=None` 默认返回 `510300`、`csi800_equal_weight`、`all_market_equal_weight` 三条；指定子集只加载该子集。每条仅含 `date, unit_nav`，以请求首日前隐含净值1重定基，**保留请求首日收益**。单日窗口可用；逐条核对完整交易日，不静默缩短区间。ETF成立前窗口需由消费者明确记录不可比较。底层 `read_equal_weight_index` 另保留绝对点位、日收益及诊断列，其 `unit_nav=index_level/1000` 不作区间重定基。

组合约束可调用同模块`read_equal_weight_targets(*, data_root, version, index_name, as_of_dates)`读取保存的月末目标；`quant.data.factor_battery_inputs.read_frozen_battery_universe(*, statistics, as_of_dates)`读取同日股票池及行业、市值、amount20。两者缺任何请求日期或出现重复键均报错，保留股票池的eligible标记和缺失控制，不补当前行业。当前目标最后信号为2026-07-31；2026-08-31的下一执行日已超版本结束，不提供替代目标。
