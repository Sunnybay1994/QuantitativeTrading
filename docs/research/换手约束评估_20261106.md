# 换手约束：讨论稿

用户提出：若成本后超额优秀，是否允许更高换手，或采用加权打分。本稿只讨论下一版规则；当前路线图§1.2、既有注册结论及安全不变量保持原样。

推荐保留数据真实、无前视、可成交、现金与风险底线，再对可行策略排序。净超额采用统一悲观成本口径，结合跨年稳定性和执行误差；换手作为成本模型误差及操作负担的软约束，不再天然等于策略价值。已在净收益扣掉的费用与滑点不应重复罚分。

加权总分可以辅助排序，但不能用高收益抵消不可能成交、前视或突破风险底线。暂不任意指定权重；若实施，应统一预注册评分方向、归一化与权重，并检查合理权重变化下排序是否稳定，不能只对当前优胜策略选择有利参数。也可先按保守净超额排序、以风险和执行负担打破近似并列，减少任意权重。

现有结果的三档成本、共同窗口对照、压力窗及来源SHA由脚本提取，见[机器评估](../../artifacts/research/turnover_policy_review_20261106_01/report.md)及同目录`review.json`、`generate.py`。这些属于已见历史开发样本；日线触价成交率仍是模型值，两倍成本不是全部冲击与排队误差的上界。讨论不构成新增样本外证据或准入。

方法参考：[Novy-Marx与Velikov原论文](https://www.nber.org/papers/w20721)研究成本后的策略收益，并比较买入与继续持有采用不同门槛等成本控制方法。美国样本不能直接导出本项目的通用换手上限。
