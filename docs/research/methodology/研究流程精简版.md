# 研究流程精简版（一个假设 ≤ 1 天）

> 取代旧的"任务书 → 派发 → 实现 → 交付报告 → 独立初验 → 返工 → 合流 → 治理记录"流程。
> 一个假设的全部产物只有三样：**一个 config、一个 run 目录、一页结论**。

## 0. 先分清两条轨道（2026-09-10 起）

| 轨道 | 对象 | 流程 | 产物 |
|---|---|---|---|
| **因子轨道** | 任何单个因子/表达式/文本信号 | **不写假设卡**。登记一行 TOML 到 `configs/factors/library/`，由因子评估流水线批量出 scorecard，阈值一次写死在 `configs/factors/battery.toml` | scorecard 里的一行；Agent 每批写一页"诊断"（这批针对什么缺口、结果说明了什么） |
| **假设轨道**（本文余下部分） | 模型、策略、组合规则、执行规则、风险预算等**策略级**命题 | 下面的五步 | config + run + 一页结论 |

分不清时问一句：这个命题的对象是"某个信号有没有预测力"（→ 因子轨道），还是"怎样把信号变成钱"（→ 假设轨道）。
设计见 [因子挖掘流水线_设计与分工](../factors/因子挖掘流水线_设计与分工.md)。

## 1. 什么算一个假设

一句话能说清的、可反驳的、只改一个变量的**策略级**命题。例如：

- "在 S2 月度趋势策略上加 12% 波动率目标，能在两折都降低最大回撤且保持正收益。"
- "把 ADMITTED 因子从等权 z-score 改为滚动 12 个月 IC 加权，2015–2026 全历史 1× 成本后 Sharpe 提高且换手不升。"
- "Top50 组合加规模中性约束后，对全市场等权的超额仍为正且最大回撤下降。"

反例（属于因子轨道，不写假设卡）："Alpha101 第 26 式在 Top800 中 RankIC ≥ 0.03"、"CV20 加 Top75 缓冲的配对增量"。

写不成一句话的，拆成几个。

## 2. 五步

| 步 | 做什么 | 产物 | 时间 |
|---|---|---|---|
| ① 预注册 | 复制最近的相似 config，改 `hypothesis_id`、`hypothesis`、一个变量，写死通过条件（`[admission]` 或 `hypothesis` 里写清） | `configs/research/<id>.toml` | 15 分钟 |
| ② 实现 | 如需新因子/新策略逻辑，写在 `src/quant/factors/` 或 `src/quant/strategies/`，配一个小 fixture 单测（手算 3–5 个值对得上即可） | 代码 + 1 个测试 | ≤ 3 小时 |
| ③ 运行 | 用既有 runner 跑；出错就修 runner，不另建 runner | `artifacts/research/runs/<run_id>/` | ≤ 2 小时（后台跑，期间做别的） |
| ④ 结论 | 一页 Markdown（模板见 §3），三种结论之一 | `docs/research/hypotheses/<id>.md` | 20 分钟 |
| ⑤ 登记 | 路线图 §4 追加一行；`git commit` | — | 5 分钟 |

超过 1 天没跑出数字：把当前状态写进结论页的"未完成"一节，标 `RESEARCH_ONLY`，换下一个假设。
不允许无限期"待授权/待 receipt/待合流"。

## 4. 判定规则

- 通过条件在 ① 写死，看到 test 结果后不改。没通过就是 `REJECTED`，把原因记下来。
- 通过预注册条件但缺真正的前向样本 → `RESEARCH_ONLY`；等数据自然增加后重跑一次即可升级。
- 通过预注册条件且满足路线图 §1.2 的候选规则 → `PAPER_CANDIDATE`，直接进模拟盘，不再有别的 Gate。
- 想翻案一个 `REJECTED`：必须是新的假设（改变了什么），起新 id，不原地重跑。

## 5. 方法底线（不多，但一条不能破）

- 信号用收盘后可知数据，最早下一开市日开盘成交；财务数据按公告日。
- **统计功效**：因子判定只用全历史（≥ 96 个月）IC 序列的 Newey–West t、ICIR、年度符号一致率；模型判定用 2015 起逐年 walk-forward。
  ≤ 3 年窗口上 Top-K 组合的收益差只做描述，不做判定。同时报 510300 / 中证 800 等权 / 全市场等权三个基准。
- 分钟级：信号用**该 bar 收盘后**可知数据；Yahoo 时间戳是 bar 开始时间，别拿它当可知时刻。分钟低频化因子聚合成日频后按日频规则走。
  日内策略成交价报三档：下一根 bar 开盘 + 1 tick（乐观）、延迟 1 分钟（基准）、延迟 3 分钟 + 2× 滑点（悲观），悲观档为正才晋级；
  A 股 ETF 滑点按 1 个最小变动价位（0.001 元），港股通按往返 ≈ 0.4% 显性成本；日内策略折切分按月而不是按年；报日均笔数。
- 参数只在 validation 折选择，test 折只看一次。
- 跨牛熊（用户2026-09-10要求）：训练段和测试段各覆盖至少一轮牛熊，以基准实际走势核实，分别报告各市场状态的样本数。历史股票池必须在相应研究期前确定并保留退市记录；禁止拿2019年选出的名单回测2015年。固定规则策略如不拟合参数，应称“训练段诊断”，不虚称重新训练。
- 在看新增结果前固定极端窗口，同时报告最差单日/连续五日、最大回撤及恢复时间、跌停/停牌拒单，并给出跨年不重置资金的连续净值。历史已看区间仍属于复验；分钟等数据不足以覆盖周期时只做探索研究，不据短期结果晋级。
- 报 0.5×/1×/2× 成本；换手要报。
- 因子研究报 RankIC 均值、各折符号、分组单调性、Top-K 成本后收益，另加与已有因子的秩相关（> 0.8 视为冗余）。
- 策略研究报成本后 CAGR、Sharpe、最大回撤、换手、相对 510300 / S0 等权的超额。
- 与基线用同一回测器、同一费用配置、同一折切分。

## 6. 不需要的东西

任务书、交付报告、独立初验、返工报告、状态机、锁、lease、receipt、manifest、fresh verifier、
双平台复跑、冷导入证明、SHA 台账、"待批示"条目、`IMPLEMENTATION0 / TRIAL0 / STOP` 之类标签。
以上任何一项出现在新文件里都视为流程倒退。
