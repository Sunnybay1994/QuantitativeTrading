# 年度模型冻结研究前向入口

已完成的 `run_calendar_annual_model` 产物可以直接导出为固定研究预测版本。入口复制实际年度 LightGBM、年度 fit、model/battery 配置，保存因子顺序与方向、缺失编码、规模/行业控制有效性、参数、统计来源及源研究结论。`selection_rule=explicit_saved_annual_fit_no_method_selection` 表示沿用指定模型；导出结论固定为 `RESEARCH_ONLY`，源模型原有 `REJECTED` 等结论单独保留。

## 运行

在项目根目录设置 `PYTHONPATH=F:/AI_Coding/QuantitativeTrading/src`，使用 Windows Miniforge：

```powershell
D:/Miniforge3/python.exe -m quant.research.export_annual_forecast --run artifacts/models/q1d_causal48_calendar_missing_20260912_01 --output artifacts/models/<新的冻结目录> --forward-start 2026-09-14

# 本地数据核对；历史日期必须显式 --rehearsal。
D:/Miniforge3/python.exe -m quant.research.run_fixed_model_forecast --selection artifacts/models/<新的冻结目录> --as-of 2026-09-11 --output artifacts/models/<新的日更目录> --rehearsal

# 前向运行时也可使用原有日更入口；去掉 --saved-data 即按原配置刷新。
D:/Miniforge3/python.exe -m quant.research.run_daily_model_forecast --selection artifacts/models/<新的冻结目录> --to today --output artifacts/models/<新的日更目录> --saved-data
```

导出要求源 run 的训练、回放及报告汇总已完成且相互一致；缺少模型文件、年度预测行数不符、训练历史不足或标签越过 refit_close 均拒绝。冻结日期为实际导出日期；`forward_start` 必须晚于冻结日期及历史测试结束日期，并且该年度已有模型。跨年需要重新导出已完成的新年度 fit。原默认 selection 和观察账户配置保持原值。

导出可用 `--refresh-config` 指定已确认的本地质量配置，默认 `configs/data/refresh.toml`。对这种导出，`run_fixed_model_forecast` CLI 自动走 `run_daily_model_forecast(saved_data=True)`：先检查完整配置范围的实际输入质量与模型因子同日覆盖，成功后才写 `forecast/features.parquet`、`forecast/predictions.parquet`。日更将同次质量结果传给预测，不重复运行健康统计；失败返回非零，原因保存在日更 `summary.json` 和 `input_quality/`。底层 `run_forecast` API 同样要求同日成功的质量结果。
