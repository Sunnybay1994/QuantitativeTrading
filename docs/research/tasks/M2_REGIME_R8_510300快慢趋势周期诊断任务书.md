## 4. exact 状态合同

### 4.1 数据、月末与可知时点

- regime symbol exact：`510300.SH`；
- adjustment method exact：`TOTAL_RETURN_DIVIDEND`；
- signal timing：完整共同自然月末 close 后；
- state application：只标记该 signal date 对应的下一 canonical monthly holding interval；
- execution/return interval：必须直接复用目标 source run 的 signal date、next-common-open execution 和下一
  rebalance/terminal exit identity；不得自行构造不同持有期。

canonical month-end 必须是已经结束自然月中 SH、SZ 同时开市日期集合的最后一天。禁止用 bars union、单市场
月末、自然月最后日、月内最后价格、未完成月份、上一交易日或后续修订冒充共同月末。calendar/price缺失、
重复、乱序、日期漂移或无下一合法holding interval均fail-closed。

对状态月 `s` 必须具有 `s-12..s` 的 exact13 个连续自然月共同月末 close；任一中间月缺失、重复、错误symbol、
null、bool、NaN、Inf、零或负价格时该状态为 `NOT_AVAILABLE`，且未来source holding return不得静默丢弃。

### 4.2 FAST exact定义

```text
fast_return_1m(s) = close(s) / close(s-1) - 1
FAST_POSITIVE if fast_return_1m(s) > 0
FAST_NONPOSITIVE if fast_return_1m(s) <= 0
```

exact zero归 `NONPOSITIVE`。不得使用盘中价格、日频窗口、当前未完成月、绝对值或结果后阈值。

### 4.3 SLOW exact定义

先对最近12个完整月逐月计算：

```text
monthly_return(k) = close(k) / close(k-1) - 1
for k = s-11, ..., s

slow_mean_12m(s) = arithmetic_mean(monthly_return(s-11), ..., monthly_return(s))
SLOW_POSITIVE if slow_mean_12m(s) > 0
SLOW_NONPOSITIVE if slow_mean_12m(s) <= 0
```

唯一允许的是12个简单月收益的等权算术均值：

- 不得替换成 `close(s)/close(s-12)-1` 几何累计收益；
- 不得替换成12月价格SMA、指数移动平均、回归斜率或多数月份投票；
- 不得按波动率、成交量或月份长度加权；
- exact zero归 `NONPOSITIVE`；
- 必须使用全部12个月，缺失时不缩短窗口、不填值、不删除月份。

FAST月收益是上述12个SLOW输入中的最后一个月；这一本身会产生机械相关，未来报告必须披露，不能把 FAST 与
SLOW 当成独立信号或两个独立trial。

### 4.4 exact4 状态与顺序

状态顺序、映射和名称固定为：

```text
1. BULL       = FAST_POSITIVE    and SLOW_POSITIVE
2. CORRECTION = FAST_NONPOSITIVE and SLOW_POSITIVE
3. BEAR       = FAST_NONPOSITIVE and SLOW_NONPOSITIVE
4. REBOUND    = FAST_POSITIVE    and SLOW_NONPOSITIVE
```

四个状态必须全部出现在配置、identity、输出和报告中，即使某状态计数为零。禁止将 `CORRECTION` 与 `BEAR`、
`REBOUND` 与 `BULL` 合并，也不得因中文解释或结果修改英文token。

state在 `as_of=s` close后才可知，只能标记该source run下一holding interval。禁止用holding-period return、下一月
close、source策略是否盈利、terminal availability或后来状态定义当前状态。

## 6. 状态样本、episode 与统计口径

### 6.1 coverage与状态行

每个 `(run_id, fold, state)` 至少输出：

- `n_periods`、`state_share`、`episode_count`；
- `status` exact `EVALUATED / INSUFFICIENT / NOT_AVAILABLE`；
- `return_contribution`、`mean_monthly_net_return`、`annualized_volatility`、`sharpe_zero_rf`；
- downside deviation、Sortino、p05、expected shortfall 5%、worst monthly return；
- mean invested weight、mean cash weight；
- source明确提供时的gross/one-way turnover与cost；否则字段保持null并说明不可推断；
- HAC mean、standard error、95% CI与t-stat；
- episode worst drawdown、episode return median、episode duration median。

四状态 `n_periods`之和必须exact等于该run/fold完整合法holding grid；`state_share`按固定状态顺序使用稳定求和
闭合为1。四状态log return contribution必须与无条件fold log return在未来任务书冻结的exact容差内守恒。

### 6.2 minimum evidence

- `n_periods < 12` 或 `episode_count < 2`：status=`INSUFFICIENT`；
- `n_periods == 0`：status=`NOT_AVAILABLE`；
- 只有 `n_periods >= 12` 且 `episode_count >= 2` 才可计算Sharpe/HAC并标`EVALUATED`；
- 短样本仍保留count/share/contribution及可直接计算描述量，不得年化后冒充稳定证据；
- zero variance、nonfinite或分母为零时相应指标null并保留状态，不得填0或极大数。

12个月与2个episode是本诊断的报告下限，不是promotion阈值；即使满足也不能产生状态赢家或交易授权。

### 6.3 年化与尾部

- monthly annualization periods exact `12`；
- volatility使用sample standard deviation `ddof=1 * sqrt(12)`；
- risk-free exact `0`；
- Sortino MAR exact `0`；对状态内全部合法月收益定义 `x_t = r_t - 0`，正收益月份不得从分母样本中删除；
- `downside_deviation_annualized = sqrt(12 * mean(min(x_t, 0)^2))`。这里的mean使用该状态全部合法月份，
  正收益贡献exact `0`；禁止只在负收益月份上计算、禁止`ddof=1`、禁止使用负收益子样本的标准差；
- `annualized_mean_return = 12 * mean(x_t)`，分子同样使用该状态全部合法月份；
- `sortino = annualized_mean_return / downside_deviation_annualized`，仅当分子、分母finite且分母严格`>0`时计算；
  分母为0或任一输入非finite时Sortino为null，并保留明确的denominator/input状态，禁止填0、无穷大或极大数；
- tail quantile exact `0.05`；
- expected shortfall只对不高于finite empirical p05的月份等权平均；
- 所有均值、标准差、分位数与尾部计算前要求输入finite，不winsorize、填0或drop非法行。

下行风险最小对抗例固定为月收益 `[+0.10, -0.01, +0.10, -0.01]`：

- 分母平方均值必须为 `(0 + 0.0001 + 0 + 0.0001) / 4 = 0.00005`；
- `downside_deviation_annualized = sqrt(12 * 0.00005) = sqrt(0.0006)`；
- `annualized_mean_return = 12 * ((0.10 - 0.01 + 0.10 - 0.01) / 4) = 0.54`；
- `sortino = 0.54 / sqrt(0.0006)`。

若实现只保留两个负收益月，则会得到不同分母，必须由测试拒绝；不得用四舍五入后的近似数替代上述exact算式
作为合同identity。

### 6.4 HAC exact方向

HAC只估计条件月均收益的不确定性，必须保留原fold完整连续holding grid和state indicator；禁止把某状态的离散
月份压缩成伪相邻序列。未来实现重冻的唯一候选为：

- Newey-West/Bartlett；
- lag exact `3`；
- two-sided 95% z exact `1.959963984540054`；
- influence序列在完整grid上定义，非目标状态贡献为0；
- LRV非有限或小于0时fail-closed，不取abs、不截零、不换estimator。

lag=3必须进入diagnostic identity；它不是可搜索参数。HAC只作不确定性报告，不是promotion Gate。

### 6.5 连续episode

episode是在同一 `(run_id, fold, state)` 内沿canonical holding interval相邻关系形成的最大连续段；fold边界强制
切断。逐episode可计算compounded return、worst drawdown、drawdown duration、mean exposure/cash及source提供的
turnover/cost。

禁止把多个不连续episode拼成一条净值，禁止输出state-level Calmar或伪state MDD。状态总表只汇总episode数、
最差episode回撤、episode return中位数与duration中位数。所有episode `n_periods`之和必须exact等于状态
`n_periods`。
