## 实测格式与口径

- `.lc1/.lc5` 每条 32 字节，小端 `<Hhfffffii>`：压缩日期、日内分钟、
  open/high/low/close、amount、volume、保留字段。日期解码为
  `year=2004+value//2048, month=(value%2048)//100, day=value%100`。
- 日内分钟是 **bar 结束时刻**：`.lc1` 首根 `571` 表示 09:30–09:31，
  `.lc5` 首根 `575` 表示 09:30–09:35；午后从 13:01/13:05 开始，15:00 结束。
- 分钟价格已经是元，不再缩放；volume 是股数，amount 是人民币元；与同标的
  `.day` 及项目 Tushare 不复权日线相符，因此 clean 口径为未复权。
- `.day` 也是 32 字节，小端 `<IIIIIfII>`，日期为 YYYYMMDD；抽样确认股票价格整数
  除以 100、ETF 除以 1000，amount 为人民币元、volume 为股数。000001.SZ、
  600000.SH、518880.SH 在 2024-12-30 的分钟末价分别与 `.day` 的
  11.95、10.47、5.923 一致。

## 存储、读取与重跑

原始逻辑记录以不可覆盖 Parquet 版本保存在：

```text
F:\AI_Coding\QuantitativeTrading\data\raw\tdx_intraday\freq=<1m|5m>\source=tdx\...
```

clean 当前视图与 BaoStock/Yahoo 隔离：

```text
F:\AI_Coding\QuantitativeTrading\data\clean\bar_intraday\freq=<1m|5m>\source=tdx\symbol=<代码.市场>\data.parquet
```

raw 占 2.131 GiB，clean 占 2.738 GiB。读取入口保留 BaoStock 为默认值，TDX 必须显式选择：

```python
from quant.data.stock_intraday_repository import read_stock_intraday_bars

bars = read_stock_intraday_bars(
    data_root,
    symbol="000001.SZ",
    start=start,
    end=end,
    frequency="1m",
    source="tdx",
)
```

全量增量导入：

```powershell
$env:PYTHONPATH = "F:\AI_Coding\QuantitativeTrading\src"
D:\Miniforge3\python.exe -m quant.data.tdx_intraday `
  --tdx-root D:\new_tdx\vipdoc `
  --data-root F:\AI_Coding\QuantitativeTrading\data `
  --artifacts-root F:\AI_Coding\QuantitativeTrading\artifacts\tdx `
  --markets sh sz bj --frequencies 1m 5m --workers 8
```

同一源状态的第二次全量运行在 17 秒内跳过 17,804/17,804 个文件，clean/raw 新增均为 0；
源文件变化时保存新的 raw 版本，并按 `symbol+bar_start` 增量更新 clean。质量证据位于
`artifacts/tdx/20260909T220331356992/` 和
`artifacts/tdx/validation/20260909T220955824939/`。
