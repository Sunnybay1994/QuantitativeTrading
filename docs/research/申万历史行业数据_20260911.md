# 申万历史行业分类：2014—2026

已发布5,552只沪深A股的11,276个历史分类区间，三级归属无重叠。2014-01至2026-09共153个月末/最新日观察点，594,731个股票月中588,086个有分类，覆盖率98.88%；最新交易日2026-09-10为5,194/5,206只，99.77%。

数据来自Tushare的[分类表](https://tushare.pro/document/2?doc_id=181)和[新版成分接口](https://tushare.pro/document/2?doc_id=335)。旧`index_member`抓取440个两版三级行业的现存/退出记录，共10,272条；新`index_member_all`补抓346个2021版三级行业，共7,883条。原始页按版本保存，可中断续传。仅用旧接口时覆盖率为94.61%，已用新接口补齐机场、集成电路制造等缺漏。

历史拼接分别使用2014版的旧接口记录与2021版的新接口记录，并按各版分类表连接一、二级父行业。133个复用的三级指数代码中有32个改变了上级归属，因此不以当前父行业倒填历史。2014版从2014-01-01起使用；[申万原始说明（转载）](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/lastest/rptid/682791709623/index.phtml)确认2021版分类7月31日公告，本地从其后的首个交易日2021-08-02起使用。即使供应商把新分类入选日写成上市日，也不能越过该边界。

按沪深A股范围及有效日期筛掉385条记录；缺失或冲突归属留空，退出日保守排除。分类区间按信号日期连接，缺口不前填。数据读取、两源拼接、缺口与日期边界、恢复采集及行业因子端到端测试均通过。因子命令在表达式含`ind_neutralize`时自动读取最新两源发布版。

重建入口：

```powershell
python -m quant.data.collect_industry --raw-root <新目录> --member-api index_member
python -m quant.data.collect_industry --raw-root <同一目录> --member-api index_member_all
python -m quant.data.industry_history --raw-root <同一目录> --as-of YYYY-MM-DD --with-current
```

本次发布位于`data/clean/tushare_industry/20260911T025905254439/`；[月度覆盖明细](../../artifacts/industry_coverage_final_20260911.json)。行业L1/L2/L3分别供Alpha101的sector/industry/subindustry使用。

关键限制：2014年前无可用分类；2014-01覆盖仅80.24%，剩余缺口保持空值，不用当前分类补填。
