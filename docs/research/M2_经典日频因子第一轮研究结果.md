## 3. 解释

1. `STD20/ROC20/RSV20` 的横截面 RankIC 明显优于两个日内因子，并且三折方向一致，说明这些信号值得作为后续组合研究的输入候选；
2. 正 RankIC 没有转化成 long-only Top-50 的正绝对收益。RankIC衡量横截面排序，不保证在整体市场下行期获得正绝对收益；
3. 2x 成本进一步恶化结果，但不是唯一根因，因为多数 1x 结果本身为负；
4. `VMA20` 同时缺少方向稳定性和经济结果，应直接停止该 canonical 单因子路线；
5. 不能用这组测试结果回头调整第一轮 Top-K、窗口、方向或阈值。任何新组合必须使用新的 hypothesis id 和 run。
