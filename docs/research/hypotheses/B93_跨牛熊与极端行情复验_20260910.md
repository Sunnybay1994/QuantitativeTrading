# B93：跨牛熊与极端行情复验（2026-09-10）

固定CV20缓冲策略在2020–2026连续测试中，1×累计收益 **+65.54%**，年化 **+8.14%**，最大回撤 **-31.22%**；相对同池三因子累计收益差 **+47.95pp**。预注册结论：**RESEARCH_ONLY**。

训练段诊断2014–2018、验证2019、测试2020-01-02至2026-09-10（1,623交易日）。训练段含2014–2015上涨与2015/2018下跌，测试含2020–2021上涨、2022下跌和2024急跌/反转。按前一日510300收盘与200日均线及其20日斜率划分，上涨／下跌／过渡样本分别为：训练542／406／272，验证180／29／35，测试740／609／274。状态只用于归因。

本次扩展历史范围，CV20负向、Top50及Top75保留规则、三因子STD−/ROC+/RSV−全部固定，不拟合或选参。为避免历史名单前视，两策略共同使用2013年流动性Top800池并保留退市记录；月末收盘信号、下一开市日成交、跨年连续持仓。通过条件预先固定为CV20的1×/2×总收益为正且1×超过配对三因子，结论上限RESEARCH_ONLY。
