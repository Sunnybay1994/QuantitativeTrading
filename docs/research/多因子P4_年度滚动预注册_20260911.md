# P4：三种固定加权模型，按历史已知信息逐年重选

目标：比较等权z、正向平均IC加权、LightGBM三种方法；共同候选池、共同缺失处理、共同Top50缓冲组合与成本，按路线图完整门槛决定是否进入模拟盘。时间盒：实现与首轮回测3天，长期成本批处理同时推进。

配置：[p4_annual_walk_forward_20260911.toml](../../configs/models/p4_annual_walk_forward_20260911.toml)。模型参数在看到模型回测结果前固定；Top100只作敏感性报告，不用它替代失败的主Top50结果。

## 训练边界

每年在上一年最后交易日收盘重选因子、拟合模型，随后一年只预测。入选条件继续使用P3门槛，但统计、相关性及单因子成本超额都从该训练截止日以前的历史重新计算。当前2026年全历史入选名单仅供当前研究，不能直接放回2015年的模型。

月度收益使用`exit_date_rebalance <= refit_close`判定是否已知。仅按信号日截断会最多多带入两个月未来收益：例如2022-11-30信号的收益到2023-01-03才完整可知。

对全部329项现有月度IC做覆盖核验：中性版最早于2022-07-01积累96个已知月；截至2021年底无一满足，2022年底133项满足，2023年底317项满足。这里只检查历史长度，不代表这些因子通过其他门槛。Alpha158_corr10中性版第96个月到2023-01-03才可知，不能进入2022年底拟合的模型。

因此2015–2026回放保留完整日历，尚无历史合格因子的年份持有现金；另外报告实际开始持仓日期，实际有效期不超过三年时不能据此判断Top50增量。拒绝缩短96月门槛或借用未来排名填满早期年份。

## 固定实现与输出

训练期ICIR降序、同分按ID排序，逐个加入与已选因子绝对秩相关均值低于0.6的因子，最多20项。三种方法都使用完整特征共同股票池，月末预测后下一开市日执行；主Top50保留至75名，Top100敏感性保留至150名。

每个模型一份报告，含2015–2026连续净值、三档成本、三基准、年度表、B93四个固定窗口、最长水下期及实际股票仓位。LightGBM依赖已在项目中声明。真实下单继续关闭。

覆盖证据：`artifacts/factors/battery_training_coverage_20260911/`；目前仅完成预注册与训练边界核验，模型结果尚未产生。
