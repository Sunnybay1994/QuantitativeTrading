# 存货字段读取与覆盖

报告《策略发现_20260909》的存货扩张定义需要 `inventories` 与总资产。已有 clean 快照保留该字段，但财务读取器未开放；现已允许余额表查询通过 `extra_fields=('inventories',)` 读取，继续保留每条公告日期、实际公告日期、可用日期与修订版本，不回填缺值。

真实快照 `financial_updates_v3_20260911_004` 的报告期从2010-03-31至2026-06-30，读取371,801条修订、5,505只股票。355,826条同时满足存货有限且非负、总资产有限且为正。2025年有效21,876条、5,230只股票；2026年至当前报告期有效8,070条、5,096只股票。

```powershell
$env:PYTHONPATH='F:\AI_Coding\QuantitativeTrading\src'
D:\Miniforge3\python.exe -m quant.data.audit_inventory_history --snapshot financial_updates_v3_20260911_004 --output artifacts/research/inventory_coverage_new
```

真实输出：`artifacts/research/inventory_coverage_20260913_01/summary.json` 与 `annual_coverage.csv`。本轮仅复用已发布数据，未抓取或覆盖raw。

已登记 `pit_inventory_expansion_yoy`，方向为低值优先，公式为 `(inventories_q-inventories_q-4)/((total_assets_q+total_assets_q-4)/2)`。两个端点分别使用信号日之前已知修订，限制工业企业合并报表；缺失或负存货、非正资产和相关修订冲突均为空，零存货允许计算。日频面板在新公告后更新，接入既有 `refresh`。

2025-08-29 抽样：美的使用2025Q1/2024Q1，值0.02036953015758348；茅台使用2025Q2/2024Q2，值0.0252167765077666，与两期报表独立手算一致；招商银行被排除。明细在 `artifacts/research/inventory_sample_20260913_01/sample.json`。27项定向测试、Ruff及4个源文件mypy通过。
