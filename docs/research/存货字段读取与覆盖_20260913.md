# 存货字段读取与覆盖

报告《策略发现_20260909》的存货扩张定义需要 `inventories` 与总资产。已有 clean 快照保留该字段，但财务读取器未开放；现已允许余额表查询通过 `extra_fields=('inventories',)` 读取，继续保留每条公告日期、实际公告日期、可用日期与修订版本，不回填缺值。

真实快照 `financial_updates_v3_20260911_004` 的报告期从2010-03-31至2026-06-30，读取371,801条修订、5,505只股票。355,826条同时满足存货有限且非负、总资产有限且为正。2025年有效21,876条、5,230只股票；2026年至当前报告期有效8,070条、5,096只股票。

```powershell
$env:PYTHONPATH='F:\AI_Coding\QuantitativeTrading\src'
D:\Miniforge3\python.exe -m quant.data.audit_inventory_history --snapshot financial_updates_v3_20260911_004 --output artifacts/research/inventory_coverage_new
```
