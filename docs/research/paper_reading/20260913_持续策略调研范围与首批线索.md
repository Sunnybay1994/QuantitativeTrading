# 持续策略调研：范围与首批线索

2026-09-13 用户重新授权持续、广覆盖研究，并允许把有价值的候选发送给项目主进程实现和测试。此前9月12日研读阶段已经结束，本轮为新增研究。按每6小时一次、每轮45分钟推进，每次聚焦一个主题；有新结论才写报告，优先转成可执行实验。

## 覆盖范围

| 方向 | 重点问题 | 最小研究产出 |
|---|---|---|
| 日内与分钟低频化 | 开盘/尾盘、隔夜与日内分解、波动与成交集中度 | 明确bar端点、可知时间和次日标签的候选列 |
| 量价 | 异常成交量、价量背离、成交额与收益关联 | 与既有库去重后的批量表达式 |
| 动量与反转 | 截面/时序、行业残差、短期反转和拥挤 | 分市场、持有期和成本的比较 |
| 买卖信号与短期策略 | 突破、回撤、事件后漂移、退出与持有 | 预先固定进出场和未成交处理的策略配置 |
| 中长期策略 | 趋势、价值质量、ETF配置、风险缩放 | 与现有趋势和配置基线的机制差异 |
| 套利 | 配对、行业残差、ETF价差与申赎 | 双腿可交易性、资金/融券/申赎条件与净成本核算 |

每轮核对2至4个原始来源，同时留意研究员实践；讨论帖用于发现问题，具体效果以可复现资料及本地测试判断。报告明确全文、摘要或文档的实际阅读范围。

## 首批文献线索与取舍

1. **日内动量的迁移边界。**《Market intraday momentum: APAC evidence》（2023）的出版平台检索摘要研究亚太ETF的首半小时与末半小时关系，首段收益包含前收盘到开盘后的跳空。全文本轮未成功取得，因此暂不采用论文数值或直接实现其交易规则。[出版方入口](https://doi.org/10.1016/j.pacfin.2023.102086)

   后续优先核对首半小时是否混合隔夜信息，再将隔夜、开盘后30分钟和尾盘分开。对于A股，将它们转为下一交易日可用因子是新的迁移假设，不能把同日尾盘预测结果当成次日预测证据。候选定义例：隔夜为 open_t/close_(t-1)-1；开盘段为 price_10:00/open_t-1；尾盘为 close_t/price_14:30-1。公司行动价格连续性、时间戳和集合竞价归属先核对，成交最早在信号可知之后。分钟历史覆盖不足时先报告覆盖，不降长期评估标准。

2. **时序动量保留为中长期对照。**Moskowitz、Ooi、Pedersen（2012）的作者机构介绍明确区分自身过去收益与横截面相对排序，研究对象包括58个期货/远期合约。本轮阅读机构摘要，未重新复现原论文。[作者机构介绍](https://www.aqr.com/Insights/Research/Journal-Article/Time-Series-Momentum)

   项目已有ETF趋势研究，先查重复。新的价值应来自总回报口径、跨资产可投资范围或风险配置的明确差异；仅改变若干均线周期不值得新开实验。期货多空结论迁移到ETF只做多需要独立验证。

3. **配对套利先过可实施性检查。**Gatev等《Pairs Trading: Performance of a Relative Value Arbitrage Rule》列为下一轮经典阅读，NBER全文入口本轮403，尚未阅读全文。[NBER入口](https://www.nber.org/papers/w7032)

   先验证双腿交易、融券及对冲条件，再设计价差收敛实验；不将相关性直接等同于均值回复。不具备做空条件时，单腿轮动只能作为另一种有方向风险的策略。ETF申赎价差需先取得对应基金的官方申赎、现金替代和交易规则。

## 给主进程的实现顺序

首先核对分钟因子库是否已完整包含隔夜、开盘段、尾盘段及成交集中度，以及时间端点和次日标签是否正确。若有实质缺口且数据覆盖支持，批量补候选并走原有评估流水线；重复或覆盖不足则不新增实现。其他方向待进一步原文核验后推荐，每轮最多发送两项，避免挤占日更与已启动实验。

研究持续进行；代码由主进程安排，保持策略预注册、成本压力、无前视与人工下单约束。论文线索不能直接晋级模拟盘。
