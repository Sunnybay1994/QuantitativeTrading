# 论文研读与研究报告

这里存放对量化论文、研究员讨论和机构研报的专题研读，服务本项目后续因子、模型与组合研究。2026-09-12建立，按研究问题持续归档；平台发现与文献索引见下方关联材料。

每份报告围绕一个研究问题，提供原始来源与版本、具体阅读范围、关键方法及证据、独立分析、与项目现状的差异，以及值得验证的后续实验。需要解释计算时使用手算或合成例，并与真实市场结果分开。论文的结果不会直接更改当前策略结论。

## 专题目录

本地应用新增重要发现：[小天鹅换股遗漏与退市核销](20260912_小天鹅换股遗漏与退市核销.md)。SUE v2 实际持有400股小天鹅，保存回放漏记美的换股权益并核销22,956元；全年244日账户重建市值差为0。已通知主进程，先修正公司行动计量，再继续比较持有规则的经济效果。

**换股修复已有实际结果：**12条配置的原核销均消失，事件前NAV一致。SUE v2 Top50 1×持股期CAGR由22.29%变为22.67%，仍因换手及压力窗口判为REJECTED。后续规则研究使用修复版；下述旧冻结run诊断保留其原范围。

[组合估计误差专题](20260912_组合估计误差与简单权重基线.md)进一步解释一股敏感性：两条路径目标完全相同，约52.85元现金差直到2021年才首次触发额外100股增持，随后积累137条股数差异。离散执行的微小路径差不能直接解释成模型信息优势。

扩展核对七个指定版本的420份年度NAV后，找到12条小天鹅核销，涉及旧SUE与SUE v2的Top50/Top100三档成本；另外24条属于其他三只摘牌股票，已核对终止上市安排并单独保留回收价值假设。零碎股规则也已读到原文，本例实际整数到账量为460或461股，需保留该范围。

[平台实践专题](20260912_平台实践_缺行情与持仓估值.md)进一步追踪富通实际持仓：4月底已清零目标，随后四次卖出被跌停或停牌拒绝；总现金损失43,302.50元中，最终核销仅7,844元。复用本地日度因子数据补足月度快照后，确认相关30天四价均等于跌停价，现有规则逐日均拒单；只增加重试频率不能解决本例。

同专题全历史汇总进一步发现：SUE v2 Top50 1×的50条卖出拒单中，34条集中在2020-02-03；退出规则实验应覆盖共同压力日及恢复交易阶段，并核对失败卖单对现金与组合偏离的影响。

这34只的日度条件核对也已完成：680行官方限制齐全，按原1×滑点，28只在2月4日、6只在2月5日恢复卖出价格条件，下一保存卖出均在3月2日。持续退出规则有可检验的作用空间，成本后收益仍需完整回放。

反向核对也已保留：其中32只零目标股的固定股数参考价值，在各自恢复日到3月卖出前合计增加14.16万元，31涨1跌。该异步起点诊断说明更及时执行不必然提高收益，不能据此直接增减完整策略净值。

同专题另用合成双持仓验证了实现入口：单只零权重目标会清零批次外持仓，已有固定股数卖单则保留其他持仓。退出重试应复用后者，并在实验前固定新目标覆盖、部分成交与公司行动后的数量规则。

[组合净交易成本专题](20260912_组合净交易成本与信号家族.md)补充了资金路径：目标权重回放的现金不足缩量不进入买入拒单表。2020-02-03没有买入拒单，却有29个正目标未形成持仓；已用合成例验证接口语义，后续报告应同时看拒单、目标覆盖与欠配幅度。

同口径92次调仓的平均目标存在比例为98.67%，但2020-02-03和2024-10-08仅42%、64%，两日贡献47/61条缺仓；现金状态分别接近零和38.19%。自动化报告应突出执行日分布和双向成交限制，避免只看均值。

## 怎样用于后续投研

先把现有研究的比较对象和计量口径说明白，再选择新的模型实验。缺失值专题要求追踪扩池后的群体和实际持仓；分钟专题将样本变化与中性化效果分开；组合专题核对净订单和费用是否已经正确计入。这三项可优先复用已有 run 和诊断模块。

LLM 专题把语义忠实度、相对结构化数据的增量、真实前向预测分开验证。风险专题区分同期收益归因与下一期风险预测。数据版本专题用维护者的真实修订案例，帮助自动日更发现口径变化并解释旧结果为何改变。

已完成一项本地应用：[Q1d 换手诊断](20260912_Q1d换手与预测池边界诊断.md)复用旧 SUE 版本的冻结预测和成交，确认高换手在目标层已经存在。随后完成 [SUE v2 同口径核对](20260912_SUE修复后换手与标签覆盖复核.md)：月均替换 41.59→41.58 只，高换手解释仍然成立；两版同月目标平均重合 39.54/50，收益与交易次数变化应分开解释。该复核及五分组缺标签覆盖已完成，后续规则实验使用修复后的产物。

[头部预测与换股价值](20260912_SUE修复后头部预测与换股价值.md)进一步完成 91 个成熟标签月的评分：整体 RankIC 与头部等级有信息，但换入相对换出的优势证据弱，完整组与可观测成员口径甚至变号。后续优先研究持有与交易成本规则，同时保留缺标签对月度比较覆盖的影响。

[退市与缺标签专题](20260912_退市收益与幸存者偏差.md)也已连接 2024 年保存标签和三条正目标的回放记录：两条买入因停牌被拒，一条原定卖出被拒。延期案例进一步完成全年 242 个交易日账户对账，持仓市值重建差为 0 元；该股缺报价五天后恢复报价，又经历 16 个有报价的交易日才在下个月度批次卖出。估值连续，但退出等待还受调仓规则影响；后续卖出价不能填成原定退出日的价格。

同专题随后核对三次代码变更与贵人鸟真实摘牌：八个“模型—事件”组合均无相关持仓，未发现错误核销；实际识别的是中航善达历史字段分散在新旧代码下，导致冻结信号日两行都未入池。后续数据工作先查跨表映射与覆盖，不预先假定存在需要补回的策略亏损。

每篇最多提出两个主要实验，实施时沿用项目现有配置和研究 run。先完成同一变量的比较；论文结果与本文合成例只用于选择假设，本地策略结论由实际实验给出。
