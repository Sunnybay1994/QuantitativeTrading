# 论文研读与研究报告

这里存放对量化论文、研究员讨论和机构研报的专题研读，服务本项目后续因子、模型与组合研究。2026-09-12建立，按研究问题持续归档；平台发现与文献索引见下方关联材料。

每份报告围绕一个研究问题，提供原始来源与版本、具体阅读范围、关键方法及证据、独立分析、与项目现状的差异，以及值得验证的后续实验。需要解释计算时使用手算或合成例，并与真实市场结果分开。论文的结果不会直接更改当前策略结论。

## 怎样用于后续投研

先把现有研究的比较对象和计量口径说明白，再选择新的模型实验。缺失值专题要求追踪扩池后的群体和实际持仓；分钟专题将样本变化与中性化效果分开；组合专题核对净订单和费用是否已经正确计入。这三项可优先复用已有 run 和诊断模块。

LLM 专题把语义忠实度、相对结构化数据的增量、真实前向预测分开验证。风险专题区分同期收益归因与下一期风险预测。数据版本专题用维护者的真实修订案例，帮助自动日更发现口径变化并解释旧结果为何改变。

已完成一项本地应用：[Q1d 换手诊断](20260912_Q1d换手与预测池边界诊断.md)复用旧 SUE 版本的冻结预测和成交，确认高换手在目标层已经存在。随后完成 [SUE v2 同口径核对](20260912_SUE修复后换手与标签覆盖复核.md)：月均替换 41.59→41.58 只，高换手解释仍然成立；两版同月目标平均重合 39.54/50，收益与交易次数变化应分开解释。该复核及五分组缺标签覆盖已完成，后续规则实验使用修复后的产物。

[退市与缺标签专题](20260912_退市收益与幸存者偏差.md)也已连接 2024 年保存标签和三条正目标的回放记录：两条买入因停牌被拒，一条买入后在原定退出日无法卖出，延至后续调仓成交。未来评估应保留这种标签、目标和实际持有期的区别，不能把后续卖出价填成原定退出日的价格。

每篇最多提出两个主要实验，实施时沿用项目现有配置和研究 run。先完成同一变量的比较；论文结果与本文合成例只用于选择假设，本地策略结论由实际实验给出。

## 下一步研究顺序

下表是研读后的行动建议，不表示实验已经执行；每项先复用已有产物，按现有模块负责人安排落地。

| 优先级 | 值得先回答的问题 | 最小可用动作 | 对应专题 |
|---|---|---|---|
| 先行 | 修复缺失后增加的股票是否带来不同风险与盈利质量？ | 将保留、新增、实际入选群体并列，固定共同样本的变换与预测 | 缺失值、盈利质量、分钟低频化 |
| 先行 | 三模型的差异来自排序、组合边界还是成本？ | 复用同一run的预测与订单，检查秩、Top-K变化及净费用；分数未校准时不直接比较MSE | 机器学习、组合净成本 |
| 先行 | 修复 SUE 后，头部选股的收益能否覆盖频繁更换成本？ | 复用已完成的 v2 换手与退出分类，进一步连接头部评分、股票身份变化和实际费用 | SUE v2 复核、排序学习 |
| 先行 | 预测评分是否漏掉实际账户承担的延迟退出路径？ | 复用已完成的三笔目标核对，进一步检查延长持有估值及缺标签分布，保留固定期限与实际成交两种对象 | 退市与幸存者偏差 |
| 先行 | 已有健康监控是否有可评分的输入？ | 对照保存序列及标签成熟情况接入已有监控；空演练不解释为因子健康 | 因子失效、数据版本 |
| 先行 | 现有因子准入对多重检验选择是否敏感？ | 用完整登记集合比较原准入、BH和BY交集，只报告变化及原因 | 多重检验 |
| 随后 | 归因模型能否形成真正的下一日风险预测？ | 固定前日设计矩阵，保留共同项交叉关系，再评分简单协方差预测 | 风险归因 |
| 随后 | Q4 风险改善来自多留现金，还是股票内部配置？ | 先分解现有等权投影；风险预测成熟后再固定股票投入做有限对照 | 组合估计误差 |
| 随后 | 历史ADV检查能否约束实际执行窗口？ | 对10笔已有压力订单比较整日量与已有5分钟窗口量；前向记录成交和未完成部分 | 流动性容量 |
| 随后 | 文本相对结构化公告增加了什么？ | 将语义评估、数值基线、未来收益增量分开；历史模型记忆靠真正前向继续检验 | LLM、盈利质量 |
| 随后 | 相关性筛选是否排除了有条件信息的候选？ | 固定年度控制集与小批候选，分开报告残差信号 IC、预测增量和收益 alpha | 因子增量 |
| 随后 | 当前排序是否有头部价值，换目标能否增加净收益？ | 先用保存预测补头部评分与成员迁移，只有证据指向训练目标时才比较固定规模的排序器 | 排序学习 |
| 随后 | 压力损失是否还有现有风格模型未解释的共同来源？ | 先看冻结持仓与收益标签，再连接自己的卖出原因和完成数量；外部拥挤需要外部持仓及资金证据 | 拥挤交易 |
| 并列主线 | ETF趋势的贡献来自择时还是长期资产暴露？ | 固定已存在的SMA10和资产范围，解释现金、总回报与下一开盘执行差异 | ETF趋势 |

当以上诊断表明简单基线之外仍有稳定增量，再选择模型或组合规则实验。原作者回应、后续反例和版本变化一起保留，不把论文的显著结果直接换算为本项目预期收益。

低风险专题优先解释已存在信号的组合含义；非标准误差专题区分同数据下的方法选择与测量修复；平台实践专题沿维护者原始讨论核对估值和成交的具体分支。它们与上表的本地诊断配合，用于确定下一项实际值得验证的问题。
