# 市场流动性、情绪代理与状态适配

2026-09-22；用户授权的研究与实现。目标是解释策略在哪些条件下赚钱或亏损，并形成交易前可用的输入。市场状态不是收益预测，更不保证提高收益。实验数值只保存在下方机器产物，不在本文手抄。

## 市场上如何测量

|维度|常见测法|本项目采用与边界|
|---|---|---|
|交易活跃度|成交金额、换手率、相对历史量额|保留总成交金额、个股换手中位数、相对前20日成交金额。金额放大可能来自恐慌抛售，不能独自代表交易顺畅|
|交易流动性|买卖价差、盘口深度、价格冲击、冲击后恢复速度|日频采用 Amihud 冲击代理；盘中支持买卖价差。没有订单簿就不声称测量深度或恢复力。BIS 将流动性视为多个维度，而非一个成交量数字。[BIS](https://www.bis.org/publ/qtrpdf/r_qt0406.pdf)|
|投资者情绪|问卷、期权、发行/投机行为等代理变量的综合指标|Baker–Wurgler 经典论文用多项代理的主成分；作者2026版已去掉 NYSE 换手率、保留五项，并提示指数适合水平而非直接差分。本地日频价格/广度指数不能冠名 BW。[原研究](https://www.nber.org/papers/w10449)、[作者当前口径](https://github.com/BWInvestorSentimentIndex/BakerandWurglerInvestorSentimentIndex/blob/main/README.md)|
|风险预期|期权隐含波动率、偏斜、认沽/认购指标|VIX 来自标普500期权，衡量未来约30天隐含波动；不是上涨方向或本地已实现波动。A股期权口径须单独获取、检验流动性及可得时间。[Cboe方法](https://cdn.cboe.com/api/global/us_indices/governance/VIX_Methodology.pdf)|
|资金与杠杆|融资余额及变化、利率、信用利差、融资条件|融资余额是存量，不能当日净流入或实时指标。发布后才能进入信号。交易流动性与融资流动性分开；NFCI 的风险/信用/杠杆思路可参考，但不能直接移植美国指标。[上交所](https://www.sse.com.cn/market/othersdata/margin/sum/)、[Chicago Fed](https://www.chicagofed.org/-/media/publications/chicago-fed-letter/2017/cfl386-pdf.pdf)|
|趋势与参与面|均线、区间收益、上涨家数、站上均线比例|首版已有；指数上涨但多数股票未跟随，是有价值的分歧，不强压成同一个牛熊标签|
|分散与集中|截面收益标准差、股票相关性、行业涨跌广度、成交集中度|首版保存截面分散度和前20只成交额占比；集中度不等同机构拥挤，相关性与行业广度待历史成分口径验证|
|估值与宏观|估值分位、盈利/利率差、信用和经济周期|适合慢变量。后续接 PIT 财务/发布日数据；不拿后来修订值回填历史，也不与日内情绪混用|

Amihud 原研究用绝对收益与金额之比衡量非流动性：[Amihud 2002](https://doi.org/10.1016/S1386-4181(01)00024-6)。本版采用20日个股均值再取市场中位数，同时保留市场均值作核对；中位数聚合是本项目的稳健改造，不是原论文原样复刻。该代理混有基本面波动与价格限制影响，不是真实订单冲击估计。

## 固定计算口径

历史范围为当日实际出现的沪深 A 股，不用今天上市名单筛历史；暂不含北交所。金额统一人民币，换手率百分数转小数。复权收益要求相邻交易所交易日连续，缺行不跨日计算、不填零。连续20日指标要求完整窗口；这会使大面积停牌时期出现不足，不能为了补全而降门槛。

- `amihud20_i = mean_20(abs(adjusted_return_i) / (amount_i / 1e6))`。
- `advance_decline_balance = (上涨家数 - 下跌家数) / 有效收益家数`；平盘进入分母。
- `breadth20 = 复权收盘价不低于当日20日均线的股票比例`。
- `close_location = 2*(close-low)/(high-low)-1`；一字价格日无区间信息，留空。
- 交易流动性分数 = 换手中位数历史分位与反向冲击历史分位的均值。
- 情绪代理分数 = 涨跌家数差、均线广度、收盘区间位置各自历史分位的均值。这三项有相关性，不能当三份独立信息；高分不代表未来收益更高。
- 标准化仅用前252个交易日内至少126个有效观测；当前观测不进入自己的比较分布。分量缺失不临时改权重。
- 趋势参考510300复权价格、60/200日均线；波动为其20日日收益标准差乘根号252。复权价格仅作趋势/波动参照，不充当策略准入收益基准。
- 市场状态依次判定：高波动且低流动性或低情绪为 `stress`；上趋势且广度过半为 `trend_up`；下趋势且广度不足一半为 `trend_down`；其余 `mixed`；必要输入缺失为 `unknown`。高低阈值固定80/20分位，不按策略收益拟合。

覆盖分母为前20个交易日或当日出现过的股票并集，属于可观测活跃参考池，**不是完整上市/停牌普查**。每个分量独立要求至少500只且覆盖80%；留存实际分母和分量计数。未知不代表风险低，不能据此解除风控。历史分类为收盘数据重建，`effective_date` 是下一交易日；没有原始到达凭据，不能宣称这段历史具备已证明的实时可得性。

## 盘中与日更如何使用

盘中只读现有 SQLite 行情库，或显式提供规范化 JSON/Parquet；不启动另一套行情轮询。要求供应商时刻和本机接收时刻均带时区、均不晚于测算时刻；同日且报价年龄不超过120秒。以前一交易日冻结的参考池算覆盖，重复收到的标的取最新合格记录。

现有订阅仅包含持仓/代表标的，且未保存所有涨跌计算所需字段。实测证明它不能生成全市场指标。输出会携带前一收盘状态、覆盖率、拒绝原因，盘中综合状态留 `unknown`。这是目前尚未完成的全市场实时数据覆盖环节，不能说已上线完整实时情绪指数。

有足够覆盖的规范化输入时已支持：涨跌家数差、相对昨日20日均线的广度、买卖价差中位数、同钟点成交金额比。输入字段包括 `symbol,last_price,amount,volume,provider_time,received_at`；可选 `prev_close,bid,ask,past_same_time_amount,baseline_end_date,baseline_clock`。`prev_close` 必须是交易所除权参考，不能用旧原始收盘价冒充。同钟点基线必须来自前日及更早、时钟匹配，调用方负责其统计和数据来源；当前没有自动积累该基线。日频情绪分数不能拿半天金额直接重算，盘中分数需独立校准。

```powershell
$env:PYTHONPATH="$PWD/src"
$env:POLARS_MAX_THREADS='4'
# 默认日期是冻结研究区间；日更时必须显式传 --start/--end。
python -m quant research market-indicators history --output artifacts/research/market_indicators_NEW --returns artifacts/research/strategy_family_regimes_20260922_01/daily_returns_1x.csv
python -m quant research market-indicators live --history artifacts/research/market_indicators_NEW --output artifacts/research/market_live_NEW
```

主进程接原盘后刷新成功节点调用历史命令；短期日更可将 `--start` 与 `--end` 都设为上一完整交易日，模块自行回读预热期。配置从刷新文件解析最新基准快照，输入配置会复制到产物，保留股票/基本面快照身份及文件大小/mtime变化检查、基准/日历/代码/输出校验和。前者不是每个源文件内容哈希，也不证明原始到达时间。运行输出目录必须新建；`summary.json` 和 `report.md` 都存在才收取，避免把失败尝试当完成。

本次仅历史重建至前一交易日，拒绝当前自然日作为完整收盘输入。每天盘前更新可以直接使用；同日收盘后自动运行前，须接既有日更完成证据与明确发布时间，不能只凭时钟超过15点放开这个限制。当前未另建定时任务。

## 主进程接续顺序

1. **接入可用输入，不影响既有观察账户。** 原盘前/日更链展示最近已完成状态、观测日期、覆盖率、缺失原因。缺失保持未知，先作为风险与研究上下文，不改变现有目标仓位。扩展已有免费全市场快照采集，保留除权参考价和双时间戳；核验真正全市场覆盖后才发布盘中广度。同步积累同钟点基线，仍由已有采集链负责。
2. **完成跨机制的适配诊断。** 将 Q10、压力反转、ETF固定暴露/动态配置等已冻结真实净收益送入同一状态接口；先分策略看年度、月份、连续压力事件及缺失，再核对市场/规模/行业暴露、换手、持仓/现金比例、拒单与成本。ETF不能仅依靠A股状态解释全部跨资产回报。控制样本重复，不把同源变体当独立证据。
3. **因子按组而非单个试错。** 复用 `quant.reporting.factor_state_ic` 和既有批量电池，将这里的前日状态按实际信号日期连接到原 PIT 面板；报告全因子族的条件 raw/partial IC、衰减、覆盖、年份和月份，不仅展示赢家。未来收益标签只能在其成熟后评分。状态内有IC不等于状态间差异显著；月块自助法/稳健推断、多重比较和训练内选择一起处理。
4. **先固定组合，再有限状态缩放。** 独立机制具备证据后，先按原路线实现固定组合，完整合并订单重算三档成本。然后最多增加一个预注册的滞后状态缩放对照：训练段定规则、下一段冻结执行、保留完整连续账户路径，报告状态持续长度、切换换手、成本后收益/Sharpe（rf0/2%）、回撤与错过反弹。不能把各状态最优策略拼成历史净值。
5. **决策与停止。** 必须检验是否只是降低平均股票仓位、或依赖单次压力事件；和相同平均风险/现金投入的静态基线比较，检验移除单次极端事件后的稳定性。既有历史已看过，只算回放；新的前向从规则冻结后开始。若无跨年份、成本后增量则保留固定组合，停止择时，不再网格调阈值。必要账户检验只用10万元，`auto_trade=false`。

状态切换的经济动机可参考 [Ang–Timmermann](https://www.nber.org/papers/w17182)，波动管理参考 [Moreira–Muir](https://www.nber.org/system/files/working_papers/w22208/w22208.pdf)，并同时检验其样本外局限：[Cederburg等](https://www.lehigh.edu/~xuy219/research/COWY.pdf)。这些研究支持开展有限检验，不证明本地 A 股组合一定受益。

验证覆盖：缺日不桥接、复权拆分连续性、重复键拒绝、缺股票分母、负涨跌家数差、历史前缀不变、下一交易日标签、缺分量不填充、盘中未来/过期时间拒绝、除权参考与同钟点基线、快照序列化及过期历史参考拒绝。数值实现测试通过不等于策略获利验证。
