# 缺失值处理与截面样本偏差

研读日期：2026-09-12。问题：Q1/Q2 放宽完整截面要求之后，怎样区分恢复覆盖、改变风险暴露和改善预测？本报告深入读取两篇论文的方法与实证设计，并对照项目代码、既有 Q2 诊断，给出两个后续实验设计。

**结论：保留中性分数补零作为简单基线，优先解释新增股票群体，再决定是否引入条件填补。** 本地历史诊断中，新增预测群体的已披露累计亏损比例为 37.48%，保留群体为 4.09%；因此，“多覆盖了多少股票”与“恢复了多少有效信息”需要分别回答。论文中关于补零的不同建议，则主要对应预测表现与参数推断两个不同目标。

## 1. 两篇论文具体读到了哪里

### 1.1 Chen、McCoy：预测收益的填补方法比较

Andrew Y. Chen、Jack McCoy，*Missing Values Handling for Machine Learning Portfolios*，JFE 155，103815，2024-05。[正式书目](https://doi.org/10.1016/j.jfineco.2024.103815)，[实际阅读的 2024-01-11 v6 全文](https://arxiv.org/html/2207.13071v6)。

阅读 §2、§3、§4.3–4.4、§5.1–5.4 及 Table 4：159 个连续特征先截尾、变换、标准化，比较六种填补与六种预测方法。1995–2021 每年六月用过去数据训练、验证，再预测未来十二个月。均值填补总体有竞争力；来源成块缺失与估计噪声限制复杂填补。随机遮掉单个字段，可能比真实的整组缺失容易。论文收益未扣交易及借券费用。[方法与实证原文](https://arxiv.org/html/2207.13071v6#S3)

[作者代码仓库](https://github.com/jack-mccoy/missing_data)已读 README 和文件结构，包含预处理、填补、预测及误差诊断；其 CRSP 数据依赖 WRDS，示例虚拟数据只能说明程序流程。本轮没有运行作者代码。

### 1.2 Freyberger 等：填补后的回归参数与推断

Joachim Freyberger、Bjoern Hoeppner、Andreas Neuhierl、Michael Weber，*Missing Data in Asset Pricing Panels*，RFS 38(3)，760–802，2025-03，在线发表于 2024-01-27。[期刊正文入口](https://academic.oup.com/rfs/article/38/3/760/7590858)。

读取期刊检索正文的 §2.1、结论及书目，并深入阅读[作者机构所存 2021-09 工作稿](https://www.qmul.ac.uk/sef/media/econ/images/documents/missing_data_in_ap_compressed.pdf) §2.1–2.2，另查 §2.3 扩展。基础方案先估计条件均值，再处理填补误差与参数推断；所需条件包括已观测、未观测群体之间的条件关系可迁移。填补后的残差方差不同，第一阶段估计也带来误差；普通回归标准误不能直接照用。基础方案的残差方差加权与 §2.3.2 讨论的观察概率倒数加权扩展须区分。工作稿用于理解方法，不与期刊版样本数字混合。[方法原文](https://www.qmul.ac.uk/sef/media/econ/images/documents/missing_data_in_ap_compressed.pdf)

期刊给出[复现数据与代码入口](https://doi.org/10.7910/DVN/QR6PHI)；本轮未读取其文件或运行复现。

## 2. 为什么两种建议可以同时成立

下表是针对本项目的独立判断。

| 想回答的问题 | 需要估计的对象 | 应采用的比较 |
|---|---|---|
| 明天或下月哪些股票排序更靠前？ | 在可交易股票池上的样本外预测 | 同期、同池、同成本的 RankIC 与组合结果 |
| 控制规模和行业后，某特征是否仍有收益解释力？ | 回归系数及其不确定性 | 明确缺失机制、残差结构、第一阶段误差 |
| 扩池后收益变化来自哪里？ | 样本变化、权重变化、交易变化的贡献 | 冻结打分器的群体分解，再看训练变化 |
| 是否值得采用更复杂的填补器？ | 可迁移的预测改善相对实现成本 | 来源成块缺失下的验证集比较及一次保留测试 |

均值填补在某个预测任务中表现好，无法单独证明回归系数没有偏差。条件均值在理想模型中改善参数估计，也无法单独证明真实 A 股组合能支付额外换手后提高收益。两者的目标函数、数据相关结构、估计误差与交易条件都需要单独核对。

### 一个独立推导：完全随机缺失也可能改变系数

以下是合成总体计算，不是股票回测，也不是两篇论文表格的复现。

设两个已中心化特征 \(X_1,X_2\) 的方差均为 1、相关系数 \(\rho=0.8\)，真实关系为：

\[
Y=X_1+X_2+\varepsilon,\qquad E[\varepsilon\mid X_1,X_2]=0.
\]

令 \(O\) 独立于所有变量，概率 \(p=0.5\) 时观察到 \(X_2\)。未观察到时补总体均值 0，于是输入变成 \(Z=OX_2\)。以 \(X_1,Z\) 回归 \(Y\)，总体正规方程为：

\[
\begin{pmatrix}1&p\rho\\p\rho&p\end{pmatrix}
\begin{pmatrix}b_1\\b_2\end{pmatrix}
=
\begin{pmatrix}1+\rho\\p(1+\rho)\end{pmatrix}.
\]

代入得到 \(b_1=1.588235\)、\(b_2=0.529412\)，偏离真实的 \(1,1\)。原因可以直接从输入看出来：部分 \(X_2\) 被压成 0 后，仍与它相关的 \(X_1\) 承担了更多解释。

再假设 \(E[X_2\mid X_1]=\rho X_1\)，且该条件关系已知，用 \(Z=OX_2+(1-O)\rho X_1\) 填补，可得输入协方差矩阵的第二个对角元为 \(p+(1-p)\rho^2\)，同样求解恢复 \(1,1\)。真实研究还必须估计这条条件关系，其误差和适用范围正是需要验证的部分。

本轮用 NumPy 解上述两个 2×2 线性方程，得到与推导一致的数值。该例只说明参数解释上的问题；它没有比较有限样本机器学习的预测误差。

## 3. 本项目的缺失值至少有三个层次

### 3.1 原始字段与因子定义

| 缺失原因 | 对数据的处理含义 | 对后续研究的含义 |
|---|---|---|
| 数据源原本返回 null | 保留未知并追踪来源 | 不能直接解释为零股息或亏损 |
| 因子仅适用于特定企业或取值范围 | 保存适用范围和定义性排除 | 评估定义覆盖了哪类股票 |
| 新股没有足够历史季度 | 保留历史不足 | 不能从上市后记录反填上市前窗口 |
| 当时尚未公布、后来修订 | 按可知日期选版本 | “今天能查到”不构成历史可用 |
| 某一字段异常导致旧清洗整行隔离 | 新版本按字段恢复已核实值 | 不把独立有效字段一起丢掉 |
| 行业或规模控制缺失 | 无法按约定完成该次中性化 | 因子补零不能代替有效控制变量 |

这张表来自本地 [Q2 缺失原因诊断](../Q2_输入缺失原因与覆盖_20260912.md)及当前模型实现的对应关系。不同来源的 null 可以在模型层暂时使用相同数值编码，但其数据语义仍应保留，供质量检查和分组分析使用。

### 3.2 模型输入与打分

2026-09-12 读取的 [model_training_models.py](../../../src/quant/research/model_training_models.py) 中，`neutral_zero_with_monthly_factor_exclusion` 只接受已经规模、行业中性化的分数：

- 在当月 eligible 股票池上计算每个因子的有限值比例；默认缺失比例超过 30% 则整月停用该因子。
- 活跃因子的个股缺失分数填 0；控制变量无效的股票随后排除。
- 等权与 IC 加权打分按当月活跃因子重新归一化；某股票单独缺失一项时，不按该股票剩余项重新分配权重。
- LightGBM 保留固定列结构；停用列填 0。月度活跃标记用于验证输入与线性打分，不作为额外模型特征输入。

覆盖阈值的分母当前是排除无效控制之前的 eligible 池。读覆盖率时应使用该定义，与最终可打分股票数分别列出。

以下四只虚构股票的观测值均已按列中心化；第二因子只有 A 缺失，占 25%，所以该因子当月仍活跃：

| 股票 | 因子 1 | 因子 2 | 当前补零、除以 2 | 改成逐股仅对有值因子平均 |
|---|---:|---:|---:|---:|
| A | 1.0 | 缺失 | 0.50 | 1.00 |
| B | 0.8 | 0.8 | 0.80 | 0.80 |
| C | -1.0 | -0.4 | -0.70 | -0.70 |
| D | -0.8 | -0.4 | -0.60 | -0.60 |

两种处理会交换 A、B 的第一名。逐股重新归一化会放大 A 剩余信号的贡献，因此它是一项组合打分规则变更，需要独立验证，不能当成无影响的数据修复。

### 3.3 股票池与最终组合

假设各特征独立地有 95% 的观测率，同时要求 20 项完整时，理论保留率为 \(0.95^{20}=35.85\%\)；50 项则只有 \(7.69\%\)。这是用于理解交集效应的假设算例，本项目存在成块缺失，不能拿该数字估计真实覆盖。

但本地数据已经给出了更直接的信号：补零后的扩池并非只在原有股票群体中随机增加几条记录。

## 4. 本地 Q2 历史快照揭示的群体变化

以下取自 [coverage_summary.json](../../../artifacts/research/q2_missing_input_diagnosis_20260912_01/coverage_summary.json) 与 [economic_summary.json](../../../artifacts/research/q2_missing_input_diagnosis_20260912_01/economic_summary.json)。它比较旧的 `q1c_missing_on_calendar_96_20260912_01` 与 `q1c_calendar_on_q1b_96_20260912_01`，时间为 2022-12-30—2026-08-31，共 45 个信号日。它用于解释研究问题，不能当成后续已修正控制变量的 Q1d 最新结果。

| 群体 | 股票—信号日 | 最新已披露累计归母亏损数 | 比例 |
|---|---:|---:|---:|
| 保留预测 | 89,157 | 3,648 | 4.09% |
| 新增预测 | 83,363 | 31,247 | 37.48% |
| Top50 保留正权目标 | 1,350 | 46 | 3.41% |
| Top50 新增正权目标 | 850 | 466 | 54.82% |

预测记录合计由 89,157 扩至 172,520。新增群体中仍有有效 PIT 利润历史；这里的“亏损”指信号日已知的最新 YTD 累计利润，不是 TTM。股票跨月重复计数，正权目标也不是实际成交或持仓；新增预测有 4 条最新利润冲突，单列未知。

从这些数字可以支持的本地判断是：完整截面的筛选与盈利特征明显相关；补零改变了候选股票分布，而且 Top50 目标也受到影响。它们没有证明“亏损股应被禁止”，也没有证明扩池导致了某个回撤。接下来应追踪新增群体经过打分、约束、成交后究竟承担了多少组合权重。

原诊断还发现新增预测中有 685 条行业缺失、21 条规模缺失；它们没有进入该快照的正权 Top50。当前代码已经单独排除控制无效股票，因此研究报告必须区分这份历史缺陷快照与已修复后的实现，不能反复把同一问题当成未解决项。

## 5. 后续实验 A：冻结打分器，拆开扩池与训练变化

**假设：扩池后的变化，首先可以分解为新增群体进入候选集合的影响；这种影响不等同于填补器提高了原群体预测能力。**

第一步只做既有 run 的归因诊断：固定因子版本、中性化参数、训练结果、当月活跃列和每只股票原有预测值，分别报告完整群体、被恢复群体，以及后者按缺失原因、已知亏损、规模、行业划分的覆盖和预测分布。随后逐层跟踪正权目标、约束后目标、实际成交、实际持仓和成本贡献；相同股票跨月份保留可追溯键。

一个必要的对照检查是：在固定变换和固定打分器的前提下，完整股票的原始预测值应完全相同。若连这些预测值也变了，应先检查是否重新标准化、重估模型或改变列集合。扩池后它们的全池排名、Top50 入选状态仍可能变化，这是其他股票参与比较的正常结果。

第二步若要研究训练数据扩展，另建一个版本化模型假设：只改变训练股票的完整性要求，两种模型在同一个冻结测试群体上评价，避免把训练改进和测试池改变揉在一起。候选参数仅在过去训练、验证段选取，收益标签必须已经成熟。

输出包括逐月群体规模、原始预测变化、同池 RankIC、行业/规模暴露、亏损群体权重、换手、实际持股期成本后收益，以及 0.5×/1×/2× 成本结果。重复股票观测不能当成相互独立样本来夸大显著性；采用项目既定时间序列统计口径。

当前优先级：先完成第一步诊断，再决定第二步是否值得跑。若新增群体只是增加某种风格暴露，优先交给组合约束和风险归因解释。

## 6. 后续实验 B：按真实缺失结构检验复杂填补

**假设：若可观察的其他字段确实含有可迁移信息，一个简单条件填补器应在成块缺失下改善验证误差，并在相同股票池上保留预测价值。**

在过去训练和验证段，挑选原本可观察的字段作为可核对真值，按本地已有原因表预先固定两类遮挡：同一财务来源的一组字段一起遮挡，以及连续若干信号月的同组字段遮挡。随机单字段遮挡可作难度参照，不能作为唯一验证。

只比较当前中性补零与一个预先选定的简单条件模型，例如使用截至该日已知的其他特征进行正则线性预测。正则参数在时间验证段选取，跨期模型只用过去数据拟合。若使用当日可观察截面估计变换，必须明示该操作并对两组一致应用；未来财报、未来收益和后来修订值都不能用于填补。

同时记录两层误差：被遮字段的标准化 RMSE，以及同一冻结股票池的预测 RankIC。填补更像原值但 RankIC 没改善，说明没有证据为复杂度付费；两者改善后才进入统一组合回放，观察净成本效果。

这类遮挡实验只能检验“原本可观测群体中的人工缺失”。企业类型不适用、上市前历史、特定盈利区间被定义性排除，未必存在可恢复的同一个数值对象，不能用遮挡胜利宣称已修复这些缺失。可以另提“缺失原因是否有预测信息”的模型假设，但原因标记也必须经过因子评估和时间切分。

## 7. 对当前推进的安排

Q1/Q2 继续采用简单补零与无效控制排除，先把群体分解接到既有诊断；Q3/Q4 用同一群体标签解释风格、流动性和成交后的权重变化。复杂填补排在这之后，以实验 B 的结果决定是否值得实施。以上是待预注册的研究设计，本报告的实际验证仅包括源文献阅读、本地诊断核对和合成数学例。

本篇最重要的边界：公开论文只能帮助选择比较方法；缺失处理对本项目收益的结论，需要由当前版本、同池比较和真实成交规则下的本地 run 给出。
