# 研究者选择与非标准误差

研究日期：2026-09-12。**同一份数据得到多个版本的结果，可以暴露方法敏感性，却不会自动增加独立证据。** 对当前 Q1，先区分必须修正的测量错误、仍然合理的方法选择和真正改变策略的试验，再解释结果分歧。

## 2. 方法与主表：保留对本地有用的几件事

论文让 **164 个团队**使用同一份 2002–2018 年 EuroStoxx 50 期货数据，独立估计六类市场特征的年度趋势；**34 位评价者**随后提供反馈。问题相同，但具体度量与分析路径由团队选择。

§I.C 写成 `X_j = e_j + ε_j`：路径相关均值与抽样误差并存，团队间抽样误差可以相关；用估计值的 **IQR** 度量 NSE。Table II 在处理多重检验后，六类问题各自的团队检验家族均拒绝“没有路径均值分歧”。Table IV 首阶段至末阶段 IQR 降 **47.2%**，但逐阶段变化大多不显著；末阶段允许不交可运行代码的信念更新。

Appendix B 公开解释了相对预分析计划改用稳健分位数方法及结果对照；§II.C 则检查频率、模型等选择的敏感性。[方法与主表 PDF](https://public.econ.duke.edu/~ap172/Menkveld_et_al_2024_Nonstandard%20Errors.pdf#page=13)

这里最值得保留的解释边界是：分歧减少并不独自证明更接近真值；正式版对分析修订有交代，也不意味着任意事后更改都已获得合理性。以下为结合本地问题的独立分析，不迁移论文百分比作为项目门槛。

## 3. 六种“结果变了”，需要六种不同解释

|变化来源|固定的对象|变化的对象|本地应回答的问题|
|---|---|---|---|
|抽样不确定性|经济问题、算法、评价定义|观测月份或样本实现|有限历史下，均值有多不稳定？|
|研究路径分歧|原始数据、概念问题|合理的度量、清洗或估计选择|结论是否依赖某项选择？|
|多重检验|给定一组候选试验|尝试数量与择优规则|大量搜索后偶然选到正结果的机会有多大？|
|异象复制|原始发现及复制定义|作者、样本、实现、判定标准等|在所声明的复制规则下是否重现？|
|数据版本变化|可能连 config 都相同|输入修订、历史覆盖、公司行动|到底是哪条输入或可用时点变了？|
|实现或口径修复|想回答的业务问题|不符合该问题的旧计算|修正后是否终于测量了原本要测的东西？|

这些来源能够重叠，却不能相互替代。比如缺失值删除改变样本，可能同时引入方法敏感性和样本选择；仅增加 Newey–West 标准误并不会恢复被删除的股票。反过来，统一清洗实现也不能消除有限月份的抽样不确定性。

传统 SE 通常是在一个已选定估计程序之内计算。如果程序本身不变，换标准误带宽可能改变 t 值而不改变均值；如果更换候选池、收益定义或股票权重，改变的可能已是估计对象。不能将两类变化混在同一个“模型稳定性”数字里。

同理，多重检验与 NSE 的问题不同：前者关心整组检验的误报控制，后者关注不同路径给出的答案差异。即便所有结果都公开而没有挑赢家，路径仍然可能分歧；即便全部路径答案接近，同一历史反复搜索仍然可能产生选择偏差。

Bonferroni 可在不要求检验独立的条件下控制家族误报；在相关检验中可能较保守。这里不把它解释为“各团队结果已经独立”，也不按版本数直接乘除本地 t 值。

## 4. 原创算例：复制四次报告不会把不确定性减半

假设四种分析路径都用同一段市场历史，估计误差由两部分构成：

`误差_i = 共同样本扰动 U + 路径剩余项 V_i`。

为了手算，设 `Var(U)=4`、`Var(V_i)=1`，各 `V_i` 相互独立且与 `U` 独立。单位均为百分点的平方。每个结果的方差是 5，但四个结果平均后：

`Var(平均误差) = 4 + 1/4 = 4.25`，标准误约 **2.06pp**。

若错当四个结果独立，就会得到 `5/4=1.25`，标准误约 **1.12pp**。重复使用共同历史无法平均掉共同市场扰动。路径数量继续增加，前一种方差仍趋近 4，而不会趋近零。

这是相关证据的合成例，不是 NSE 的估计公式，也不是任何本地模型已经测得的相关性。它说明为什么“多个 run 都为正”可以作为覆盖不同选择的敏感性描述，却不能等同于多个独立市场样本。

再考虑五条路径的估计依次为 `−2、−1、0、1、2pp`。按常用线性分位数定义，IQR 为 `1−(−1)=2pp`。这个范围描述的是所列路径的离散；它不是某个收益参数的 95% 置信区间。只报告最高的 `2pp` 会丢掉分歧信息，直接把五个值平均成 0 又可能掩盖“为什么会改变符号”。

如果这五条路径其实分别用了价格指数、收益指数、整手账户、不同起始年份和不同模型，那么连上述 IQR 的业务含义也不足：它混合了不同问题，首先应拆开解释。

## 5. 对 Q1 的具体含义：先把修复和研究选择分开

本轮读取的[研究流程审查](../../研究流程审查_对标量化私募_20260912.md)已明确 Q1a–Q1d 的不同作用。下面按其定义解释；不是重新批准旧模型或改变判定门槛。

|本地变化|合理归类|如何解释新旧结果|
|---|---|---|
|Q1a：去掉模型投入运行前的准备期现金，仍保留运行后的空仓日|评价窗口修正|回答投入运行后的连续表现，同时保留准备期说明；不把仅选持股日当修复|
|Q1b：股票账户基准换为明确收益指数|基准测量修正|若只换最终报告基准，策略路径可不变；若基准进入选因子和准入，后续策略也会变化|
|Q1c：日历口径修复|输入定义修正|修正同一个经济窗口的缺日计算，不能把旧错误实现继续当作同等合理备选|
|Q1c：另行比较缺失处理方案|方法选择|需保留样本覆盖、信号尾部和预测池差异，不能只比较一个最终收益数|
|Q1d：从 96 个月准入前缀改为 48 个月|研究规则变化|改变可用证据与模型启用条件，应作为独立策略级假设，不能附带包装成纯报表修正|

“看到结果后才发现错误”不自动构成 p-hacking。可检查的是修正理由是否独立于输赢：同样的日期和费用规则是否适用于所有模型，收益变差时是否仍采用修正，旧结果和修正原因是否保留。

例如，发现比较基准受整手限制而长期只投入很少资金，修复收益基准有明确业务依据；若因为修复后跑输，又在几个收益指数里挑一个最弱的作为主基准，则变成择优比较。二者的区别在于规则是否服务于正确的问题，而非变化发生在看结果之前还是之后这一单独事实。

预注册的作用也不是把已发现的错误永久冻结。必要修复应纠正并说明；新的参数或模型选择另立版本，用后续可用验证或前向记录评价。已经反复查看过的测试段不会因为换了 run 名字而重新变成未看过的数据。

### 相同数据还不足以宣称相同问题

全 eligible 样本的原始 RankIC、行业规模中性后的 RankIC、只保留流动性较好股票的 RankIC，分别回答原始关联、控制暴露后的关联和受限可投资样本中的关联。若结果不同，先看估计对象是否改变，再看同一问题内部的方法敏感性。

同样，Top50 的账户净收益与全市场收益指数的收益差还包含暴露、交易限制和估值规则。它们不是一份纯粹的“研究者意见”样本。将所有版本简单求平均、算标准差或投票，会掩盖最需要解释的业务差别。

## 6. 只做一个复用产物的诊断：固定旧回放，追踪报告结论为何变化

**问题：** 对完全相同的历史预测和成交路径，Q1a/Q1b 的报告变化能否全部归因于窗口、基准和评价规则，而没有偷偷混入新的策略路径？

已有对象是[原 P4 回放](../../../artifacts/models/p4_follow_20260911_01/attempt_0017/replay/)及[以新等权基准重报的摘要](../../../artifacts/models/q1b_original_p4_equal_weight_reports_20260912_01/summary.json)。本轮读取后者的 `source_run`，它明确指向前者；这为检查提供具体配对，而不是用文件夹名称猜测同源。

后续仅选该冻结回放中的一个模型及 1× 成本，复用已有逐日权益、交易记录和报告。做一张小表：

|需对齐的内容|目的|
|---|---|
|来源回放、模型名、成本档|确认仍在解释同一交易路径|
|共同连续区间、首次持仓日、窗口前一个有效权益点|防止把起点移动产生的变化误归因于基准|
|策略与基准在共同窗口的累计收益|区分策略本身变化与比较对象变化|
|换手、回撤、年度胜率等每项原判定|确认结论改变究竟来自哪个条件|

如果输入策略日收益与窗口完全相同，它的累计收益应相同。若报告采用简单累计收益差 `E=R策略−R基准`，则单独换基准的差异必须满足：

`E新−E旧 = −(R基准新−R基准旧)`。

**可推翻假设：** 这一对报告的差异仅来自已声明的测量修正。若同窗策略收益也变了，或差异恒等式不成立，就先查来源、首日边界、权益口径和聚合实现；发现未解释差异即否定假设，不通过再次换窗口找一致结果。

不同起始日期、重新选因子或重新成交的版本只作旁注，不能加入这一配对诊断。[Q1d 的冻结摘要](../../../artifacts/models/q1d_causal48_calendar_missing_20260912_01/summary.json)已经属于规则变化后的另一条路径，且含旧 SUE 的已知待修事项，不能与这两个报告一起当成三个独立成功或失败证据。

输出只需解释清楚这一个配对。不需要重跑回测、枚举所有方法组合或新建多版本管理体系；新结论应是“哪项测量或路径改变了答案”，而不是“更多版本投票通过”。
