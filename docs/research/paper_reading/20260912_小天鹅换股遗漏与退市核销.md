# 小天鹅换股遗漏与退市核销

2026-09-12。目标：从已发现的缺标签持仓中核实一次公司行动；时间盒30分钟。结论：保存的 SUE v2 LightGBM 回放确实遗漏了小天鹅换股权益，把400股持仓核销22,956元。2019全年244个交易日账户重建的市值差为0，损益残差最大4.26×10⁻¹⁰元，足以把问题定位到已保存账户，而不是只凭缺标签推测。

## 1. 发现路径与固定范围

[头部预测与换股价值诊断](20260912_SUE修复后头部预测与换股价值.md)中的 `replacement_members.parquet` 显示：000418.SZ在2019-04-30属于继续持有目标，2019-05-31属于失去预测资格的退出目标，均无完整收益标签。继续核查对应实际账户，发现它在退出目标后仍有持仓，随后被核销。

固定对象为 `q2_sue_context_v2_causal48_20260912_02` 的 `lightgbm_top50/cost_1/2019`。复用2018年底账户、2019保存成交和NAV，以及原回放配置指定的数据快照，通过现有 `read_battery_execution` 和 `lagged_exposure.reconstruct` 重建全年账户。这里是在核对已发生的模拟记账，没有选择新的策略参数。

完整证据：[分析规格](../../../artifacts/research/paper_reading_little_swan_merger_20260912_01/analysis_spec.json)、[可复运行脚本](../../../artifacts/research/paper_reading_little_swan_merger_20260912_01/analyze.py)、[结果摘要](../../../artifacts/research/paper_reading_little_swan_merger_20260912_01/summary.json)。

## 2. 官方条款与本地账户不一致

实读美的集团2019年6月新增股份上市公告书印刷页3、4、26、29：小天鹅A最终换股比例为 **1:1.15144821**；换股登记日2019-06-20，登记在册股东自动转换；新增股份上市日2019-06-21。公告同时披露此前现金分红及比例调整，因此旧方案1:1.2110不能直接使用。[巨潮资讯官方公告](https://static.cninfo.com.cn/finalpage/2019-06-19/1206364891.PDF)

## 3. 该怎样解释金额

400×1.15144821＝460.579284，是按比例计算的理论股份量。后续实读独立财务顾问2019-05-23核查意见第10页“零碎股处理方法”：按股东尾数排序分配剩余整数股，同尾数超过剩余股数时随机分配。因此本例到账量应在460或461股中，无法只凭400股持仓恢复确切结果，不能直接四舍五入认定461股。[原始核查意见](https://static.cninfo.com.cn/finalpage/2019-05-23/1206296152.PDF)

冻结行情中美的6月21日、24日收盘分别52.11、52.18元。以6月24日价格计算，460与461股对应24,002.80与24,054.98元，差52.18元。整数分配不确定性远小于漏记整笔权益，但应在修复中明确保留，不应按交易买入整手截成400股。

该22,956元是保存账户的核销金额，不是修复后完整策略收益的增加值。正确处理会改变股份、市值、以后调仓与现金，必须从事件日起重新回放，才能计算修复后的年化与超额。

另一个容易重复计量的项目是分红：本地输入已有小天鹅4元/股的4月分红，以及美的5月分红，见[保存分红输入](../../../artifacts/research/paper_reading_little_swan_merger_20260912_01/saved_dividends.csv)。新增的6月换入股份不能追领美的5月登记日分红；修复也不能再给旧小天鹅持仓重复支付已处理的分红。

## 4. 最小修复与验证建议

当前[回放实现](../../../src/quant/research/classic_monthly_baseline.py)在配置退市持仓零回收时按摘牌日期清除持仓。应先识别已公告的股份转换：以生效日期记录旧代码、新代码、最终比例和股份可交易日期，将旧权益转成新权益，再处理没有此类承接事件的终值规则。历史财务与预测数据仍保留原证券时点，不能把一次公司行动变成全历史代码替换。

定向验证应覆盖已有400股小天鹅、没有原美的持仓的实际情形，以及同时持有两者时数量相加的情形；检查股份转换不会产生买卖费用，不重复分红，换入股份按其可交易日期及零股卖出规则处理。随后重跑受影响账户，保留原始run，用差异报告说明公司行动修复的影响。

前一轮[退市专题](20260912_退市收益与幸存者偏差.md)核对的是三次代码更换与一次真实摘牌，八个模型—事件组合没有持仓；这个结论仍成立。本次是从另一只实际持仓发现的吸收合并遗漏，提示公司行动样本必须同时覆盖“无暴露”和“有暴露”的情况。

已将本例及官方条款单独通知主进程，由现有回放模块负责人修复。当前关键限制：尚未完成正确换股后的全账户回放，不能据此修改策略准入结论。
