# SUE 修复后：换手解释是否仍然成立

2026-09-12。复用新完成的 SUE v2 模型产物，回答上一批研读留下的两个问题：高换手是否随输入修复消失，缺失收益标签是否集中于预测高分组。

**SUE v2 改变了选股及历史收益，但没有消除高换手。** 剔除首次建仓后，月均替换从 41.59/50 变为 41.58/50；两版同月 Top50 平均重合 39.54 只。2024 年高分五分组的缺标签率均为 0.208%，其余组未呈现简单单调关系。下一步应沿修复后的固定模型解释头部机会与交易代价，不能把收益提高当成换手问题已解决。

关键限制：这是相同已研究历史上的版本对照；既不增加独立测试样本，也不识别那些缺失标签本应取得的收益。

## 2. 同一把尺子下，主要换手现象没有改变

累计目标换手是相邻股票权重绝对变化和的一半；实际换手是逐日成交额除以两倍前日权益。两个定义各自保持不变，阶段差额不作因果贡献解释。

| 指标 | 原 SUE | SUE v2 |
|---|---:|---:|
| 未缓冲目标累计单边换手 | 80.02 | 79.68 |
| 缓冲目标累计单边换手 | 76.20 | 76.18 |
| 实际累计单边换手 | 74.58 | 74.76 |
| 建仓后每月平均替换只数 | 41.59 | 41.58 |
| 同一年度模型内平均替换只数 | 41.46 | 41.43 |
| 年度模型切换时平均替换只数 | 43.14 | 43.43 |
| 同年度相邻共同股票分数秩相关均值 | 0.613 | 0.640 |
| 退出时无当月有限预测的次数 | 914 | 922 |
| 有预测但落到第 75 名以后的次数 | 2,871 | 2,862 |
| 有预测退出时的排名中位数 | 587 | 577 |
| 有预测退出中落在第 76–100 名的占比 | 5.12% | 4.86% |

v2 原始输出：[换手汇总](../../../artifacts/research/paper_reading_q2_sue_v2_turnover_20260912_01/summary.json)、[成员转换汇总](../../../artifacts/research/paper_reading_q2_sue_v2_turnover_20260912_01/rank_summary.json)、[退出排名距离](../../../artifacts/research/paper_reading_q2_sue_v2_turnover_20260912_01/rank_exit_distance_summary.json)。

这组结果同时支持三点。第一，普通月份依旧大量换股，不能只盯年度重训。第二，整体相邻秩相关有所提高，但最前面 50 个位置的保留没有相应改善；它与[排序学习专题](20260912_排序学习与TopK稳定性.md)区分整体排序和头部成员的分析一致。第三，大多数排名退出仍离第 75 名较远，小幅扩大缓冲的效果需要真实配对路径，不能按当前排名区间直接估计节省交易数。

922 次没有当月预测的退出，连接保存输入后分为：910 次 `eligible=false`、4 次资格有效但控制输入无效、8 次无对应股票池行。失败标志中流动性 841 次、涨跌停距离 71 次、风险名称 2 次；标志可以重叠，不能相加作为互斥分解。[输入分类](../../../artifacts/research/paper_reading_q2_sue_v2_turnover_20260912_01/absent_prediction_input_summary.json)

两版预测池的键相同，却可以有不同数量的“无预测退出”：每个版本前月持有的目标不同，遇到下一月资格变化的股票也就不同。这个例子说明，预测池边界与组合自身路径共同决定退出数量。

## 3. 收益变化与换手变化应分开解释

既有共同区间比较显示，Top50 在 2019-01-02—2026-08-31 的 1× 成本年化从 19.41% 变为 22.29%，最大回撤从 −37.47% 变为 −38.75%，压力窗口由 3/4 变为 2/4；两版均未满足完整准入条件。[已完成模型对照](../../../artifacts/models/q2_sue_v2_vs_old_common_20260912_01/report.md)、[v2 完整结论](../../../artifacts/models/q2_sue_context_v2_causal48_20260912_02/reports/lightgbm/report.md)

本次补充的同月成员比较显示：92 次信号中，两版 Top50 平均重合 **39.54 只**、中位数 40 只。虽然总体换手几乎不变，买入和卖出的股票身份已经改变。因而不能用“换手没下降”否定修复的研究意义，也不能把收益变化解释成交易次数减少；还需分开看头部选择、不同股票的收益路径和各笔交易成本。[同月成员明细](../../../artifacts/research/paper_reading_q2_sue_v2_turnover_20260912_01/same_month_target_overlap.csv)

缺失率总体较低，最高分组的缺失率略高，但各组之间没有简单单调模式。这些是股票—月份计数，不能当作相互独立的市场样本来给出很窄的统计区间，也不能据此认定缺失机制随机。五分组也远宽于 Top50；已有三笔正目标的停牌拒单与延期退出记录，比单独一个总体覆盖率更接近账户问题。

此表回答“哪些分数组难以获得固定期限标签”，没有补出这些股票的固定期限收益。由此尚不能判断它们使 RankIC 高估还是低估；更不能把更晚的成交结果提前写成原退出日标签。
