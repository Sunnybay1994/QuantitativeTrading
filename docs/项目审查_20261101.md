## 0. 结论

1. **执行纪律明显变好，研究产出仍然太少。** 上一轮的"自行宣布闭合"没有再出现：每项都如实标了 waiting / 未通过，`quant doctor` 每日产出红项，快测试从约 15 小时降到 503 秒（7054 passed），注册表污染已隔离，港美分钟三段调度完整率 ≥99.8%。但 6 天 153 次提交（fix 65、docs 48、test 23、feat 12），只产出 7 个策略级结果（S1 四个、S2 三个），全部 RESEARCH_ONLY。清单文件被执行日志撑到 30.6KB，违反 AGENTS 的 md ≤30KB 规则。流程从"假完成"矫枉过正成了"证据仪式"。
2. **Q10 样本外第一个完整月：−9.03%，同期全市场等权 −12.75%，超额约 +3.7pp。** 绝对亏损来自市场（10 月创业板 −23%、科创 50 −24%）。连续三个观察点都是"下跌少跌"。
3. **更正我在 10-26 的一个判断。** 我当时说"Q10 的超额主要是低波风格、不是 SUE"，并建议把库里最强的低波/流动性/价值机制直接组合起来。S1 回放否定了这个判断：M1–M4 四个组合的 2× 超额比 Q10 低 7.3–9.8pp，去掉 SUE 只再降 0.6pp。所以 Q10 的超额来自它的 SUE-context 模型本身，不能用一篮子低波股复制。低波风格只解释了它在急跌月份的防守表现（A1 的 2026-07 归因），不解释长期超额。基于错判提出的"多机制组合替代 N5"方向就此关闭。
4. **最接近"十几只、可人工操作"的结果已经出现**：S2a Q10-Top15 在 100 万档，年化 22.1%、1× 超额 9.6pp、2× 超额 7.5pp、最大回撤 −30.2%，只差压力窗一项。问题是每月 81.9 笔订单，人工做不了；10 万档时整手约束导致 55% 的订单被拒。下一轮要做的是这个版本的"人工执行化"，见清单 R2。

## 2. 本次新发现的问题

1. **月末信号链在最关键的那天失败了。** 10-30 是月末信号日，21:30 日更 exit 1：影子账户的股票池缺 10-30 交易日，连带月度对比报告失败。Codex 凌晨 03:02 修复（`b36eba3e`），Q10 订单在 10-31 01:53 才重新生成。一个辅助账户的错误阻塞了主账户订单，这是架构问题，不是偶发 bug。
2. **情报管线产出的是"挂着论文标题的通用量价表达式"。** W45 digest 把《The Generalised Kessler Syndrome and the Persian Gulf》（轨道碎片与地缘）标成"换手率与日收益的秩相关"，把 Hawkes 过程、整数关口等论文都映射成同一类量价秩相关，8 个都自动入队。来源出处是编造的，本质是 GP 噪声。
3. **GP 继续占用大部分算力且零产出。** batch 71–80 共 0 准入，处理队列积压 41 个 ngp 候选。10-26 研究思路里"GP 降到每周 1 批"的建议没有被执行，原因是它没有写进清单——执行 Agent 只做清单里的事，这是对的，但说明建议必须进清单。
4. **LLM 10 月花费 $7.36**（S4 抽取 $5.00、文本打分 $2.06），在 $30 总预算内，但 S4 超出了它自己的 $5 上限，产出质量低（见 S4）。
5. **代码与文档规模**：`src/quant` 约 19.9 万行（research 7.7 万 / 312 文件，data 4.4 万，execution 3.5 万，backtest 1.7 万）；配置 2,341 个 toml（`configs/research` 顶层 227 个）；文档 1,589 个 md（其中归档 1,252）；测试 620 个文件。对一个个人项目、一个候选策略来说，大约是需要的 5 倍。

## 3. 框架优化建议

按对"赚钱"的影响排序。前三条进入新清单，其余交给结构整理任务或延后。

### 3.1 把"订单链"从日更里剥出来，成为最高优先级的独立任务（新清单 K1）

Q10 和影子账户的"信号 → 目标 → 订单 → 推送"是唯一直接决定钱的路径，应与市场背景、因子健康、月度对比、分钟补数等辅助步骤**解耦**：订单链只依赖冻结预测和当日行情；辅助步骤失败只告警，不阻塞订单。另外加三道保险：
- 月末前一交易日 21:30 做一次"假装明天是月末"的订单链预演（只生成不推送）；
- 月末当晚 22:30 未产出 `latest_orders.md` 即发通知；
- doctor 首行显示"下一次调仓日 / 订单是否就绪"。

### 3.2 修订任务书规范：证据要够，但不能变成仪式（已写入 [任务书规范](任务书规范.md) §6）

要点：清单 ≤10KB，每项状态一行，过程写 `artifacts/worklog/`；等待日历门槛的项在门槛日前不追加记录；每项每天最多一次文档提交；doctor 增加"本周策略级新结果数"，连续 7 天为 0 即红——这条对应 AGENTS 的"连续一周只有重构没有研究产出视为失灵"。

### 3.3 算力与 LLM 重新分配（新清单 C1、L1）

- GP N2 每周 1 批；N5 月度三模型关闭（连续两月全 REJECTED，且 S1 已说明简单组合无效）；N3/N4 只处理预注册族系和 Top15/账户组合需要的回放。
- 情报管线停止自动入队，只产出 digest；候选必须引用论文中的具体公式或段落，否则丢弃。
- S4 改为"结构化接口优先，LLM 只补缺失字段并抽样核对"。
