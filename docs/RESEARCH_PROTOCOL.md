# 研究协议

目标：用真实资金赚到经风险调整后为正的收益。机器挖因子、评估、回测；人做文献假设、读结果、策略级决策。

## 两条轨道

- **因子轨道**：表达式进 `configs/factors/library/` 或 `queue/`，流水线批量出 scorecard。不为单因子写假设卡。
- **假设轨道**：只给模型 / 组合规则 / 策略级命题。版本化 config + 不可覆盖 run 目录 + 机器 `report.md`。

## 判定口径

因子 `ADMITTED`：≥96 个月，|NW t|≥3，ICIR≥0.3，年度符号一致率≥70%，多空 Sharpe≥0.5，与更高分因子最大秩相关<0.7，Top 组 1× 成本后超额全市场等权>0。

模型 `PAPER_CANDIDATE`：walk-forward 按**实际持股期**；基准必须是收益指数；1× 超额最强基准≥3pp，2× 仍为正，Sharpe≥0.6，换手中位数≤6×（6–8× 且 2× 超额≥5pp 视为通过），回撤不劣于基准 1.2 倍，压力窗口有效者至少 3/4。空仓窗口标不适用。

结论只有 `REJECTED` / `RESEARCH_ONLY` / `PAPER_CANDIDATE`。≤3 年 Top-K 收益差不作判定。

## 自动化挖因子

持续挖掘（白天也跑）：队列摄取 → GP（种群 200 / 30 代 / 深度 5）→ 全历史电池 + 增量 IC → 入库 `library/auto/` → 月度重训。本地 GP 不调用 LLM。

每周 DeepSeek 候选：`$5/周`、`$30/月`，提示含库清单。`python -m quant intel scan` 把 arXiv/GitHub/RSS 炼成 DSL 写入同一队列。LLM 不直接下单，不直接改门槛。

## 时间与成本

信号收盘后生成，最早下一开市日成交。财务按公告日 PIT。A 股 T+1、整手、涨跌停/停牌不可成交；报告必须含 0.5×/1×/2× 成本。分钟数据只做低频化日频因子、调仓时点、以及成本地图比值≥20 的 T+0（主要黄金 ETF）。不做秒级/盘口。

## 结果落点

人工延迟压力对照：已完成信号后，下一个5分钟窗口按最高价买入、最低价卖出，
另计统一三档费用与滑点。极值仅用于事后不利计价，不能参与当时的信号、选股、
订单数量决策。总延迟落在窗口内时使用整窗极值；延迟跨过窗口终点时顺延到
可提交时刻所在窗口。缺失窗口不得跳到之后的有利行情补成交。该方法是价格压力
测试，不证明盘口容量、限价排队或真实成交；仍披露未成交与退出容量不足。

卖出资格按具体证券规则：T+1仅可卖前日可用份额，当日新买份额冻结；T+0可卖
当日买入份额但不得裸卖。股票ETF、黄金ETF、债券ETF不得按统一ETF规则处理。
港股通当日回转与T+2交收分别建模，按标的核验交易日历、每手数量、价位、税费、
币种及资金可用性；当前A股ETF原型不因这一说明自动支持港股通。

## 当前研究优先级与反馈

2026-09-24 用户调整个人账户研究口径：10万元账户允许横截面综合评分集中持仓，新增实验主方案先固定Top5、单笔最低佣金1元；注册在 `configs/research/personal_top5_fee1_v1.toml`。用Top5/Top50与1元/5元的预先固定配对对照区分集中持仓和费用变化，均保留三档成本、历史税费、滑点及整手执行。1元是佣金下限，不是每笔固定总费用。原冻结电池、旧账户与旧结论不覆盖，新研究按新配置生成独立机器产物。少量持仓单独定义集中度约束，不照搬Top50的单票3%和旧联合账户调仓预算；原正式准入门槛不变，不能用短窗口或新增风险暴露冒充alpha。

`configs/research/research_priorities.toml` 保存研究目标和优先级；成本后 Sharpe 1.5 是研究目标，不替换上述准入门槛。报告应明确无风险利率，固定 0%/2% 仅作统一敏感性对照，2% 不是历史实际利率；收益指数须匹配持股期，主动收益 IR 不等于策略 Sharpe。现有 Q10 诊断及 R3 风险归因路径在配置中登记，不能把归因代理基准当准入基准。

持续调度在每轮结束汇总已完成 N3 电池的统计失败、家族、衰减、训练/全历史指标和基准缺口到 `artifacts/research/feedback/feedback.json`。未完成批次单列，不记零通过；数据缺口和预测失败分别记录；全历史电池不冒充独立验证。新周度请求纳入最近三批汇总，冻结后的请求不回写。低相关不代表预测能力，旧批次适应度和既有准入门槛不改。

跨股票样本搜索仅按 `configs/research/gp_cross_stock_v1.toml` 注册规则执行一次电池：三组互不重叠的股票全部用于训练，最弱组方向调整IC进入搜索目标；不把任一组称为独立测试集。调度在当前未完成批次之后冻结配置并创建一次，恢复时核对目标与股票分组，结果不得通过追加种子或参数网格挽救。已观察的历史区间用于描述性诊断，独立前向证据只能在候选及方向冻结后积累。

后续 `gp_stock_time_stability_v3.toml` 针对预测稳定性失败注册一次电池：
三组股票分别在固定训练日历的前后两半测算IC，方向由完整训练期统一确定，
六块均须正向且覆盖合格；搜索最大化最弱块IC并保留复杂度惩罚。
控制相关性只作冗余上限，不再用大幅相关性扣分偏好弱信号。
当前批次及旧断点不改，下一个新批次冻结执行一次；全部块都是训练资料，
历史诊断不算独立验证，原入库电池与三档成本不变。B16执行验证并行推进。

后续 `gp_predictive_priority_v2.toml` 是另一项已注册的一次实验：三组预测能力为主，仅在最弱组IC相差不超过0.001的候选间比较与冻结控制的相关性，并要求实际引用预先列明的财务机制终端。训练截止2025年底；保存全部尝试及拒绝原因，候选仍走原全历史电池。不能把改变搜索目标后的批间差异解释为因果改进，也不能把已见历史称作独立测试；前向从候选和方向冻结后的下一交易日开始，最早2026-09-21。

该批前向月度观察固定取每个信号日最早完整、开盘前保存的记录；同一最早时间存在值或股票池冲突则排除并提示，不按收益选记录。只有月末信号的下一开盘至次月末下一开盘收益成熟后才评分，方向、原始/中性化版本、股票池和测量设置沿用冻结电池，跨日口径漂移不混合；停牌或缺失价格不跳日、不填零。月度 RankIC 是信号观察，不等同成本后组合收益或准入，原准入与模拟账户规则不变。

优先研究与 SUE 不同来源的小容量非信息压力反转，先查数据覆盖、表达式重复、衰减和退出冲击，再决定新机制电池。分钟机制须已有足够 PIT 覆盖。不得仅换窗口重复已否定的 Q1–Q9/P7/Q6；组合假设最多一个且先预注册。资金档位最多两档，仅允许 10 万元和 100 万元；按需选一档或两档，不强制每次双档回放。资金档位与 0.5×/1×/2× 成本档独立；历史结果保留原资金标注。这些是候选设计约束，不代表新策略已验证或自动启动账户回放。

策略报告提供年度、月度累计收益、基准收益、超额（百分点）、日频年化夏普（rf=0 及固定2%敏感性）、区间最大回撤。期初采用前一交易日净值，包含期初亏损；首次持仓前现金期排除，后续现金期保留。边界期间单列，基准缺日或未换汇不计算超额。看板支持策略简述及下载期间报告；自动模型报告按年度拆分月度明细，避免巨型文档。

## 旧策略的研究保留（2026-09-17 用户调整）

回撤、换手、恢复期、压力期和年度超额稳定性可作为研究风险提示，允许优秀收益证据的旧策略从研究淘汰转为 `RESEARCH_ONLY`，不自动放行模拟盘或交易。`configs/research/strategy_retention.toml` 固定本次筛选：持股跨度至少5年，1×同期最强基准年化超额≥5pp或1×夏普≥1.5；原收益、2×成本、最低夏普、有效持仓证据检查必须通过，失败项仅限上述风险项。数据/执行约束未验证、未知失败项及因子电池不适用放宽。历史原判定不覆盖，看板并列复核结论与原判定；既有同一净值的正式更新复核优先展示。

`python -m quant report review --output artifacts/reports/<新目录>` 生成全量机器复核与保留清单。看板按当前配置动态复核并显示标签；分类来自冻结配置，日线回放和输入频率分别理解，中性化信号不等于市场中性策略。此次历史复核不构成新样本验证，不据此反复调参。
