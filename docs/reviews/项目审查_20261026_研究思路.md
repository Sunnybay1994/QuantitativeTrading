# 项目审查（2026-10-26）· 研究与挖掘思路的改进方向

> 配合[复核报告](项目审查_20261026.md)。本文只谈"为什么 76 批挖掘没有产出第二个策略，以及该把算力和 LLM 预算换到哪里"。所有数字来自已有产物，不含新回测。

## 1. 诊断：挖掘管线在一个已饱和的空间里搜索

事实：
- 76 批 / ≈1,500 个 GP 候选 / 3 个准入 / 0 个进入策略；三个准入因子叠到 Q10 上增量 **0.02pp**（`q10_plus_admitted`）。
- N5 三类模型（等权 z、正均 IC 加权、LightGBM）对全部准入因子逐月重训，2026-10 全部 REJECTED。
- 全库 386 因子的机制级中性 IC（`artifacts/research/market_mechanism_20261004_01/family_summary.parquet`，146 个月）：

| 机制 | 月均中性 IC | 上涨态 | 下跌态 | 备注 |
|---|---:|---:|---:|---|
| mined_mixed（GP 已入库） | 0.056 | 0.054 | 0.064 | 与低波/流动性高度重叠 |
| volatility_risk（低波） | 0.052 | **0.078** | 0.030 | 库内最强且最稳 |
| liquidity_activity（低换手/非流动） | 0.051 | 0.051 | 0.051 | 状态无关 |
| value_dividend | 0.044 | 0.057 | 0.038 | 跨年稳定 |
| reversal | — | 0.008 | **0.069** | 只在下跌态有效，换手高 |
| growth_surprise（SUE 所在族） | 0.013 | 0.018 | 0.009 | **Q10 的名义机制其实很弱** |
| momentum | −0.027 | −0.047 | −0.042 | A 股反向，符合常识 |
| price_trend_position / price_bar_shape / volume_activity（GP 主要搜索的价量形态，224 个因子） | ≈0 | ≈0 | ≈0 | **GP 在这里花了最多算力** |

含义：
1. **Q10 的超额主要不是 SUE**。A1 归因 2026-07 主导风格是 volatility；全库 growth_surprise 机制 IC 只有 0.013；样本外三周"下跌少跌" +2.3pp 也是低波特征。Q10 = "SUE 选股 + Top50 + 0.5 换手预算" 在实践中选出的是一篮子低波质量股。这解释了用户的直觉（上涨市超额薄）。
2. **GP 搜索的算子空间（价量形态）在这个库里 IC≈0**，再搜 1,500 个也只能产出低波/流动性的同构体，而 N4 的"与 386 控制最大秩相关 <0.6"又把这些同构体挡在门外。搜索目标与门槛共同保证了"0 准入"是稳态，不是运气。
3. **库里最强的 3–4 个机制从未被组装成一个过线的策略**。N5 把全部准入因子一视同仁地训练，被弱因子和高换手因子拖累；没有人做过"低波 + 流动性 + 价值/股息 + SUE，固定权重，换手预算"这种最朴素的多机制组合并走 §1.2。

## 2. 思路转向：从"挖因子"到"做第二条腿 + 换数据"

### 2.1 研究单位改为"策略级预注册假设"，KPI 改为"每月 ≥2 个完整走完三档成本的策略假设"

GP 批次数、候选数不再是进度指标。注册表里 `level=strategy` 且 `design_date` 在当月的行数才是。

### 2.2 先把库里已有的东西用掉（零新数据，2 周）

预注册一个**多机制固定权重组合族**（一个 toml，4 个成员，不做网格）：
- M1 低波 + 流动性 + 价值股息 + SUE 等权 z，Top50，0.5 换手预算（与 Q10 同构建，便于对照）；
- M2 同上去掉 SUE（检验 SUE 的真实边际贡献）；
- M3 M1 + 规模中性（A5 已证明规模中性把 MDD 从 −31.6% 压到 −25%、2024-01 窗从 −23.9% 到 −15.4%，只是反弹窗跑输）；
- M4 M1 季度调仓（换手预期降到 2–3×，检验低波类机制是否容忍更低频）。
判定仍走 §1.2；额外报告"vs Q10 同窗 2× 超额差"和 A2 的滚动列。任何一个成员 2× 超额 ≥ Q10 + 1pp 且压力窗 ≥3/4，才开第三个模拟账户。**这是对 N5 的替代，不是补充**：N5 继续跑但不再是产出路径。

### 2.3 第二条腿必须是进攻型（1–2 个月）

Q10 在上涨态跑输是结构性的。分散价值只能来自上涨态有效的机制：库内 `volatility_risk` 上涨态 IC 0.078、`value_dividend` 0.057、`intraday_aggregated` 0.045；`reversal` 只在下跌态有效。可行方向：
- **进攻腿 O1**：日内聚合类（`intraday_aggregated`，60 个月样本，IC 0.030/0.045）+ 价值股息，月频，0.5 预算；样本短是硬伤，先作 RESEARCH_ONLY 前向账户积累；
- **进攻腿 O2**：ETF 轮动的进攻版。B13/B16 现有的是防守配置；用同一框架做"行业/风格 ETF 动量 Top2，月频"的进攻版（ETF 层面动量在 A 股成立，个股层面不成立），和 Q10 的相关性天然低；
- 组合层：Q10 + 进攻腿按**固定 50/50 风险平价**（不择时、不切换，Q6 overlay 禁令不受影响），作为路线图阶段 C 的提前量。阶段 C 定在 2026-12，但现在只有一条腿，提前到 11 月做并不违反任何冻结项。

### 2.4 换数据，不换算子（LLM 的正确岗位）

GP 的边际收益已经为零；**数据是护城河**。以下数据项目当前都没有、且日频可得：
| 数据 | 来源 | 可形成的事件/因子 | LLM 角色 |
|---|---|---|---|
| 业绩预告/快报（类型、幅度、修正） | 巨潮公告（已有 `cninfo_announcements` 连接器） | 预告惊喜（A4 的 S4）、预告→正式报差 | 从公告文本抽取结构化字段（类型/区间/原因），不做情绪打分 |
| 股东增减持、回购实施、限售解禁 | 巨潮 / Tushare 已有权限表 | 内部人净买入、回购强度、解禁压力 | 抽取金额/比例/期限 |
| 分析师预期变动 | Tushare `forecast`/一致预期（若权限内） | 预期修正动量 | 不需要 |
| 融资融券余额 | Tushare `margin_detail` | 杠杆拥挤度、融资买入占比 | 不需要 |
| 北向持股变动 | Tushare `hk_hold`（若未停） | 外资净流 | 不需要 |

LLM 抽取成本：DeepSeek 按每份公告 ≈2k tokens 计，每天 100–200 份目标类型公告约 $0.05–0.2，月 ≤$5，远低于 $30。**与被拒的 P7 的区别**：P7 让 LLM 给"预测文本"打情绪分（主观、不可复核）；这里让 LLM 做结构化抽取（客观字段、抽样可人工核对），输出先进因子库走同一电池。预注册族系 `event_family_v1`，每类事件一列，先做增减持与回购两类（样本最充分）。

### 2.5 评估口径的两处调整（不改 §1.2 门槛）

1. **N4 冗余规则从"最大秩相关 <0.6 淘汰"改为"同族替换"**：相关 >0.6 的候选若增量 NW-t 更高，替换族内旧成员而非被淘汰。当前规则让任何更好的低波变体都进不了库。
2. **GP 残差目标（B1）的控制集加入低波、流动性、价值股息三个机制代表**，否则残差搜索会继续找到低波同构体。同时 GP 批次节奏降到每周 1 批（算力让给 2.2/2.3 的策略回放），直到残差目标产出第一个增量 >0.5pp 的候选再恢复。

### 2.6 样本外纪律与资金

- Q10 任何参数不再动；A5 的规模中性变体以**影子账户**（零资金、同一账本代码）从 11-02 起前向记录，6 个月后再比较。
- 真金分级（A §5）仍由用户决定；建议门槛改为"两份真实月报 + 影子账户同步运行"，不绑定日历。
- 个人账户容量：10 万元 × Top50 = 每票 2,000 元，大量股票一手买不起；若真金是 10 万档，Q10 必须有 Top20–30 版本并单独走 §1.2（这是 2.2 之外唯一允许的 Q10 派生假设）。
