个人量化投研与交易系统。**投研是重点**：后台自动挖因子、自动扫描前沿论文/开源仓库并提炼策略假设、自动 LLM 分析（DeepSeek）。**交易只预留接口**：无实盘 API，订单以邮件 / 企业微信 / 飞书 / wxauto 推送给人工执行。最高优先级是**不破坏正在产生收益证据的东西**：Q10 观察账户、S0 与 8 个既有观察账户的日更、持续挖因子。

## 2. 原则

1. **不重写回测器与数据面**：它们产出了 Q10 的全部证据；改动只限"搬走死代码、加门面、加新模块"。
2. **死代码进 `legacy/`，不删**：Git 有历史，但 `legacy/` 让复现旧结果时 `PYTHONPATH=legacy` 即可。
3. **新能力独立成包**（`core/llm/notify/intel/cli`），只依赖现有模块，不被现有模块依赖（避免循环）。
4. **一个入口**：`python -m quant <组> <命令>`；PowerShell 脚本只做调度与互斥，不含业务逻辑。
5. **文档三层**：`README`（定位+架构+快速开始）→ `docs/` 6 份长期文档 → `docs/archive/`（一切按日期命名的实验页）。
6. GPU 是配置项（`QUANT_DEVICE=auto|gpu|cpu`），失败自动回退 CPU，不成为阻塞。
