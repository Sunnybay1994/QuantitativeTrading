## 2. 运行面隐患（按严重度）

1. **注册表被测试污染**：48 行来自 pytest 临时目录。影响排行榜、简报、`quant status` 的结论分布。修法：`experiment_registry.append` 拒绝 `run_path` 不在仓库内的行；测试用 `QUANT_REGISTRY_ROOT` 指到 tmp；清洗现有行并记录。
2. **持续挖掘实际停滞**：10-09 → 10-26 仅完成 batch 71–75（100 候选 / 0 准入）。batch_075 N3 三次 `GP_CONTEXT_ALIGNMENT` 失败、两次人工 `manual_clear`；batch_076 N2 当前失败：`Frozen GP context source checksum changed: data/clean/bar_intraday/freq=5m/source=baostock/symbol=300001.SZ` —— **月频 GP 上下文竟校验 5 分钟线文件**，而 BaoStock 分钟写入器与 GP 冻结期互斥没生效。修法：GP 上下文输入清单只含日频/财务表；分钟写入器与 GP 完全解耦。
3. **7 个计划任务中 5 个最近一次非零退出**：IntelWeekly(1)、MinutesRecent(1)、MinutesHistory(2)、PostCloseK1M(1)、PostCloseK1M-HKUS(1)、RealtimeQuotes(1)。没有任何一处汇总显示这件事。修法：`quant status` 读取 `Get-ScheduledTaskInfo`，非零即红；所有 `.ps1` 改 ASCII-only 或强制 BOM，加单测扫描。
4. **日更 10-21 不完整**（150 MiB 公告 PDF 超 128 MiB 硬门导致整晚退出），10-23 手工重跑 4 次；Q10 账户缺 10-23 日记录。修法已在工作区但未提交。

## 3. Q10 当前事实（样本外第 3 周）

- 模拟盘：09-30 建仓信号，10-08 开盘成交，10-22 权益 944,491（−5.55%）；同期全市场等权（5,222 只，复权收盘）−7.84% → **样本外超额 +2.3pp**（自 10-08 收盘起 +2.6pp）。再次是"下跌少跌"模式，和 A1 归因（低波风格主导）、2026-07 的表现一致。
- 这意味着 Q10 的超额有相当部分是**低波/质量风格暴露**而非 SUE 本身。这不是坏事（能赚钱即可），但决定了三件事：① 上涨市会继续跑输等权；② 第二策略必须是**进攻型**才有分散价值；③ 对 Q10 做"增量因子"搜索时，控制集里应加入低波/质量，否则会继续找到同风格的东西（三个 ngp 因子增量 0.02pp 就是这个结果）。
- 决策仍待用户：A §5 的 10 万真金分级。当前证据不支持也不反对，建议至少等 11-02 首份真实月报与第二次调仓（10-30 信号 / 11-02 执行）。

## 4. 框架进一步优化（按收益相关度排序）

1. **一个 `quant doctor`**：串起 计划任务退出码 / 最近批次状态 / 日更完整性 / 注册表完整性（无仓库外路径、无重复 experiment_id）/ LLM 账本定价完整 / 未提交文件数 / 根目录杂物。每日 21:30 后随日更推送；任何红项即通知。它替代"验收记录"——验收由机器每天重做。
2. **注册表与排行榜去重**：以 `experiment_id + variant + 口径版本` 为主键；同一策略的重算（r1_calendar、r1_rolling、sizing 对照格）作为 `aliases` 挂到主行，不单独占行。排行榜按 2× 超额排序，Q10 只出现一次。
3. **调度解耦**：数据写入（分钟、BaoStock、Futu、公告 PDF）与研究计算分属不同进程，用文件锁；GP 上下文只校验自己真正读取的表。128 MiB PDF 这类单点异常只能让该步骤 `unresolved`，不能让整晚退出。
4. **测试分层**：`unit`（<10 min，默认）/ `integration`（夜间）/ `legacy`（不收集）。CI 没有也行，但 DailyObservation 开头跑 `unit`，失败即退出并通知。
5. **真正把冻结的搬出去**：`research/m3`、`data/m3_*`、`execution/{store,session_barrier,soak,service,contracts,paper_broker_store,paper_formal_*}` 整体移 `legacy/`，`_legacy_shim` 保留导入兼容；`src/quant` 剩余 >1500 行的只保留 `a_share_reporting`/`schemas`/`query` 三个并在下月拆。这件事做完 `src/quant` 体量下降约一半，`pytest` 时长同比例下降。
6. **LLM 预算与账本**：价目表进 `configs/llm/pricing.toml`，随代码版本冻结；每笔调用必须有 `usd>0` 或 `estimated=true`；`budget.py` 读账本而不是 sqlite 缓存。gp_hints 每批一次；weekly candidates 周日自动；intel 周日自动；brief 月初自动并调用一次 LLM 写归纳段。四个岗位每月合计 ≤$10 即够。
7. **报告"口径头"**：所有 report.md 顶部机器写入 设计日 / 数据截止 / 样本外月数 / 基准快照 id / 成本档 / 代码指纹。已有字段，统一到 D1 出口即可。
8. **提交**：DailyObservation 结束 `git add src configs docs tests && git commit -m "auto: <date>"`；根目录 `_*.py` 进 `.gitignore` 或删除。
