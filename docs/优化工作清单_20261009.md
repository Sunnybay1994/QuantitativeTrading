## 0. 执行模型必须遵守的约束

来自 [AGENTS.md](../AGENTS.md) 与 [项目实施路线图.md](../项目实施路线图.md) §1.2、§3，不得绕开：

1. 安全不变量：无前视；`data/raw` 不可覆盖；统一回测口径与 0.5×/1×/2× 三档成本；预注册；凭据不进 Git；`auto_trade=false`。真钱下单、覆盖 raw、付费新源、单次 >US$50 API、改 AGENTS 安全不变量，必须用户确认。
2. 不新建治理层/平台/身份体系/审查仪式；不做单因子微假设；不用 ≤3 年 Top-K 收益差判定；LLM 不直接交易。
3. **准入门槛不改**（§1.2：1× 超额最强基准 ≥3pp、2× 为正、Sharpe ≥0.6、换手中位 ≤6×（6–8× 需 2× 超额 ≥5pp）、MDD ≤1.2× 基准、压力窗 ≥3/4、年胜率 ≥60%）。本清单所有"监控列"都是 **advisory**，写进报告但不参与判定。
4. Q1–Q9/P7/Q6 不再追加变体；每个新假设必须是独立经济机制并先写冻结 toml 再跑。`research/m3` 冻结不碰。
5. 单文件 >1500 行、md >30KB 必须拆；连续一周只有重构无研究产出视为失灵。**重构时间盒：每周 ≤1 天。**
6. 实验结果不手写文档：数字由 `artifacts/registry/experiments.parquet` 与 `docs/research/排行榜.md` 机器生成；本清单只写"做什么、产物在哪、怎么验收"。
7. 每天 `git commit`。上一轮项目 Agent 两周未提交 229 个文件，是本次检查的直接教训。
8. 运行方式：`python -m quant <group> <cmd>`（见 `src/quant/cli.py`），base 环境，默认 CPU；`QUANT_DEVICE=gpu` 仅 LightGBM OpenCL 可选。
