# 日更输入恢复

`quant data refresh` 的 `limits` 阶段保留 ETF 原口径，`stock_limits` 单列股票限价。
股票限价只按请求参数和响应中的实际交易日期匹配；raw 目录按抓取日期分区，
不能把分区日期当交易日期。复用已保存响应时校验源、哈希、时区、唯一键、价格和所需覆盖，
无完整响应才补一次对应日期的请求。实际抓取时间保留，晚到数据不冒充历史当时可用。

日更分钟任务使用当前刷新配置，只请求该范围内实际成交股票；独立的全历史/ETF采集命令
保持各自范围。最近区间检查先筛日期；完整备用源须整日通过时间网格和日线价量额核对，
不得将两源零散分钟拼起来。仅有供应商请求失败不再跳过全部分钟因子，缺失仍为 null，
采集错误和最终输入检查仍阻止不完整日更通过。备用整日及部分补数会触发受影响区间重算。
共享连接、预算或黑名单暂停只记录当前错误及尚未尝试股票，不逐票重复触发同一个暂停。

恢复后使用原输入质量检查和模型因子检查；实际运行证据见路线图当前基础的机器记录。
仅修好输入，不能改写旧失败日更、补写前向收益或把市场状态强制设成已知。
下一次正常日更的完成凭证、订单及模拟净值仍须分别核对。

恢复预测若保存在独立目录，生产预测监控必须显式引用已核验的那一个 `summary.json`，
不通配所有恢复或演练目录。原始记录时刻、月末资格和次开盘前可得检查照常执行；
仅重新发现预测和读取现有账户快照，不推进账户，也不补写正常日更完成回执。
当前接续证据在 `artifacts/daily_recovery/20260929_dependency_fix/monitor_recovery/summary.json`。

调度默认使用 `configs/research/daily_observation_q2_sue_v2_20260930.toml`。
每次运行先解析当时可用的模型、候选终端、健康诊断和账户依赖，保存 `dependencies.json`，
再将消费者因子并集同时用于当次计算和质量检查。原财务/基准配置仍按原路径推进版本；
不修改旧运行的配置或回执。依赖不明、候选定义变化或必需因子被排除时，模型保持未完成。
只有真实消费者需要分钟输入才在日更刷新分钟；影子滑点的订单窗口缺口继续独立报告，
不将局部分钟数据称为全市场覆盖，不绕过最终日更完成检查。

独立分钟采集脚本现在接入 `python -m quant data minute-factors --collect`，
按原分钟定义重算近期受影响区间，包含滚动预热；采集部分失败仍保存部分状态，
晚到数据使已物化的缺失值重新计算。已有日更/模型/因子写入任务时，此阶段延期，
保留原采集与研究流程。单独维护近期分钟因子不替代全历史回补及其覆盖验证。

ETF既定长历史延伸入口：`python -m quant research etf-history-extension --output <新目录>`。
消费已有价格/公司行动审查及官方年度报告哈希，生成独立冻结输入，再复用原账户引擎。
只延伸原三ETF、原窗口及原费用三档；早期费用明确为同一假设费用的敏感性实验，
不是已核实的历年券商收费。早期债券/黄金ETF日价缺少逐日独立报价复核，开发历史也不是新样本外。
已有回放可用 `etf-measurement --config <该配置> --output <新目录> --reuse-daily <已完成回放>`
按哈希复用净值和成交。新个人账户的最低佣金配置不追改这一冻结实验。
