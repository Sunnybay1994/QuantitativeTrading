## 2. F1 — OrderAggregate 自证

- 聚合必须携带并冻结 `command_quantity` 与 `last_event_at`，由 `new_order_aggregate(command)` 从已验证 command
  建立；reducer 每次都核对 aggregate 的 command id、command quantity 与传入 command 一致。
- `OrderAggregate` 直接构造也必须严格拒绝错误类型、非裸 64 lowercase hex command/event id、重复 event id、
  非 UTC-aware 时间、负数/超量成交和不可能状态组合；bool 不得冒充 int。
- 至少关闭：CREATED 非零成交或已有事件、PARTIAL_FILLED 不在 `(0, command_quantity)`、FILLED 未恰好满量、
  REJECTED 无 reject code 或带成交、非 REJECTED 带 reject code、空事件集合与 `last_event_at` 不一致。
- 不引入数据库、serializer 或可变集合；聚合保持 frozen、纯内存、可比较。

## 3. F2 — 事件时序闭包

- 非重复事件的 `occurred_at` 必须不早于 command `generated_at`，也不得早于 aggregate `last_event_at`；相同
  时间允许，以兼容只有秒级时间戳的合法多事件。
- 成功应用任何新事件时同步写入 `last_event_at`；same `event_id` 的幂等 no-op 返回原对象，不改变时间。
- 时间错误统一抛 `OmsError`，不把合法晚到的重复回报误判成新事件。

## 4. F3 — broker_order_id 单次绑定

- aggregate 尚未绑定时，可由首个带值事件绑定；一旦已有非空 broker order id，后续事件的非空值必须完全
  相同，否则 `OmsError`。
- 后续事件省略 broker id 时保留既有值；不得清空或静默替换。
- 规则在 central reducer 边界执行，覆盖 accepted、rejected、fill、cancel accepted、cancelled，不在每个分支
  复制不同口径。

## 5. 必须新增的定向测试

1. 参数化直接构造聚合的非法类型、identity、重复 id 和各状态跨字段反例；合法种子及每个合法状态仍可构造；
2. command quantity 与 aggregate 不一致拒绝；
3. event 早于 command、早于 last event 拒绝；同一时间的不同合法事件允许；重复事件保持 no-op；
4. broker id `None → B-1`、`B-1 + None`、`B-1 + B-1` 合法，`B-1 → B-2` 对各适用事件 fail closed；
5. 保留既有 20 项 P1 测试，并适配 D0 已通过实现接口，不回退真实 command 绑定。
