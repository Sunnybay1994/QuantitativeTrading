均在 WSL `conda run -n base` 下用纯内存探针复现（不落盘、不改生产/测试文件）。

| P1-D | reader `OSError("/home/user/private/market.parquet")` 原样外溢路径 | market reader 抛该 `OSError` 后 load | **稳定映射且脱敏** | `code=READER_FAILURE`；`__cause__ is None`；`str`/`repr`/traceback **不含**注入路径 |

代码侧对应门禁（只读核对）：

- F1：`_validate_market_mapping_entry` / `_validate_account_mapping_entry` 在构造阶段绑定 key↔内容并调用 identity verifier。
- F2：`_validate_clean_*_facts_bundle` + `_require_exact_bool`；repository 在属性访问/排序/domain builder 前再验一次。
- F3：reader `except Exception` → `READER_FAILURE`，再在 except 外 `raise`；domain 经 `_invoke_domain` 映射 `DOMAIN_CONTRACT`，切断链式异常。
