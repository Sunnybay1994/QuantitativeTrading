## 4. 许可与留存边界（设计级，非法律意见）

1. **HKEX Data Marketplace Usage Terms** 为每产品 SSOT；采购前必须确认：**内部研究、审计留存、是否允许离线 raw 存盘、是否禁止再分发/再发布 clean bar**。
2. **留存**：项目要求 raw 不可覆盖 + metadata sidecar；HKEX 投递 archive **原字节**保留；manifest 绑定 SHA-256（01065 R1 §3.2）。
3. **SFTP 14 天窗口**：过期需 Marketplace 重新请求下载；正式 pipeline 应把 licensed raw 复制到项目受控 raw root（用户批准路径），不能依赖 SFTP 临时目录 alone。
4. **旧平台退役（2026-05-31）**：现有旧订阅需迁移至 Data Marketplace（[Historical Data 首页说明](https://www.hkex.com.hk/eng/ods/index.aspx)）。
5. **Tushare**：token 凭据不进 Git；其数据许可 **不等于** HKEX 官方 no-trade / 02983 formal HKEX provenance。
6. **第三方 Vendor**：通常禁止把 terminal 输出当作 `source=HKEX_DAILY_QUOTATIONS`；若使用，应新增独立 `source` 枚举并经主 Agent 改 SSOT — **超出当前 frozen 01065 合同**。
