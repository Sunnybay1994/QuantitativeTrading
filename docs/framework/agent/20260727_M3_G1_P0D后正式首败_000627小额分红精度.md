## 根因

P0 恢复 fail-closed 时把 event 分支的 `actual <= 1.0` 和 `market <= 1.0` 无条件视为失败。
该规则误把“有实施事件、但因报价/因子精度使 ratio 在 1 附近稳定”的合法情况与无证据或反向跳变混为一类。

下一轮只允许在 event identity 完整且 actual/market 均为 `>1` 或在 `1±rtol` 内、并且
actual 与 market 相互匹配时沿用现有 `MATCHED_EVENT_*` 状态。无事件大跳、远离 1 的反向 ratio、
缺 market proof 和 event 失败回退继续 fail closed。
