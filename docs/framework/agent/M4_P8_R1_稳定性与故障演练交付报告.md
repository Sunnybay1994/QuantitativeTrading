## 实现内容

新增 `quant.execution.soak` 公共合同和安全导出：

- `SoakEvidenceKind`、`SoakRunManifest`、session/fault receipt、development/formal verified 类型和
  `SoakGateDecision`；
- `build_soak_run`、`append_soak_session`、`append_fault_drill`、`verify_soak_evidence`、
  `decide_soak_gate`，以及 expected schedule identity helper；
- content-addressed run、canonical JSON、exclusive-create append-only 写入；相同 bytes 幂等、异 bytes 冲突；
- development 固定目录尾部和正式显式根分离，development 类型与元数据永不产生 Gate PASS；
- 每次 invocation 重验 source/config/gateway/store/account identity，禁止跨 run 漂移；
- session 重新构造 P5 recovery/reconciliation、验证 P7 canonical report，重算 command/event/ledger 摘要，
  UNKNOWN/LEASED、差异、非 READY、report Gate false 均阻断；
- fault drill 从前后 recovery 的 command/cancel/event/ledger/checkpoint 闭包重算经济影响，自行决定
  outcome/stable codes；
- 正式 Gate 要求 28 个自然日、expected sessions 全覆盖、时间严格递增、零 issue 和强制演练 exact set 全通过；
- 公开错误为稳定码并切断 hostile cause/context；manifest/receipt 不保存根路径、token、broker/account 原文。

未增加 runner CLI：冻结合同允许但不要求 CLI；当前最窄 API 已能由后续独立调度层注入 P5/P6/P7 已验真结果，
避免在 P8 复制 PAPER 操作或 broker 查询能力。

## 函数签名补全决策

任务单省略了 `...` 参数。本轮冻结为所有写操作显式接收 `root` 和 `manifest`，不做默认发现；session 接收
P5 `RecoveryResult`、`ReconciliationResult`、P7 `ExecutionReport` 及 UTC invocation 时间；session 与 fault
均要求 source/config/gateway/store/account 五类不可逆 identity。fault 只额外接收 drill 名、前后 recovery 与
排序唯一的不可逆 subject IDs，不接受调用者自报 outcome、stable codes 或经济影响摘要。

## 测试覆盖

- development/formal 身份与目录隔离、manifest 无绝对路径和账户原文；
- manifest/session/fault 同 bytes 幂等、session 异 bytes 冲突；
- expected schedule 顺序、唯一性和 invocation 时间递增；
- 五类运行 identity 分别漂移均拒绝；
- P5/P7 伪造 identity、类型子类、非 UTC 与 hostile 输入稳定拒绝且无异常链；
- command/event/ledger 摘要分别由空闭包和真实 staged/partial-fill/fill/ledger fixture 确定重算；
- duplicate callback 的无经济变化演练 PASS，未证明经济增量的 exact submit 演练 BLOCKED，真实增加
  command/event/ledger 闭包的 exact submit 演练 PASS；
- receipt invocation identity 被修改并全量重哈希后仍拒绝；
- 显式 run 下的非预期 session/fault/root 条目与符号链接不会被静默忽略；
- 跨越 28 日的 development evidence 仍只返回 `WAITING_FOR_SOAK_EVIDENCE`；
- formal evidence 即使 session 完整，缺自然时间或 fault matrix 仍等待。
