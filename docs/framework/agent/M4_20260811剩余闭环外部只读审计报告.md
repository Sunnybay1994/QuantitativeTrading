## 2. 到“正式 PAPER 可启动并进入连续 4 周 soak”的最短串行依赖链

目标定义（本报告冻结）：

- **可启动**：formal PAPER 账户/配置已按用户裁决落盘；store/gateway/service/runner 可在显式 trusted root 下 plan→approve→dispatch→event→ledger→reconcile→EOD；安全默认 `PAPER` + `auto_trade=false`。
- **进入 soak**：P8 harness/故障矩阵代码闭环完成并标记 `WAITING_FOR_SOAK_EVIDENCE` 后，**开始**真实日历计时的连续运行；**不等于** soak 完成，更不等于 M4 Gate。

## 5. Windows / WSL1-DrvFS / 未来 WSL2-ext4 证据边界

| 环境 | 可证明什么 | 不可证明什么 |
|---|---|---|
| Windows 原生 Miniforge | 开发反馈环；journal/store 等已双平台模块的定向单测；Windows G1 发布物磁盘验真（既有报告） | Linux Gate；`renameat2(RENAME_NOREPLACE)`；ext4 不可变发布 |
| 当前 WSL1 / DrvFS（交接与既有探针共识） | 同目录 Linux 解释器下的合同测试；部分能力 **skip** | 正式 Linux 发布 Gate；与 Windows 绿测等价 |
| 未来 WSL2 + 经探针 ext4 root | Linux 权威发布/部分平台特有终验 | 自动回溯证明历史 Windows 产物等价 |

- **工程合同**可在 Windows 与 WSL1 定向验证，但报告必须分平台陈述。
- **不得**把 Windows/WSL1 绿测写成“Linux/ext4 Gate 已过”或“M4 Gate 已过”。

- 真实 soak 证据必须来自约定根上的保留运行产物；fake clock / 回放 **不能**关闭四周要求。
