## 1. 交付结论

已交付 SQLite `ExecutionStore`：显式 schema version、migration、`BEGIN IMMEDIATE` 事务、typed repository（commands / events / order_aggregates / outbox / ledger_entries / reconciliation_runs）。同 key 同 payload（及 events 的关联键 `command_id`）幂等 no-op；同 key 异 payload / 异关联键抛 `IdempotencyConflict`。无通用 SQL escape hatch；异常消息使用稳定 code，不泄露绝对路径。

**披露（强制）**：本包基于 **M4-C0 / D0 / D1 待主验** 合同预实现；不得将下游依赖解读为相关 Gate 已关闭。

## 2. 冻结入口

| 入口 | 行为 |
|---|---|
| `ExecutionStore.open(uri)` | 解析 `sqlite:///` URI；建库；跑 migration；返回 ready store |
| `store.schema_version()` | 返回已应用版本（当前 `CURRENT_SCHEMA_VERSION = 1`） |
| `store.transaction()` | 写事务上下文；异常 rollback，正常 commit |
| `ExecutionRepository.put_*/get_*` | 按表 typed 读写；identity + payload bytes 与 unique key 同存 |

表：`schema_version`（`ready`/`migrating`）、`commands`、`events`、`order_aggregates`、`outbox`、`ledger_entries`、`reconciliation_runs`。

Migration：`migrations/v001_initial.py`；中断（status=`migrating`）→ `MigrationInterruptedError`；未知更高 version → `UnknownSchemaVersionError`。
