## 2. 交付报告 identity 矩阵核对（§3.3）

交付报告声称：双字段迁移后 `full/g1/snapshot/scientific` **changed**，其余五个 **unchanged**。

独立重建（旧 method literal 不可加载，故不复现“旧→新”全量 hash，而用可加载分量 + selector 归属）：

1. 仅把 `data.start_date` 从 `2016-01-04` 改回 `2016-01-01`：delta = `{full, snapshot, scientific}`；
2. `membership_method_version` 的 selectors 精确为 `{"g1"}` → 方法切换只贡献 `{full, g1}`；
3. 并集 = `{full, g1, snapshot, scientific}`；unchanged = `{provider, provider-validation, label-reconciliation, acceptance, tracking-target}`。

与任务书 §3.3 及交付报告矩阵一致。不能只靠单测绿色；本核对不依赖实现者抄写的 64-hex。
