## 恢复方法

查看标签：

```powershell
git tag --list 'archive/20260908/*'
```

恢复某条历史分支时，选择实际标签创建 worktree，例如：

```powershell
git worktree add -b codex/restore-faber artifacts/dev_worktrees/restore-faber archive/20260908/m2-strategy-r2-faber-10m-trend
```

对应 `saved/<原worktree名称>/` 中包含：

- `staged.patch`、`unstaged.patch`：原暂存与未暂存修改；依次使用 `git apply --index`、`git apply` 恢复。
- `working_files.zip`：已修改文件的最终内容、未跟踪文件，以及非缓存的本地忽略文件；需要时解压到恢复目录。
- `data/`、`artifacts/` 等目录（原 worktree 存在时）：直接迁移保留的原始数据及运行产物。

`saved.json` 记录原目录、分支、提交、标签和备份位置。标签随 Git 保存；ZIP、本地配置和数据备份
被 Git 忽略，恢复未提交内容需要同时保留该本机备份目录。
