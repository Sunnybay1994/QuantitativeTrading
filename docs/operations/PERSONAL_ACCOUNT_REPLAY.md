# 个人账户配对回放

入口：`python -m quant research personal-top5 --output artifacts/research/<新目录>`。

按 `configs/research/personal_top5_fee1_v1.toml` 固定10万元、Top5/Top50、最低佣金1元/5元，
各跑0.5×/1×/2×成本。复用冻结预测，先保存完整执行输入与代码指纹，再按年度保存账户断点。

中断后同命令加 `--resume`。已有进程运行时不要重复执行同一目录；输入或执行代码变化时拒绝混接，
应保留旧目录并使用新目录。只有已经完整发布的年度断点可复用，未完成年度从上个断点重算。

`progress.json` 区分冻结输入、运行中、未完成和完成。全期完成后才生成 `summary.json`、`report.md`；
各账户的 `periods/report.md` 提供年度结果及逐年月度报告链接。固定委托、未成交、每日持仓、
行业和规模暴露、费用分解另存于账户目录；连续压力窗口和准入检查在总汇总内。

科创板最低200股、1股递增由本实验独立处理，不改旧账户及冻结挖掘。
历史回放不等于人工延迟执行验收；1元最低佣金是用户指定研究假设，实盘证券权限另须核实。
`auto_trade=false`，该入口不下真实订单。
