# B16 前向研究模拟

冻结配置 `configs/research/b16_manual_forward_v1.toml`：10万元，9月30日首个信号、
10月8日首次执行，120秒主账、60秒影子，0.5/1/2倍成本，三个调仓周期。
本模块不连接券商、不发送消息、不启用外部监听，`auto_trade=false`。

## 自动运行

既有实时行情任务通过 `scripts/run_realtime_quotes.ps1` 启动独立模拟伴随进程，
单实例锁防重复；只使用三只既定ETF，不中断原行情采集。
既有日更在B20数据发布后调用B16收盘环节；失败独立记录，其他日更阶段继续。
行情伴随进程启动时从完整的已有日线发布恢复前一交易日账本；每5秒重试，09:41退出。
电脑关闭时不模拟后台运行，重新启动后不补造提交时刻或遗漏报价。

```powershell
python -m quant paper b16-forward --once
python -m quant paper b16-forward --probe
python -m quant paper b16-forward --close 2026-09-30
```

第一条执行一次当前生命周期检查；第二条只读三只ETF行情，保存在独立 `probes/`，
不会用于正式成交；第三条使用该日期已发布的B20同池日线、分红和日历收盘。
正式入口不接受伪造当前时刻，未完成/未来日期不能收盘。

## 信号与成交口径

信号使用完整61个交易日总收益价格计算60日波动率倒数权重，按各自实际收盘权益、
持仓、收盘价格取100份整手固定数量。目标、输入指纹、实际准备时刻一并保存。
模拟提交不早于“09:30或更晚实际准备时刻”加原60/120秒延迟，重启时记录实际提交时刻。
不是历史1/3分钟极值压力回测，也不使用未来价格调整下单数量。

只消费供应商时间严格晚于提交、接收时不超过10秒的盘口。复用Tushare/Sina只读接口：
SDK的B1_V/A1_V是截断后的100份手数，明确换算为份，原始SDK字段另存raw。
买单使用卖一、卖单使用买一，容量上限为该侧显示数量的1%，向下取整手；
重复供应商时刻不重复补充容量，不以累计成交量替代深度。
当日官方涨跌停价格、有效价差、盘口数量或新鲜度不足则不成交。

09:40按此前实际捕获报价顺序结算模型成交，余单取消；逐笔检查现金和可卖份额。
同一委托部分成交累计收取最低佣金，原每份滑点和三档费用不变。
模型分红按已登记支付日入账，复用公司行动和收盘持仓/现金对账。
这些是保守模拟假设，显示盘口仍不保证真实可成交、排队顺序或券商执行。

## 查看证据

账户根目录 `artifacts/paper/b16_manual_v1/`：

- `service_status.json`、`daily_status.json`：最近服务与日更状态；历史 `bootstrap.json` 不改写。
- `delay_*/cost_*/日期/signal.json`：固定目标、数量、收盘持仓和输入证据。
- 同目录 `submission.json`、`execution.json`、`close.json`：实际模拟提交时刻、成交/余单、收盘对账。
- `quotes/日期/`：正式捕获记录；`probes/` 仅用于接入演练。
- 各账户 `performance.json`：从首次真实到期信号的模拟提交起记录，排除此前现金期，演练不进入。

确定性六账户夹具及集成验收产物在 `artifacts/research/b16_forward_acceptance_20260924_01/`。
测试通过不等于已有正式前向收益；以到期后的实际信号、提交、报价、成交和收盘证据为准。
