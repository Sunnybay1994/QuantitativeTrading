## 4. Agent 反馈原则

本轮反例说明，正常路径绿测不能替代权威 Schema 联调、identity 变化传播和对抗性验证。后续每次交付继续
执行“主任务书 → 实现自测 → 独立初验 → 主终验”；返工报告必须把问题的根因和新反例写入项目文档，
而不是只描述修了哪一行。
