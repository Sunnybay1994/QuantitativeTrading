REGIME-R1 只用于回答“既有策略在预注册市场状态切片中的表现是否不同”，不负责选择赢家或自动切换策略。其静态实现与审查没有读取三个 immutable source run 的经济内容；最新 direct validation 又在 Python/resource 前因既有 cache 与冻结 scope 冲突停止，所以当前只能写成 `STATIC_REWORK6_REVIEW_PASS / DIRECT_VALIDATION_PREFLIGHT_STOP / PRODUCT_NOT_EVALUATED / ECONOMIC_CONTENT_UNREAD / trial_delta=0`。不得把阻断写成 regime 机制无效，也不得从已消费授权推定第二次运行权限。

该诊断的 `3 strategies × 2 folds × 4 states = 24` 行不是 24 个独立市场样本：三策略在同一折共享由 510300 生成的状态 grid，真正独立的时间折仅有两个。`n_days>=20` 且 `episode_count>=2` 只允许报告一折内的 Sharpe/HAC，不证明跨折稳定。三个来源策略自身也使用 510300 正趋势准入，因此 DOWN 状态的低敞口或低回撤可能只是原规则的机械重述，不是新的择时 alpha。未来任何状态切片结果都只能形成 exploratory heterogeneity；不得复活已 `REJECTED` 的来源策略，也不得据此切换策略。

ETF 策略统一按[投研评价指标与市场状态研究方法](../../../../research/methodology/投研评价指标与市场状态研究方法.md)报告：主指标至少包括成本后 CAGR、累计收益、年化波动率、Sharpe、Sortino、Calmar、最大回撤、相对基准的超额收益与 IR、gross/one-way turnover 和成本压力；因子研究继续使用 RankIC、ICIR、方向、分组单调性、coverage 与冗余。不得强迫无横截面的趋势策略报告 IC，也不得把跨任务经验阈值当成统一生产门槛。趋势 × 波动率市场状态只用于解释适用条件，必须 `as_of` 可知且在结果前预注册，不能事后用来选择、切换或挽救策略。

cutoff 后规划补充的队列为：**公共 receipt 返工/复验/合流 → Faber 最小返工与验证 → 2026-08-31 前向观察 → R11 510300 多周期趋势等权 → R5 十二月绝对动量 → R6 ETF 双重动量**。其中 R11 及由其引出的排序不属于主 cutoff 的工程或经济证据；它只陈述 source `38892310` taskbook 所登记的 `IMPLEMENTATION0 / ECONOMIC_IO0 / TRIAL0` 规划。该排序不证明 R11 更优，也不授权运行或调参。R3/R4 在相同公共边界释放后按共享写锁串行进入；PIT 财务链与 ETF 快线并行推进。

R6 必须保持“权益内部相对轮动 + 12 月绝对动量现金门”的本地定义。exact11 全部是中国或港股主题权益 ETF，因此它不是 Antonacci 式跨资产 dual momentum，也没有债券、黄金或货币工具提供的独立分散来源。未来若回撤下降，应优先归因于 strict-positive absolute gate 与空槽持现金；报告必须披露 active slot 0/1/2/3 频率、现金权重、Top3 内部相关与集中暴露、权益类别贡献以及高波动阶段的门控滞后。任何跨资产扩展都是新的 universe 与 trial，不得作为 R6 失败后的 fallback。

当前波动率目标历史结果还受三个结构限制：两折 test 合计仅 12 个月；fold 2 在 2026-01-01 处同时发生时间推进与 Akshare→Baostock 数据源切换；11 ETF universe 在 2026-07-12 才冻结，却被用于更早历史。前向或未来重验须逐证券闭合切换点附近的 session、raw close、`TOTAL_RETURN_DIVIDEND` adjusted close、分红调整、重复/重叠和 source identity，并报告每折 exact signal/outcome count。连续性失败只能 `STOP/UNASSESSED`，不得调参或补值。

### 4.2 立即开展：投研侧只做经济合同和预注册收口

1. **首个 PIT R3 业务合同整理。** 将四因子方向 `(+1,+1,+1,-1)`、h20 单调性、singleton report type、trial budget、attempt receipt、universe/folds/cost、13 outputs 和失败语义整理成可实施任务书；在 audit-v4 与 allowed report type 未闭合前不运行、不创建结果 artifact。
2. **建立 `quant_factor_research_v2` 候选增量地图。** 只做机制、字段可得性、与现有因子重复度、预期方向、负对照和成本敏感性审计；不把论文结果当成本地 alpha，不新增 trial，不再盲目堆 bar-only 因子。
3. **预注册 annual asset growth。** 主定义固定为 `(TA_FY_t - TA_FY_t-1) / TA_FY_t-1`，prior assets 必须大于 0，低资产增长优先、方向 `-1`，单独 trial；主板、剔除最小市值 30%、long-low-AG 与 `1x/3x/10x` 容量成本只作诊断，不能替代主试验。

### 4.3 框架/数据 Gate 闭合后：完成首个 PIT，而不是继续扩候选池

1. 框架线完成大 JSON 的完整、单遍、低内存证据闭包；若确认 audit-v4 `BLOCKED`，由数据 owner 对 exact 一条异常及其 fail-closed 处置另立任务，不由投研层绕过。
2. audit-v4 达到可发布状态后，冻结 singleton `allowed_report_types`，再由统筹基于 latest clean main 冻结 R3 exact base、worktree 和白名单。
3. R3 完成实现、独立审查和平台验证后，发布不可覆盖 financial snapshot。
4. 对四个 PIT 质量因子执行唯一预注册试验：
   - `pit_roe_ttm`，方向 `+1`；
   - `pit_roa_ttm`，方向 `+1`；
   - `pit_cash_profit_quality_ttm`，方向 `+1`；
   - `pit_total_accruals_ttm`，方向 `-1`。
5. 只按预注册的 fixed direction、RankIC、fold 稳定性、h20 分组单调、coverage、冗余和 0.5x/1x/2x 成本给出 `REJECTED` 或最高 `RESEARCH_ONLY`；不使用组合来挽救单因子失败。

### 4.4 首个 PIT 后：按经济机制逐包推进

| 优先级 | 研究包 | 预注册重点 | 启动条件 |
|---|---|---|---|
| P1 | Annual asset growth | 年频资产增长、方向 `-1`、单 trial、规模/流动性/容量诊断 | 首个 PIT 完成且 annual pair lineage/字段 coverage 闭合 |
| P2 | GPOA | 年度收入与营业成本形成 gross profitability，方向 `+1`；不以 margin proxy 替代 | 本地 raw 字段、income/balance PIT join 与 clean contract 闭合 |
| P3 | NOA | 方向 `-1`；现金、债务、权益分量及 prior-FY 资产分母必须会计闭合 | 字段 mapping、缺失策略和重复扣减风险全部 fail closed |
| P4 | SUE / PEAD | classic EPS SUE 与公告事件研究分开；announcement→next-open、季度链和标准化窗口预注册 | EPS/季度 revision provenance、公告可知时点与更高换手成本闭合 |

GPOA、NOA、SUE/PEAD 不能混成一个“基本面大礼包”。每个候选必须拥有独立 trial identity、方向、时间语义、成本和停止条件；只有单项通过后，才允许另开低维、冻结权重的组合试验。
