## 2. 冻结入口

```python
load_trading_config(path: Path) -> TradingConfig
trading_config_identity(config: TradingConfig) -> str
```

字段组（`schema_version = trading-config-v1`）：

| 组 | 键 |
|---|---|
| meta | `schema_version` |
| execution | `mode`（PAPER/SHADOW）、`auto_trade=false`、`manual_approval`、`sell_only`、`frozen_symbols`（唯一、canonical 排序） |
| rules | A/HK rule selector、fee/FX schedule selector |
| data | `snapshot_max_age_seconds` |
| store | `sqlite_uri`（仅相对 SQLite 逻辑路径） |
| risk.limits[] | 有效期 + 单笔/单票/总仓/日成交/日单/日撤上限 |

Identity envelope：`hash_version=trading-config-hash-v1` + `schema_version` + sorted-key compact JSON payload；注释/空白/键重排不变。
