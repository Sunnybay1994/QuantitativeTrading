## E0 Alpha158 VWAP staging 与双向 symbol codec

- **修改文件：** `src/quant/research/m3/snapshot.py`，`tests/unit/test_m3_snapshot.py`，`src/quant/research/m3/__init__.py`
- **签名符合性：**
  - `STAGING_COLUMNS = symbol,date,open,high,low,close,vwap,volume,factor`
  - `prepare_qlib_staging(..., source, universe)`：amount/volume 正且 finite；`vwap=(amount/volume)*factor`；验证 `vwap/factor == amount/volume`
  - `to_qlib_symbol` / `from_qlib_symbol` 互逆；接受 `SH600000/sh600000/SZ000001`；拒绝 HK/未知前缀/非 6 位数字
  - `build_snapshot_manifest` 必需并 hash `universe`、`g1_release_id`、`g1_release_manifest_sha256`；`adjustment` 含 VWAP 公式
- **针对性测试：** 手算 VWAP、输入顺序稳定、amount/volume null/NaN/inf/0、公式恒等式、G1/VWAP 改变 snapshot ID、round-trip、非法 symbol、调入前 60 sessions 保留、非目标 universe 排除
- **未实现：** `materialize_qlib_provider`、真实 3×20 回读

## E3 运行身份与 stage receipt

- **新增文件：** `src/quant/research/m3/run_state.py`，`tests/unit/test_m3_run_state.py`
- **实现：** `ArtifactDigest`、`StageReceipt`、`compute_provider_key`、`compute_experiment_key`、`compute_work_key`、`verify_stage_receipt`、`publish_stage_receipt`
- **Identity join 格式：** `sha256:` + SHA-256(UTF-8 of `json.dumps([fields...], separators=(",", ":"), ensure_ascii=True)`)；任一字段为字面量 `unavailable` 拒绝
- **Receipt 规则：** canonical JSON `sort_keys`；相对 POSIX；拒绝 `..`/绝对路径/未知 alias/重复 `(alias,path)`/符号链接逃逸；receipt 不进 outputs；相同内容字节复用；冲突拒绝；`tempfile` + `os.replace` 原子写
- **反例覆盖：** 字段变化改变对应 key；dependency 变 experiment/work 不变 provider；缺文件→`None`；hash/大小不符、非法 JSON、路径安全、冲突 receipt、半写入后最终文件仍为合法 JSON
- **未实现：** CLI / `run_m3.py` / 编排 DAG
