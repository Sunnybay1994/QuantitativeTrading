## 9.1 七阶段 receipt 闭包

每个 verifier 必须从 verified upstream bundle、strict spec 与 `LoadedM3Config` 重建下表的精确 input/output
集合；多一个、少一个、路径别名、同 bytes 不同物理身份或只验通用 receipt 自洽都失败。表中的“bundle”是
其 manifest、receipt 及本阶段实际读取的全部数据文件，不允许只列 manifest 后绕过内容 bytes。

| stage | scope | inputs 精确闭包 | outputs 精确闭包 |
|---|---|---|---|
| `folds` | `EXPERIMENT` | snapshot request/manifest/receipt/calendar；experiment manifest/receipt | `folds.json` |
| `features` | `EXPERIMENT` | G1 release/eligible；snapshot request/manifest/receipt/calendar；provider bundle；experiment bundle；fold bundle | worker request/response、三个 segment parquet、coverage、feature manifest |
| `alignment` | `WORK` | feature bundle；当前 horizon label bundle；fold bundle；experiment bundle | train/validation parquet、diagnostics、alignment manifest |
| `model` | `WORK` | alignment bundle；feature manifest/receipt；label manifest/receipt；experiment bundle | `model.txt`、`validation_curve.parquet`、`model.metadata.json` |
| `predictions` | `WORK` | model bundle；feature manifest/receipt/test segment；fold bundle；experiment bundle | `predictions.parquet`、prediction manifest |
| `evaluation` | `WORK` | G1 release/eligible；feature manifest/receipt/coverage/test；prediction bundle；label bundle；fold bundle；experiment bundle | `daily_ic.parquet`、`metrics.json`、evaluation manifest |
| `research-summary` | `EXPERIMENT` | experiment bundle；按 fold 排序的全部 evaluation bundle | summary daily、fold metrics、metrics、manifest |

所有 stage writer 只写已存在空 temp，JSON 使用 canonical bytes，Parquet 使用本文冻结参数；StageRunner 是唯一
final publisher。receipt 的 stage/node id 必须区分 fold/horizon，scope_key 必须等于父作用域 identity：
`features.<fold>` 用 `EXPERIMENT/experiment_key`，work stage 用 `WORK/work_key`，summary 用
`EXPERIMENT/experiment_key`。不能用 `WORK` receipt 发布 experiment 级共享 feature，也不能让同 fold 两个
horizon 各自发布一份 feature。
