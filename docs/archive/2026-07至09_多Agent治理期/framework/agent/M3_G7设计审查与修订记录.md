## 1. 审查角色与结论

主 Agent 完成首版接口后，由未参与实现的下级 Agent 对现有 Top-k、时间调度、ETF 模拟器、市场规则、

## 3. 追加的 P1 规则

- M3 A 股按完整 batch 调度到共同下一 SH session，不复用逐 symbol 静默丢尾部的接口。
- prediction 必须覆盖全部 scorable keys；scorable/eligible 比例低于配置失败，并在 target manifest 留计数。
- 申报数量按现行 G7 任务书的版本化板块规则；`InstrumentSchema.board_lot` 不能替代最小量、递增量和零股卖出政策。
- 历史回测只使用 list/delist 与当日事实，不能用证券主表的当前 `status` 回填过去。
- G1 mapper 形成唯一经济公司行动并保存多公告版本选择证据；`event_id` 唯一不能替代经济事件去重。
- 同时报 target/realized turnover；`test_turnover` 是 realized one-way，另报 gross。
- 轻量版明确假设开盘无限量成交，不模拟参与率、冲击和日内部分成交。
- bars、日历、停牌、limits、公司行动和 instrument 必须来自同一验真 G1 release。

## 4. 对实现 Agent 的指导

本轮问题的共同根因是把“一个能输出净值的循环”误当作“可审计账户”。实现时不要从 ETF 模拟器复制
并逐项打补丁；先建立 batch identity、日历循环、账户状态和 entitlement，再接入纯规则。每个状态转移
都要有输入证据、输出 artifact 和守恒测试。若真实 dividend 日期或 factor ratio 不满足契约，先提交
raw snapshot 与最小样例，由主 Agent 决定规则，不得提前发放权益、填补日期或忽略事件。
