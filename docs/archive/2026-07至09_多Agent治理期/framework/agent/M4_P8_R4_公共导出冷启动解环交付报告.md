## 返工结论

R4 仅解除 `quant.execution` 包根的 P8 eager re-export 冷启动循环依赖。已公开的
soak 符号集和 `__all__` 保持不变；运行时改由 PEP 562 `__getattr__` 在首次访问 exact
soak 符号时加载 `quant.execution.soak`。单独 `import quant.execution` 不再拉入 soak 及其
reporting/backtest 依赖；未知属性仍抛出标准 `AttributeError`。`TYPE_CHECKING` 分支保留公共类型与
函数可见性，不在运行时 eager import。

R3 的 anchor journal、retained facts、私有时钟、fresh verify 与 Gate 主体均未修改。

## 新增回归

`tests/unit/test_execution_soak.py` 新增四个完全独立解释器探针，各自检查真实退出码：

1. 冷启动导入 `quant.backtest.event_simulator`；
2. 冷启动导入 `quant.reporting.trading_metrics`；
3. 冷启动导入 `quant.execution.soak`；
4. 先确认 `import quant.execution` 未加载 soak，再检查未知属性 fail closed，最后通过
   `from quant.execution import SoakRunManifest` 触发惰性公共导出。

子进程使用当前 `sys.executable`，继承当前项目 `PYTHONPATH`，不依赖 pytest 文件顺序或先导入副作用。
