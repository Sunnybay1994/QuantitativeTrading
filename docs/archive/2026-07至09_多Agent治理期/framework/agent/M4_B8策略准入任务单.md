# M4-B8 策略准入任务单

## 目标

新增纯内存 `compare_strategy_candidates(subjects, common_context, thresholds)`，只输出可重放的
evidence 与 admission decision。B8 不部署策略、不写产物、不访问网络或数据目录，也不依赖尚未交付的 B7
具体类型；未来 B7 只需把已验证指标显式投影为本模块的 typed evidence。

## 冻结合同

- `AdmissionContext` 精确冻结候选集合、场景集合、test-only segment，以及 snapshot、window、rules、
  costs 四类 identity；候选必须全部一致。`StrategyCandidate` 可携带 validation 标记，仅用于检测混用。
- `AdmissionThresholds` 显式列出每个指标的 `MINIMUM`/`MAXIMUM` 阈值和唯一 ranking metric；阈值拥有独立
  identity，不能从候选表现反推。
- 每个候选必须提交全部场景和全部阈值指标。所有场景逐项过线后才有排名资格；ranking 使用主指标的最坏
  场景值，禁止只取最好场景。
- 唯一合格优胜者返回 `ADMIT/UNIQUE_THRESHOLD_WINNER`；无人过线或排名并列返回显式 `REJECT`。
- 候选缺失、场景缺失、segment 混用、四类 identity 漂移、非有限值、伪造 identity 均以稳定错误 fail closed。

## 白名单与验证

返工冻结：最终准入只接受 `test` 上下文。候选仍可携带 `validation` 标记用于检测跨段混用，但
`AdmissionContext` 构造、重验和公开比较入口对非 `test` 一律以 `ADMISSION_CONTEXT_INVALID`
fail closed；完整且彼此一致的 validation-only 候选也不得产生 `ADMIT`。
