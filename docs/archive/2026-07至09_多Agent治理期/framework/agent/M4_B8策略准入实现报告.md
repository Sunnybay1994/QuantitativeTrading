# M4-B8 策略准入实现报告

## 交付

新增独立于 B7 落盘顺序的 typed admission 合同。候选、共同上下文、阈值和最终 decision 均使用规范 JSON
payload 计算 identity；浮点进入 identity 前使用有限值门禁和 `float.hex()` 表示。比较函数重验嵌套冻结对象，
按完整候选/场景/指标集合 fail closed。

决策先逐场景验证显式阈值，再以 ranking metric 的最坏场景值比较。输出包含每个候选、场景、指标的 observed、
threshold、comparison 和 passed evidence；不存在部署、发布或交易入口。

## 覆盖

- 同 context 下唯一最坏场景优胜者；输入顺序不影响结果；
- snapshot/window/rules/costs 任一漂移；
- 缺候选、缺 stress 场景、validation/test 混用；
- NaN、正负无穷和构造后嵌套篡改；
- 阈值 identity 变化、无人过线、排名并列；
- 最佳 base 但 stress 未过线的候选不会被挑选。

## 验证

独立初验返工：初版允许 validation-only 上下文进入准入比较，破坏模型选择期与最终 test 准入隔离。
现已把 `AdmissionContext` 固定为 test-only，非 test 使用稳定
`ADMISSION_CONTEXT_INVALID` 失败，并新增 validation-only 不得准入的回归测试。

- Windows Miniforge：定向 pytest `14 passed`；Ruff passed；mypy passed（公共导入由同组测试覆盖）。
- WSL Miniforge base：定向 pytest `14 passed`；Ruff passed；mypy passed。

本结论仅表示 B8 开发工程合同通过。B7 真实指标适配、正式数据比较、策略部署及 M4 Gate 仍未关闭。
