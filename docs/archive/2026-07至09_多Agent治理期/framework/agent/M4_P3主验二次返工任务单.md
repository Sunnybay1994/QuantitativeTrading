## 2. F1 — 经济字段消费前的输入自证

`evaluate_pretrade` 在读取 mode、quota、cash、position、sellable、intent quantity/side 等任何经济字段之前：

1. 使用 D0 公开 verifier 按当前 payload 验证完整 `OrderPlan` identity；
2. 使用 D0 公开 verifier 验证 `VerifiedMarketSnapshot` identity；
3. 使用 D0 公开 verifier 验证 `AccountSnapshot` identity；
4. 调用 C0 既有 `trading_config_identity` 验证 config；
5. 重新执行 `DailyRiskCounters` 当前结构验证，关闭构造后篡改。

不得复制 D0/C0 哈希或校验算法。任一普通验证异常统一映射为新增的稳定 `RiskInputError(ValueError)`，错误消息
只允许固定 code（如 `PLAN_CONTRACT_INVALID`），使用 `from None`，`__cause__`/`__context__`/traceback 不得包含
篡改 payload 或原异常文本；不捕获 `BaseException`。异常即 fail closed，不返回 commands。

完成自证后，保留当前 plan↔market/account/config id 等值绑定检查和第一轮 F1–F4 业务规则。

## 3. F2 — 保持范围最小

- 不新增第二套 snapshot/plan identity、不改 contracts、不做 serializer/store/repository；
- 第一轮 25 项时点、gross、sellable、SHADOW/manual approval/counter 语义全部保留；
- `RiskInputError` 可在 `risk.py` 的 `__all__` 导出，但本轮不改包根；P4 后续负责服务层映射。

## 4. 必须新增的测试

1. market state quota/reference price/suspended 中至少两项被篡改但 snapshot id 保持旧值，均在风控规则前拒绝；
2. account cash/sellable/quantity 中至少两项被篡改但 snapshot id 保持旧值，均拒绝；
3. plan intent quantity/side 被篡改但 plan/intent id 保持旧值，均拒绝；
4. daily counters 被篡改为负数或 bool 冒充 int，均拒绝；
5. 异常为 `RiskInputError`、`__cause__ is None`、`__context__ is None`，message/repr/traceback 无注入值；
6. 合法输入保持第一轮 25 项全部通过。
