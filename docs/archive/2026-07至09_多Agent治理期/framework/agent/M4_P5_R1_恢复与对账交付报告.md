# M4-P5-R1 恢复与对账交付报告

日期：2026-08-02  
状态：R1 返工完成，待独立复验

## 实现

- 新增 `quant.execution.reconcile`：`recover_local_state` 只在一次
  `ExecutionStore.transaction()` 中读取 P0C `RecoveryRows`，逐项重解 wire、重算 identity、重证父项、
  aggregate、context、checkpoint 与 delivery 闭包，零写入。
- 新增 canonical `BrokerSnapshot`/order observation builder；账户、订单、事件、时间与 source identity
  全部进入 snapshot identity，不保存 broker 原始文本。
- `reconcile` 为零 IO 纯函数；输出 deterministic differences、优先级、disposition、Gate 与
  reconciliation identity。PENDING 且未跨 adapter 才允许 `AUTOMATIC_RETRY`；INTRADAY、UNKNOWN、
  未知订单/事件、重复经济事件、账户或订单漂移均 fail closed。
- hostile wire、可构造对象 mutation 与底层异常统一翻译为稳定错误，最终 cause/context 为空。
