## 1. 现象与判定

上一全新实现会话已把 SH/SZ clean 日历更新为相同的 `2015-01-01..2026-12-31` 自然日域，并连续运行了
多条 WSL Python 命令；但会话在所有可见 WSL 子进程退出后仍长期没有生成任务书要求的交付报告，原 stdout
所属执行 cell 又已丢失，无法证明七个 Tushare 端点、BaoStock、内核 probe、测试和静态检查各自结果。
主 Agent 已终止该孤立 Cursor 进程，避免其与返工会话并发写入。

因此本轮状态是 **未完整交付**，不是测试通过。已有日历文件可以复用，但任何远端烟测或验证结果都不能靠
进程曾经运行来推断。

## 2. 根因与应遵循规则

- 根因：长任务把唯一证据留在外部进程 stdout，必需报告直到最后才计划写入；执行通道丢失后没有可审计产物。
- 规则：长真实依赖任务必须先建立脱敏的增量报告，再在每个独立阶段结束时原子更新；只有全部通过后才把
  状态改为“待独立初验”。进程存在、CPU 活动、退出码不可替代逐项证据。
- 本返工是交付收口，不放宽 R0 原任务的任何数据、远端、测试、安全或环境合同。
