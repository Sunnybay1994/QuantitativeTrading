## 3. formal v2 的唯一允许执行顺序

当前 formal v2 不是“继续跑下一批”，而是被证据前置条件硬阻断。取得 licensed bytes/spec 后的最小顺序为：

1. 对 2026-05-05 的 main 文件及全部适用 supplement/correction 做 fresh digest、严格格式和语义校验；由 verifier 投影 evidence，调用方不得自报 reason。
2. 用正式 original expected、seed 与该 evidence 创建**全新** v2 plan 和 journal root；核对 plan SHA、evidence identity 与 wire request identity。
3. 运行一次 `--recover-existing-only`：只恢复可验证的 COMPLETE raw/receipt；connector 构造与网络调用必须为零；遇首个 ABSENT 即 `HK_HISTORY_INCOMPLETE`。
4. 另进程逐批执行剩余请求；每次最多一个新 API request，严格遵守至少 3,600 秒冷却，保留 raw-first、intent/attempt/failure/receipt。
5. 全部 Tushare receipt 完整后，finalize 显式读取并 fresh 验证 retained 02983 HKEX raw；生成 v2 finalize receipt，发布必须 no-clobber、可重复字节幂等。
6. 对 SH_CONNECT 与 SZ_CONNECT 分别 fresh 运行 available-history Gate，要求 required STOCK 的精确 session 闭包、unexpected=0；只有双 Route 同时 complete 才可关闭 HK60 子 Gate。

任一步失败均保留证据并停止，不回写 R1、不合成 OHLC、不把 no-trade 和 suspended 混为同一语义。

## 4. 下一最小可执行工程包（推荐）

### M1-HK-CA-P0：来源无关的 HK PIT 公司行动证据与选版合同

这是当前唯一既有真实下游价值、又不依赖 licensed 01065、U0C 时间窗或 ext4 的小包。范围仅到“已验证来源证据 → canonical HK corporate-action candidate → as_of 可见选版”，不包含任何真实 source adapter、网络请求、累计因子或 total-return 数值发布。

冻结目标：

- 复用 `CorporateActionSchema`，先证明现有字段是否足以表达 HK；若 revision identity、record/pay/listing 日期、币种或权益字段不足，应先修改 schema SSOT，不在 mapper 私有列中另造第二套合同。
- 输入必须携带不可变 raw/metadata digest、source record identity、抓取/来源时点和 verifier 结果；projection 由 verifier 产生，调用方不能自报“已验证”。
- `as_of` 只可选 `announce_time <= as_of` 的版本；更正/撤回只能从其自身可知时点生效，不能用未来最终版本覆盖历史。
- 同一经济事件重复、冲突修订、未知 action type、缺关键日期、负金额/比例、非 HK symbol、摘要漂移、naive/错误时区均 fail closed。
- 明确 cash dividend、bonus/split/consolidation、rights 的候选语义；P0 不做 total-return 公式。rights、税费或币种转换尚未冻结时保留为显式 unsupported，而不是近似为现金分红。

## 6. 审计结论

M1 当前有四类相互独立的真实阻断：HK60 的 licensed 01065 证据链、完整 HK Instrument 的合规 ETF 来源、真实港股复权/PIT 公司行动来源，以及 U0C 五日自然运行。formal v2 的恢复、余批、02983 finalize 和双 Route Gate 已有足够工程基础，但必须按第 3 节等待并串行完成；G1 Windows 发布成功不改变这些前置条件，G1 Linux/ext4 也不应阻塞来源无关的 HK 工程。

下一步应先冻结并交付 M1-HK-CA-P0。它复用现有 SSOT，补齐目前实际不存在的 HK PIT revision/identity/选版层，同时严格停在真实 source adapter 与 total-return 公式之前；这样既形成可并行增量，也不会制造新的伪 Gate。
