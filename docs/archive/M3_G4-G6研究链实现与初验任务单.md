## 4. H1：horizon 共享 Alpha158 FeatureBundle

新增：

- `src/quant/research/m3/qlib_adapter.py`
- `tests/unit/test_m3_qlib_adapter.py`

实现 `build_alpha158_dataset/qlib_dataset_to_feature_bundle` 和 SSOT 数据对象。顶层不得 import Qlib；使用
严格 fake module/dataset 验证协议。生产 stage 必须为每个 fold 启动一个 fresh Python worker，在该 worker
内连续完成 `qlib.init`、DatasetH 构造、prepare 和普通 Parquet/JSON 输出；Qlib/DatasetH 对象不得跨进程，
父进程不得 import Qlib。这样连续运行两个 provider/fold 时不会复用进程级全局 provider/cache。

要求：

- Alpha158 显式空 infer/learn processors 和 `label=([],[])`；不得创建或读取 LABEL0。
- handler 加载从 provider history start 到 fold test end，使用 provider manifest 的历史并集 instrument set，
  不使用默认 csi500/csi300；segments 来自 PlannedFold。
- `prepare` 只取 feature + DK_I；运行时 feature config 恰好 158 个唯一 name/expression，并记录实际版本。
- 按命名 MultiIndex 转换时间/证券；拒绝无名、时区、非午夜、重复、segment 外或非 session index。
- 先 join PIT eligible keys；inf→NaN；只以 train eligible rows 冻结 input→selected projection，全 NaN train
  列永久删除；validation/test 不得恢复。只允许 numeric float64，bool/object/category/datetime 失败。
- selected columns 后全行 NaN 为 unscorable；逐日 coverage 计数守恒。输出 train/validation/test feature
  parquet、feature manifest 和 coverage，不含 label。
- 同 fold h=5/h=10 必须引用同一 feature receipt/schema/row-key hash，不能调用两次 Qlib handler。
- worker 必须接收 SSOT `FeatureBuildSpec`，绑定 experiment/fold/provider manifest+receipt/planned fold/feature
  config/worker protocol 与实际 Qlib 版本；回包逐项 echo。子进程只写 StageRunner 分配的空 temp，失败或
  版本不符不发布部分 FeatureBundle。PID 只由测试控制器运行时观察，不进入 manifest/report/receipt。

至少覆盖：调入前历史可供 lookback但不成样本、158/157/159列、重复 leaf name、train 全 NaN列在 test
有值仍删除、单行全 NaN、普通 NaN保留、inf转换、列交换、非法 index、不同 horizon feature hash 一致，
以及测试 spy 观察两个不同 provider 请求产生不同 worker PID/初始化 URI、持久产物不含 PID，父进程
`sys.modules` 无 `qlib`。

## 5. H2：监督训练对齐与无标签测试推理

继续修改 `qlib_adapter.py` 与单测，实现 `align_supervised_segment/build_inference_segment`。

- train/validation 一对一 join 项目 label，并使用各自 embargo cutoff；metadata、X、y 使用唯一排序
  MultiIndex `(as_of,symbol)`，y 名称固定 `relative_return`。
- alignment diagnostics 至少记录 feature eligible/scorable、label identity、label joined、cutoff dropped、最终
  rows、row-key/X/y hashes，计数守恒。
- test inference 只读取 FeatureBundle.test，不允许 labels 参数，不因未来缺 label 删除任何 scorable key。
- train/validation 为空失败；不得填充 feature/label，不得在 horizon 间复用 y。

阻断反例：同一天 A/B 都可评分，B 的未来 exit bar 缺失；inference 必须预测 A/B，evaluation 可只匹配 A。
若输出 prediction 前先 inner join label，测试必须失败。
