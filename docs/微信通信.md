# 微信通信：人工交易通知

入口 `quant.reporting.wechat` 使用 wxauto4，向指定群发送文本并读取当前可见消息。
用途是后续策略输出买卖信号后提醒用户，由用户决定并手工下单。

参考本机 `G:\BaiduSyncdisk\wsl\Cursor\wechat_avatar\wxauto-run\scripts\windows_wxauto_server.py`：
复用 `ChatWith`、`ChatInfo`、`SendMsg`、`GetAllMessage` 的调用方式，直接在 Windows Python 3.13
中运行。发送前必须精确核对群名和群聊类型；不自动重试发送，避免超时后重复通知。

## 安装与运行

微信保持登录、桌面解锁。首次安装（项目目录中执行）：

```powershell
D:\Miniforge3\python.exe -m pip install --no-deps --target artifacts/wechat/runtime wxauto4==41.1.7
$env:PYTHONPATH = 'F:/AI_Coding/QuantitativeTrading/src;F:/AI_Coding/QuantitativeTrading/artifacts/wechat/runtime'
$env:PYTHONIOENCODING = 'utf-8'
```

本机此次已具备 wxauto4 的依赖；其他机器可安装项目的 `wechat` optional 依赖。
真实桌面操作需要运行进程能访问当前交互桌面；Codex 沙箱内可能找不到窗口。

准备 UTF-8 文本文件后，先预览，再发送；`--execute` 为实际发微信开关，与交易开关无关：

```powershell
D:\Miniforge3\python.exe -m quant.reporting.wechat --group '原神启动' send --text-file artifacts/wechat/test_message_20260910.txt
D:\Miniforge3\python.exe -m quant.reporting.wechat --group '原神启动' send --text-file artifacts/wechat/test_message_20260910.txt --execute
D:\Miniforge3\python.exe -m quant.reporting.wechat --group '原神启动' read --contains WXTEST-20260910-01
```

默认校验当前群。需要切换时在 `send` / `read` 前增加 `--select`，按完整群名精确搜索。
操作期间请让微信保持在目标群，避免与手动切换聊天同时进行。
`read` 仅提取当前窗口消息；`source=self` 为本账号消息，`friend` 为他人消息。
收到的文本只作为数据返回，不执行消息内容或自动回复。

- Windows 原生 Python 3.13、wxauto4 41.1.7、微信 4.1.12.26。
- 精确识别“原神启动”3 人群，成功读取他人表情消息。
- 发送 1 条明确标注“通信测试｜非交易信号”的 `WXTEST-20260910-01` 文本，返回成功。
- 随后回读到同编号的 `source=self` 测试文本，以及另一账号的
  `source=friend` 文本“收到 WXTEST-20260910-01”，双向文本收发验证通过。
- 12 项定向单测通过，覆盖错误群/私聊拒发、失败不重试、空消息拒发和收取来源。

下一步接入策略生成的订单清单，通知中包含信号编号、策略、生成时间、有效交易日、
买卖方向、标的、数量和价格条件；正式信号接入时增加过期拒发与信号去重。

关键限制：UI 自动化依赖微信版本及桌面状态；发送成功或本机回读不等于手机送达、人工已读或已成交。
