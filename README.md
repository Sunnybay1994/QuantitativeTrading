# 个人 A 股 / ETF 量化投研系统

面向个人投资者的量化研究工作台：持续寻找因子和策略，回测比较历史表现，跟踪模拟账户，并通过消息通知辅助人工操作。

目前可用于投研和模拟观察；飞书人工交易闭环处于演练阶段。系统不自动向券商下单，历史回测表现不代表未来收益。

## 主要功能

- **持续投研**：自动搜索因子、批量评估候选，保存进度并在中断后续跑。
- **策略比较**：查看收益、超额收益、夏普、最大回撤及交易成本影响，按标签搜索和排序。
- **收益曲线与报告**：对比策略和基准曲线，查看策略说明及年度、月度表现，打开或下载报告。
- **模拟账户**：跟踪账户净值、持仓、现金、每日订单和风险提示。
- **运行看板**：查看研究进度、后台任务与异常提示，手动刷新或请求从断点恢复。
- **消息通知**：支持邮件、企业微信、飞书和个人微信；飞书另支持人工成交回复与记账演练。

## 启动项目

当前运行环境为 Windows，项目Python位于 `D:\Miniforge3\python.exe`。在项目根目录打开PowerShell：

```powershell
$env:PYTHONPATH = "$PWD\src"
$env:PYTHONUTF8 = '1'
$env:POLARS_MAX_THREADS = '4'
D:\Miniforge3\python.exe -m quant status
```

若看板已启动，直接打开 [投研工作台](http://127.0.0.1:8768/)。否则执行：

```powershell
D:\Miniforge3\python.exe -m quant report dashboard --port 8768
```

看板仅在本机访问。换机器时需先准备项目依赖、数据和配置，运行环境与详细命令见[运维说明](docs/OPERATIONS.md)。

## 日常怎么用

1. **看进度**：打开看板，检查当前任务、最近更新时间及待处理提示。点击“手动刷新”读取最新状态。
2. **选策略**：在研究结果中搜索名称或标签，点击指标表头排序。默认折叠重复结果，可展开查看原始记录。
3. **比表现**：选择策略、日期和成本档，按需叠加中证500、纳指、恒科等已有基准；可用范围以页面实际数据为准。
4. **读报告**：打开“报告 · 年/月表现”，查看策略说明、年度/月度收益、超额、夏普和回撤，也可下载HTML报告。
5. **查异常**：阅读运行卡片的具体原因。需要恢复时点击“重启投研 / 从断点恢复”；若日更正在运行，挖掘会等待，避免同时写数据。

曲线使用已有数据，刷新页面不会自动补齐行情。详细指标口径、分组规则和运行状态见[看板说明](docs/DASHBOARD.md)。

## 后台自动运行

已安装计划任务后，电脑开机并登录时会按配置运行：

|任务|默认安排|用途|
|---|---|---|
|每日观察|工作日17:30、21:30|更新数据与模拟账户|
|持续挖掘|每10分钟尝试接续|继续未完成的因子研究|
|投研看板|登录时启动|提供本地网页入口|

关机期间不会运行；恢复后保留已有断点。任务尚未安装时，按[运维说明](docs/OPERATIONS.md)注册。计划触发不等于立即开始计算，运行状态以看板为准。

## 消息通知与人工交易演练

单向通知支持 **邮件、企业微信群机器人、飞书群机器人、个人微信**。选择通道后，按[通知接入指南](docs/NOTIFICATIONS.md)配置账号或环境变量，并在 `configs/notify.toml` 设置默认通道。

```powershell
# 只检查本地通知路径，不发送消息
D:\Miniforge3\python.exe -m quant notify test --dry-run
# 配好飞书群机器人后发送测试消息
D:\Miniforge3\python.exe -m quant notify test --channel feishu
```

未配置通道时，通知只保存在本地文件，不会发到手机。接入指南提供每个通道的完整配置、使用示例与送达检查方法。

**飞书双向演练**使用自建应用机器人，可接收委托、部分成交、费用确认和未操作回复，更新演练账本。它与普通飞书群通知是两套配置，目前尚未上线实盘。先体验无需联网的演练：

```powershell
D:\Miniforge3\python.exe -m quant paper manual demo --output artifacts/manual/demo_new
```

输出目录须为新目录。配置双向机器人及学习回复格式，见[人工交易演练说明](docs/MANUAL_EXECUTION_OPERATIONS.md)。
